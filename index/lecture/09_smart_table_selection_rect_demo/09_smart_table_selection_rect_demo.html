v6 對比 v5 改動：
 ・解耦重構：選取狀態機抽出為 TableSelector extends EventTarget。
 ・TableSelector 只負責：繪圖（highlight / cursor）＋消化 pointer 事件狀態機。
 ・選取確認後發出 selectioncommit 事件，payload 使用 row/col index（非 DOM ref）。
 ・「電腦 single 不自動跳選單」的業務規則移至 listener 端，TableSelector 不含 UI 政策。
 ・status 更新、context menu、copy 邏輯各自成為獨立 listener，未來擴充不需修改 TableSelector。
 ・另發出 selectionstart、selectiondrag、selectioncancel 輔助事件。
