★ v4 改動（對比 v3）：
 ・移除 Mouse Events（mousedown/mousemove/mouseup）。
 ・移除 Touch Events（touchstart/touchmove/touchend）。
 ・改用單套 Pointer Events（pointerdown/pointermove/pointerup/pointercancel），同時支援滑鼠、觸控、手寫筆。
 ・使用 table.setPointerCapture(e.pointerId) 確保拖出表格範圍時仍持續收到事件。
 ・CSS touch-action: none 已阻止瀏覽器搶走捲動，不需 passive: false workaround。
