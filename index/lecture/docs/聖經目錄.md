# 聖經目錄

#### 相關程式

| 類別 | 檔案 | 職責 |
|------|------|------|
| `BookSelect` | `index/BookSelect.es2023.js` | 頂部書卷/章顯示按鈕，決定用哪種 UI |
| `BookSelectPopUp` | `index/BookSelectPopUp.es2023.js` | 寬螢幕的下拉展開容器 |
| `BookSelectName` | `index/BookSelectName.es2023.js` | 書卷名稱列表（66 卷，分 8 類） |
| `BookSelectChapter` | `index/BookSelectChapter.es2023.js` | 章次列表（點選書卷後展開） |
| `Ijnjs.BookChapDialog` | ijnjs 函式庫 | 窄螢幕的 Dialog UI |

---

#### 兩種 UI 路徑

```
使用者點擊 #bookSelect
  ↓
判斷視窗寬度 < 1280 或 ps.book_select_method == 1
  ├─ 是（窄螢幕）→ Ijnjs.BookChapDialog.s.show({ book, chap, isGb })
  │                  ↓（使用者選好後關閉）
  │               dlg.setCBHided(callback)
  │                  → ps.bookIndex, ps.chap, ps.sec = 1
  │                  → change_sec_of_ps_if_address_exist_in_view_history()
  │                  → triggerGoEventWhenPageStateAddressChange(ps)
  │                  → BookSelect.s.render()
  │                  → FhlLecture.s.render()
  │                  → ViewHistory.s.render()
  │                  → FhlInfo.s.render(ps)
  │
  └─ 否（寬螢幕）→ BookSelectPopUp.s.dom.fadeIn/Out（toggle）
                    └─ 展開 #bookSelectPopUp
                         └─ BookSelectName（書卷列表）
                              ↓（點擊書卷）
                              BookSelectChapter.init()（章次列表定位展開）
                                   ↓（點擊章次）
                                   ps.bookIndex, ps.chap, ps.sec = 1
                                   → change_sec_of_ps_if_address_exist_in_view_history()
                                   → triggerGoEventWhenPageStateAddressChange(ps)
                                   → BookSelect.s.render()
                                   → FhlLecture.s.render()
                                   → ViewHistory.s.render()
                                   → FhlInfo.s.render(ps)
```

---

#### 狀態更新欄位

| 欄位 | 說明 |
|------|------|
| `ps.bookIndex` | 書卷編號（1-based，1=創世記） |
| `ps.chap` | 章 |
| `ps.sec` | 節（預設設為 1） |

`change_sec_of_ps_if_address_exist_in_view_history()`：若使用者曾瀏覽該章，`ps.sec` 自動跳回上次所在節，而非第 1 節。

---

#### BookSelectName 的書卷分類

`render()` 將 66 卷依分類渲染為 6 欄：

| 欄 | 分類 |
|----|------|
| 1 | 摩西五經（創—申） |
| 2 | 舊約歷史書（書—斯）、詩歌智慧書（伯—歌）、大先知書（賽—但） |
| 3 | 小先知書（何—瑪） |
| 4 | 福音書（太—約）、新約歷史書（徒） |
| 5 | 保羅書信（羅—來） |
| 6 | 其他書信（雅—啟） |

每個 `<li>` 帶 `chineses` 屬性（書卷中文縮寫），點擊後觸發 `BookSelectChapter.init()`，以 `getBookFunc("index", chineses)` 取得 0-based book index。

#### BookSelect.render()

頂部按鈕的顯示文字由此產生：

```js
// 詩篇特例：用「篇」
if (ps.bookIndex == 19) {
    html = bookName + "： 第" + CHINESE_NUMBERS[ps.chap] + "篇"
} else {
    html = bookName + "： 第" + CHINESE_NUMBERS[ps.chap] + "章"
}
// 結尾加下拉箭頭 ▼
html += '&nbsp;&#9660;'
```
