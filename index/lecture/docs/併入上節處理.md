## 併入上節處理

### 資料來源

API（`qsb_php`）回傳的 `bible_text` 欄位若為 `"a"`，代表此譯本此節的內容與上一節合併。

```js
// API 回傳範例（歌羅西書 2:20-21，21節與20節合併）
record[0]: { book:51, chap:2, sec:20, bible_text: "各位與基督一同死..." }
record[1]: { book:51, chap:2, sec:21, bible_text: "a" }
```

### 偵測函數

`is_merge_with_prev_verse()` — [FhlLecture_render_core.js:47](../FhlLecture_render_core.js#L47)

```js
function is_merge_with_prev_verse(dtexts_with_addr2) {
    const dtexts = dtexts_with_addr2[3]
    if (dtexts.length != 1) return false;
    if (dtexts[0].w == "a") return true;
    return false;
}
```

判斷條件：`dtexts` 陣列長度為 1，且唯一一筆的 `.w` 欄位等於 `"a"`。

### build_view_model() 的處理

[FhlLecture_render_core.js:219](../FhlLecture_render_core.js#L219)

偵測到合併節時，執行兩件事：

1. **更新上一節的 `verseLabel`**：將其從 `"20"` 改為 `"20-21"`（範圍標籤），並將本節節碼加入 `mergedSecs`。
2. **為本節建立隱藏的 placeholder**：保留在 `verses` 陣列中，但設定隱藏旗標，供 mode1/2 row 模式對齊使用。

```js
if (is_merge_with_prev_verse(dtexts_with_addr2)) {
    const last = verses[verses.length - 1];
    if (last != null) {
        const start = String(last.verseLabel).split("-")[0];
        last.verseLabel = `${start}-${sec}`;   // 改為 "20-21"
        last.mergedSecs.push(sec);
    }
    verses.push({
        book, chap, sec, dtexts,
        verseLabel: "",
        mergedSecs: [],
        isMergePlaceholder: true,
        hideVerseNumber: true,
        hideVerseContent: true
    });
    continue;
}
```

### VmVerse 相關欄位

[FhlLecture_render_core.js:136](../FhlLecture_render_core.js#L136)

| 欄位 | 說明 |
|------|------|
| `verseLabel` | 顯示的節碼標籤，合併後的上一節會變成如 `"20-21"` |
| `mergedSecs` | 被合併進來的節碼陣列，如 `[21]` |
| `isMergePlaceholder` | `true` 表示此節是 `"a"` 的佔位符 |
| `hideVerseNumber` | `true` 時不渲染節碼 |
| `hideVerseContent` | `true` 時跳過整節渲染 |

### 完整流程

```
API: bible_text="a"
  → cvt_others()              將 "a" 轉為 DText: { w: "a" }
  → build_view_model()
      is_merge_with_prev_verse() 偵測
      上一節: verseLabel "20" → "20-21"，mergedSecs=[21]
      本節:   hideVerseContent=true（placeholder，保留供對齊）
  → render_paragraph_div()
      hideVerseContent=true → continue（跳過）
      上一節節碼顯示為 "20-21"
```
