# 取得經文資料

#### 相關程式

- 主要函式：`index/lecture_get_data_async_es2023.js` → `lecture_get_data_async()`
- qsb API 封裝：`index/api/qsb.js` → `qsb()`
- 原文版本（fhlwh）：`index/Bible_fhlwh_json.es2023.js`

---

#### 整體流程

```
lecture_get_data_async()
  ↓
讀取 ps.version[]，對每個版本並行發出請求
  ├─ ver == "fhlwh" → get_fhlwh(book, chap)
  │    ├─ 等待 Bible_fhlwh_json.s.filecontent 載入完成
  │    └─ 從 JSON 資料直接過濾 book/chap，回傳 TpResultBibleText
  │
  └─ 其他版本 → get_from_qsb_php_async(book, chap, gb, ver)
       ├─ 將 bookIndex 轉成中文簡稱，組成 qstr（例如「約1」）
       └─ qsb({ qstr, ver, isGb })  ← POST 到 /json/qsb.php
  ↓
Promise.all() 等待所有版本取回
  ↓
add_book_property_to_bibletext_record()
  └─ record 中原本只有 engs/chineses，補上 book 欄位（1-based）
  ↓
（若有 bhs）modify_bhs_bible_text()
  └─ 每節的 bible_text 以換行切割後 reverse，修正希伯來文順序
  ↓
回傳 TpResultBibleText[]
```

---

#### 資料型別

**`TpResultBibleText`**（定義於 `FhlLecture_render_mode_common_es2023.js`）

| 欄位 | 說明 |
|------|------|
| `status` | `"success"` 或 `"failed"` |
| `version` | 版本代號，例如 `"unv"` |
| `v_name` | 版本中文名稱，例如 `"新譯本"` |
| `record_count` | 該章節數 |
| `record` | `TpOneRecordBibleText[]` — 每節的資料 |
| `next` | 下一章的 DAddress（書/章/節） |
| `prev` | 上一章的 DAddress |

**`TpOneRecordBibleText`**

| 欄位 | 說明 |
|------|------|
| `book` | 書卷編號（1-based，後處理補上） |
| `chap` | 章 |
| `sec` | 節 |
| `bible_text` | 經文內容（原始字串，含標記） |

---

#### 兩種資料來源

**一般版本 — `qsb` API**

```
qsb({ qstr, ver, isGb })
  ↓
POST /json/qsb.php
  params: qstr, engs（書卷英文縮寫）, version, strong, gb
  ↓
DQsbResult { status, record_count, record[] }
  ↓
qsbRecordToStd()  ← engs → book（in-place）
  ↓
加上 v_name（從 abvphp.get_cname_from_book() 取得）
```

**原文版本（fhlwh）— 本地 JSON**

```
Bible_fhlwh_json.s.filecontent["data"]
  資料格式：[book, chap, sec, bible_text]
  ↓
過濾 book == ps.bookIndex && chap == ps.chap
  ↓
組成 TpResultBibleText（不需網路請求）
```

---

#### 特殊處理

**`add_book_property_to_bibletext_record`**
qsb 回傳的 record 只有 `engs`（英文書卷名），需透過 `BibleConstantHelper.getBookId()` 轉成 `book`（1-based 整數），同時也處理 `next` / `prev`。

**`modify_bhs_bible_text`**（僅 bhs 版本）
BHS（希伯來文聖經）每節可能包含多個子節，以換行分隔但順序相反，需 reverse 後重新合併。
