# 滑鼠（電腦）與平板行為規畫

## 一、選取模式總覽

| 模式 | 觸發條件 | 說明 |
|------|---------|------|
| `single` | 點擊單一 cell，未跨格 | 選取該格內容 |
| `col` | 拖曳，起點與終點同欄 | 同欄跨列選取，藍底白字 highlight |
| `row` | 拖曳，起點與終點跨欄 | 矩形範圍選取，藍底白字 highlight |

---

## 二、電腦（滑鼠）行為

### 選取
- `pointerdown`（左鍵）→ 進入選取流程
- 拖曳跨格 → 判斷 col / row 模式，highlight 對應格
- 單格點擊（未拖曳）→ `single` 模式，**開啟該 td 的 `user-select`**，讓使用者可以在格內選取部分文字

### 複製觸發方式（三種，互不衝突）
| 方式 | 說明 |
|------|------|
| `Ctrl+C` | 透過 `copy` 事件攔截，直接複製，不跳出選單 |
| 右鍵 | `contextmenu` 事件 → 顯示自訂 ctx menu |
| 面板複製按鈕 | 點擊按鈕 → 執行 `performCopy()` |

### user-select 策略
- `tbody td` 預設 `user-select: none`（避免拖曳時出現原生選字水滴）
- 進入 `single` 模式後，**只對目標 td** 動態設為 `user-select: text`
- 離開 single 模式時恢復 `none`

---

## 三、平板（touch）行為

### 選取
- `pointerdown`（pointerType === 'touch'）→ 進入選取流程
- 拖曳跨格 → 同電腦，判斷 col / row 模式
- 單格點擊（未拖曳）→ `single` 模式，**整格複製，不做字元級選取**

### 複製觸發方式
| 方式 | 說明 |
|------|------|
| `pointerup` 後自動跳出 ctx menu | 選完即顯示，觸控最直覺 |
| 長按右鍵（contextmenu） | 長按也會觸發，同樣跳出 ctx menu |
| 面板複製按鈕 | 備用 |

> **不提供 Ctrl+C 以外的鍵盤操作**（平板無鍵盤假設），但 Ctrl+C 仍有效。

### user-select 策略
- `tbody td` 全程 `user-select: none`
- **不開放字元選取**，不出現藍色水滴 handle
- 單格 = 整格複製，這在平板上已足夠實用

### 為何平板不做字元選取
1. 平板原生水滴 handle 和自訂拖曳流程無法共存（會觸發 `pointercancel`）
2. 平板手指精準度低，字元選取體驗本就不佳
3. 雙擊、三擊的原生行為難以一致性攔截
4. 整格複製對平板使用情境已足夠

---

## 四、cell 內有互動元素的處理

cell 內可能含有可點擊的功能元素，例如 Strong's Number（點擊開啟字典）。

**規則：點到互動元素時，忽略選取流程，讓事件正常傳遞。**

```js
table.addEventListener('pointerdown', e => {
  // 點到互動元素 → 放行
  if (e.target.closest('a, button, [data-action]')) return;

  const td = tdAt(e.clientX, e.clientY);
  if (!td) return;
  // 進入選取流程...
});
```

可依實際 DOM 結構調整 selector（如 `.strong-num`、`[data-strno]`）。

---

## 五、行為對照表

| 操作 | 電腦（mouse） | 平板（touch） |
|------|-------------|-------------|
| 單格點擊 | single 模式，可選部分文字 | single 模式，整格複製 |
| 拖曳同欄 | col 模式，highlight 藍底白字 | col 模式，highlight 藍底白字 |
| 拖曳跨欄 | row 矩形模式，highlight 藍底白字 | row 矩形模式，highlight 藍底白字 |
| 選完後複製 | 右鍵 / Ctrl+C / 按鈕 | 自動跳出選單 / 按鈕 |
| user-select | single 時開啟目標 td | 全程關閉 |
| 水滴 handle | 不出現（除 single 模式目標 td） | 不出現 |
| 點到互動元素 | 忽略選取，正常觸發元素行為 | 忽略選取，正常觸發元素行為 |

---

## 六、架構規畫（08 版本）

```
08_smart_table_selection_rect_demo/
  ├── 08.html
  ├── 08.css
  ├── CtxMenu.js     ← UI 元件：顯示/隱藏/位置/items
  └── 08.js          ← 選取邏輯、copy 邏輯、呼叫 CtxMenu
```

### CtxMenu.js 對外介面

```js
export class CtxMenu {
  constructor(menuEl) { ... }
  show(x, y, items) { ... }  // items: [{ label, onClick, disabled }]
  hide() { ... }
}
```

### 08.js 呼叫方式

```js
import { CtxMenu } from './CtxMenu.js';
const ctxMenu = new CtxMenu(document.getElementById('ctx-menu'));

// 選取完成後（touch）
ctxMenu.show(x, y, [
  { label: '📋 複製', onClick: performCopy, disabled: !currentMode },
  { label: '顯示瀏覽器原本選單…', onClick: showNative },
]);
```
