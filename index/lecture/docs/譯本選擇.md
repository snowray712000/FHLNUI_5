# 譯本選擇

#### 相關程式

- 主要邏輯：`index/FhlLeftWindow.es2023.js`
- Dialog 元件：`Ijnjs.BibieVersionDialog`（外部 ijnjs 函式庫）
- 版本列表資料：`window.abvphp`（`static/search_api/abvphp_api.js`）

---

#### 整體流程

```
使用者點擊「聖經版本選擇」按鈕（#versionSelect2 或 #versionSelect3）
  ↓
Ijnjs.BibieVersionDialog.s.open({ selects, offens, sets })
  selects = ps.version        ← 目前已選版本
  offens  = ps.versionOffens  ← 偏好設定
  sets    = ps.versionSets    ← 群組設定
  ↓
（使用者在 Dialog 中勾選版本後關閉）
  ↓
setCallbackClosed(jo => ...)
  jo.selects  → 新版本陣列
  jo.offens   → 更新 ps.versionOffens
  jo.sets     → 更新 ps.versionSets
  ↓
比對 jo.selects 與現有 ps.version 是否有變化
  有變化 → ps.version = jo.selects
         → triggerGoEventWhenPageStateAddressChange(ps)
         → FhlLecture.s.render(ps)
  無變化 → 不 render
  ↓
ps.saveToLocalStorage()   ← 無論有無變化都儲存
```

---

#### 版本列表資料來源

Dialog 開啟前，需等待 `window.abvphp` 就緒（以 `testThenDoAsync` 輪詢）：

```js
testThenDoAsync(() => window.abvphp != null && window.abvphp.isReadyGlobalBibleVersions())
    .then(() => {
        s.setVersionsFromApi(getAbvResult())
    })
```

`getAbvResult()` 依 `ps.gb`（1=簡體，0=繁體）選擇資料源：
- 繁體：`abvphp.g_bibleversions`
- 簡體：`abvphp.g_bibleversionsGb`

轉換格式為 `{ na: version_id, cna: 中文名稱 }[]` 後注入 Dialog。

---

#### 狀態欄位（TPPageState）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `ps.version` | `string[]` | 目前選中的版本 id，例如 `["unv", "cbol"]` |
| `ps.versionOffens` | any | Dialog 的偏好設定（由 Dialog 管理） |
| `ps.versionSets` | any | Dialog 的群組設定（由 Dialog 管理） |

---

#### UI 觸發點

| 元素 | 說明 |
|------|------|
| `#versionSelect2` | 左側欄「聖經版本選擇」文字按鈕 |
| `#versionSelect3` | 工具列圖示按鈕（`bi-layout-three-columns`） |

兩者點擊後都呼叫同一個 `open()` function。

---

#### 初始化時序

```
FhlLeftWindow.init()
  ↓
setTimeout 300ms
  ├─ renderVersionSelect2()   ← 建立 #versionSelect2 DOM
  ├─ renderVersionSelect3()   ← 建立 #versionSelect3 DOM
  └─ initSetVersionDialogAsync()
       ↓
       testThenDoAsync(() => Ijnjs.BibieVersionDialog != undefined)
         ↓
         s.setCallbackClosed(...)    ← 設定關閉 callback
         s.setCallbackOpened(...)    ← 設定開啟 callback
         testThenDoAsync(() => abvphp.isReadyGlobalBibleVersions())
           ↓
           s.setVersionsFromApi(...)  ← 注入版本列表
         #versionSelect2 / #versionSelect3 綁定 click → open()
```
