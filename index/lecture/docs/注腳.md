# 注腳

#### 相關程式

- 注腳資料型別：`index/DFoot.js` → `DFoot`
- DText 掛接欄位：`index/DText.js` → `DText.foot`
- 從經文抽取標誌：`index/cvt_others_addFoot.js`
- RCUV 特殊處理：`index/cvt_other_text_like_foot.js`
- 核心查詢與格式化：`index/queryFootsAsync.js` → `queryFootsAsync()`
- 顯示方式狀態：`index/TPPageState.es2023.js` → `ps.foot_note_show_method`
- 測試：`tests/foots_query_test.js`

---

#### 整體流程

```
QSB API 回傳經文字串
  ↓
cvt_others_addFoot.js
  └─ 偵測 【n】 標誌 → 建立 DFoot { id, book, chap, verse, version, footContent: null }
  └─ 掛到對應 DText.foot
  ↓
依 ps.foot_note_show_method 決定載入時機
  ├─ 0 (點擊顯示) → 使用者點擊 【n】 才呼叫 queryFootsAsync
  └─ 2 (直接載入) → 渲染前立即呼叫 queryFootsAsync 預載全部
  ↓
queryFootsAsync(dtexts_with_addr, ver)
  ├─ 並行 rtAsync → GET /json/rt.php?engs=&chap=&version=&id=
  ├─ 填入 dfoot.footContent = [{ w: text }]（初始）
  └─ 依版本格式化（見下方）
       ├─ csb → cvt_foot_csb()
       ├─ cnet → cvt_foot_cnet()
       └─ lcc → 無需額外轉換
  ↓
footContent = DText[]（可含 isRef:1 的交互參照）
```

---

#### DFoot 型別

定義於 `index/DFoot.js`：

| 欄位 | 說明 |
|------|------|
| `id` | 注腳識別碼（各版本規則不同，有的換章重置） |
| `book` | 書卷編號 |
| `chap` | 章 |
| `verse` | 節 |
| `version` | 版本代號（`csb` / `cnet` / `lcc` / ...） |
| `footContent` | `DText[] \| null`，null 表示尚未載入 |

API 回傳範例（`/json/rt.php`，以 ROM 3:57 為例）：

```json
{
  "status": "success",
  "record_count": 1,
  "version": "cnet",
  "engs": "Rom",
  "record": [{ "id": 57, "text": "\t 「有許多好處」或作「各方面都有好處」。" }]
}
```

#### 各譯本格式差異與轉換

**CSB（中文標準譯本，新約）**

原始內容格式：`"3 1:23 《以賽亞書》7:14。"`

轉換規則（`cvt_foot_csb()`）：
1. 移除開頭重複的章節號
2. 正則 `/《([^》]+)》([0-9\:：\-\;；,，、]+)/g` 抽取書卷名與章節
3. 特殊範圍：「詩篇 113-118 篇」→ `詩113:1-118:29`
4. 連續交互參照合併為單一 `{ isRef:1, refDescription }` 的 DText

**CNET（NET 聖經中譯本）**

原始內容格式：`"「烏利亞的妻子」。即拔示巴（Bathsheba）（參撒下11:3）。"`

轉換規則（`cvt_foot_cnet()`）：
1. 抽取所有有效書卷名稱，**按長度由長到短排序**（避免「撒」先匹配到「撒下」）
2. 動態正則搜尋書卷名 + 章節號
3. 識別出的書卷轉換為 `{ isRef:1, refDescription }`

**LCC（呂振中譯本）**

無需格式化轉換，直接使用 API 回傳文字。

**RCUV（和合本 2010）**

注腳嵌在經文內容裡，格式：`（【n.m】... 注腳文字 ...）`

處理於 `cvt_other_text_like_foot.js`：
- 正則 `/\(\s*\[\s*\d+\.\d+\s*\]([^\)]*)\)/g` 直接解出文字
- **不需要呼叫 API**，解出後直接設定 `foot.footContent`

#### `foot_note_show_method`

定義於 `index/TPPageState.es2023.js`，設定 UI 於 `index/Settings.es2023.js`：

| 值 | 說明 |
|----|------|
| `0` | 點擊顯示：使用者點擊標誌才 lazy load |
| `2` | 直接載入：渲染前預載全部注腳 |

（值 `1` 滑鼠移過已定義但目前在 Settings UI 中被註解）

---

#### 測試

`tests/foots_query_test.js` 涵蓋：

| 版本 | 測試場景 |
|------|---------|
| lcc | 基本流程（創 2:1）；多位置同一 id 同步優化 |
| csb | 交互參照轉換（太 1:23、4:6）；詩篇範圍（太 26:30）；同節多個注腳（羅 9:9） |
| cnet | 無《》書卷名搜尋（太 1:6）；複雜學術注解（太 1:23 三個注腳） |
