Mode 1–4 HTML 結構規格範例

資料說明：範例使用 2 個譯本 (rcuv, csb)，西2:20–22，故意含有合併上節（20-21 合為一節）的情況。
書卷：book="51"（歌羅西書）、chap="2"、sec = 節次
Modelayoutcopy_dir段落結構
1逐節 (verse-by-verse)col / row每節一個 .paragraph，每譯本一個 .vercol
2逐節 交錯col only所有譯本在同一 .vercol，節次交錯排列
3段落 (paragraph)col / row同一段落的所有節在同一 .paragraph，每譯本一個 .vercol
4段落 交錯col only所有譯本在同一 .vercol，段落交錯排列

Mode 1 — 逐節並排 (copy_dir="col"，每譯本獨立直欄)

┌─────── vercol (rcuv) ───────┐ ┌─────── vercol (csb) ────────┐ │ paragraph: sec=20 (20-21) │ │ paragraph: sec=20 │ │ paragraph: sec=21 (空) │ │ paragraph: sec=21 │ │ paragraph: sec=22 │ │ paragraph: sec=22 │ └─────────────────────────────┘ └─────────────────────────────┘
每個節次各自一個 .paragraph。rcuv 的 20-21 合節，所以 sec=21 的 paragraph 內容為空。
copy_dir="col" → 複製時以「整欄（同一譯本）」為單位，讓使用者能反白複製同一譯本的完整經文。
<div id="lecMain" mode="1" copy_dir="col">
<!-- 譯本1 rcuv -->
<div class="vercol">
<div class="paragraph">
<span class="lec" ver="rcuv" book="51" chap="2" sec="20">
<span class="verseNumber">20-21 </span>
<span class="verseContent">{render_dtexts} 既然你們與基督同死...</span>
</span>
</div>
<div class="paragraph"> <!-- sec=21 在 rcuv 已合入上節，故內容為空 -->
<span class="lec" ver="rcuv" book="51" chap="2" sec="21">
<span class="verseNumber"></span>
<span class="verseContent"></span>
</span>
</div>
<div class="paragraph">
<span class="lec" ver="rcuv" book="51" chap="2" sec="22">
<span class="verseNumber">22 </span>
<span class="verseContent">{render_dtexts} 這些都是根據人的命令...</span>
</span>
</div>
</div>
<!-- 譯本2 csb -->
<div class="vercol">
<div class="paragraph">
<span class="lec" ver="csb" book="51" chap="2" sec="20">
<span class="verseNumber">20 </span>
<span class="verseContent">{render_dtexts} 你們如果已經和基督一同死了...</span>
</span>
</div>
<div class="paragraph">
<span class="lec" ver="csb" book="51" chap="2" sec="21">
<span class="verseNumber">21 </span>
<span class="verseContent">{render_dtexts} 「不可碰，不可嘗，不可摸」...</span>
</span>

<span class="lec" ver="csb" book="51" chap="2" sec="22">
<span class="verseNumber">22 </span>

</span>
</div>
</div>
</div>

Mode 1 — 逐節並排 (copy_dir="row"，以「節次 row」為複製單位)

┌── vercol ─┐ ┌── vercol ─┐ ┌── vercol ─┐ ┌── vercol ─┐ ┌── vercol ─┐ ┌── vercol ─┐ │rcuv sec=20│ │csb sec=20 │ │rcuv sec=21│ │csb sec=21 │ │rcuv sec=22│ │csb sec=22 │ └───────────┘ └───────────┘ └───────────┘ └───────────┘ └───────────┘ └───────────┘ ←──────────────────── 節次 row: sec=20 ──────────────────→ ...（以此類推）
copy_dir="row" → 同一節次的所有譯本各自放在獨立的 .vercol，
排列順序為：[rcuv:20, csb:20, rcuv:21, csb:21, rcuv:22, csb:22]，
CSS 負責以 row 方式對齊，讓同節並排。
<div id="lecMain" mode="1" copy_dir="row">
<!-- sec=20：先 rcuv 後 csb -->
<div class="vercol"><div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="20">...</span></div></div>
<div class="vercol"><div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="20">...</span></div></div>
<!-- sec=21 -->
<div class="vercol"><div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="21">(空)</span></div></div>
<div class="vercol"><div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="21">...</span></div></div>
<!-- sec=22 -->
<div class="vercol"><div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="22">...</span></div></div>
<div class="vercol"><div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="22">...</span></div></div>
</div>

Mode 2 — 逐節交錯 (copy_dir="col" only)

┌─────────────────── vercol (唯一) ───────────────────────┐ │ paragraph: rcuv sec=20 (20-21 合節) │ │ paragraph: csb sec=20 │ │ paragraph: rcuv sec=21 (空) │ │ paragraph: csb sec=21 │ │ paragraph: rcuv sec=22 │ │ paragraph: csb sec=22 │ └─────────────────────────────────────────────────────────┘
mode 2 只有一個 .vercol；同節次的各譯本「交錯」排列（rcuv → csb → rcuv → csb…）。
copy_dir 固定為 "col"，沒有 row 模式。
<div id="lecMain" mode="2" copy_dir="col">
<div class="vercol">
<!-- sec=20 -->
<div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="20">
<span class="verseNumber">20-21 </span><span class="verseContent">{render_dtexts} 既然你們與基督同死...</span>
</span></div>
<div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="20">
<span class="verseNumber">20 </span><span class="verseContent">{render_dtexts} 你們如果已經和基督一同死了...</span>
</span></div>
<!-- sec=21（rcuv 空節） -->
<div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="21">
<span class="verseNumber"></span><span class="verseContent"></span>
</span></div>
<div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="21">
<span class="verseNumber">21 </span><span class="verseContent">{render_dtexts} 「不可碰，不可嘗，不可摸」...</span>
</span></div>
<!-- sec=22 -->
<div class="paragraph"><span class="lec" ver="rcuv" book="51" chap="2" sec="22">
<span class="verseNumber">22 </span><span class="verseContent">{render_dtexts} 這些都是根據人的命令...</span>
</span></div>
<div class="paragraph"><span class="lec" ver="csb" book="51" chap="2" sec="22">
<span class="verseNumber">22 </span><span class="verseContent">{render_dtexts} 這些東西都是一經使用就要衰朽的...</span>
</span></div>
</div>
</div>

Mode 3 — 段落並排 (copy_dir="col"，每譯本獨立直欄)

┌─────────── vercol (rcuv) ───────────┐ ┌─────────── vercol (csb) ────────────┐ │ paragraph A: │ │ paragraph A: │ │ lec sec=20 (verseNumber: 20-21) │ │ lec sec=20 (verseNumber: 20) │ │ lec sec=21 (verseNumber: 空) │ │ lec sec=21 (verseNumber: 21) │ │ lec sec=22 (verseNumber: 22) │ │ lec sec=22 (verseNumber: 22) │ │ paragraph B: ... │ │ paragraph B: ... │ └─────────────────────────────────────┘ └─────────────────────────────────────┘
與 mode 1 最大的差異：同一段落的「所有節」都放在同一個 .paragraph 內（多個 .lec span 並排），
而 mode 1 是每節各自一個 .paragraph。
.vercol 結構與 mode 1 相同。
<div id="lecMain" mode="3" copy_dir="col">
<!-- 譯本1 rcuv -->
<div class="vercol">
<div class="paragraph"> <!-- 段落 A：sec 20–22 合在同一 paragraph -->
<span class="lec" ver="rcuv" book="51" chap="2" sec="20"><span class="verseNumber">20-21 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="rcuv" book="51" chap="2" sec="21"><span class="verseNumber"></span><span class="verseContent"></span></span> <!-- 空 -->
<span class="lec" ver="rcuv" book="51" chap="2" sec="22"><span class="verseNumber">22 </span><span class="verseContent">{render_dtexts}</span></span>
</div>
<div class="paragraph">...</div> <!-- 段落 B, C... -->
</div>
<!-- 譯本2 csb -->
<div class="vercol">
<div class="paragraph">
<span class="lec" ver="csb" book="51" chap="2" sec="20"><span class="verseNumber">20 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="csb" book="51" chap="2" sec="21"><span class="verseNumber">21 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="csb" book="51" chap="2" sec="22"><span class="verseNumber">22 </span><span class="verseContent">{render_dtexts}</span></span>
</div>
<div class="paragraph">...</div>
</div>
</div>

Mode 3 — 段落並排 (copy_dir="row"，以「段落 row」為複製單位)

┌── vercol ──┐ ┌── vercol ──┐ ┌── vercol ──┐ ┌── vercol ──┐ ┌── vercol ──┐ ┌── vercol ──┐ │rcuv para A │ │csb para A │ │rcuv para B │ │csb para B │ │rcuv para C │ │csb para C │ └────────────┘ └────────────┘ └────────────┘ └────────────┘ └────────────┘ └────────────┘ ←───── 段落 row A ──────────→ ←───── 段落 row B ──────────→
與 mode 1 copy_dir="row" 邏輯相同，但改以「段落」為單位切分 .vercol，
每個 .vercol 的 .paragraph 內包含該段落所有節的 .lec span。
<div id="lecMain" mode="3" copy_dir="row">
<!-- 段落 A row：先 rcuv 後 csb -->
<div class="vercol"><div class="paragraph">
<span class="lec" ver="rcuv" sec="20" ...>...</span>
<span class="lec" ver="rcuv" sec="21" ...>(空)</span>
<span class="lec" ver="rcuv" sec="22" ...>...</span>
</div></div>
<div class="vercol"><div class="paragraph">
<span class="lec" ver="csb" sec="20" ...>...</span>
<span class="lec" ver="csb" sec="21" ...>...</span>
<span class="lec" ver="csb" sec="22" ...>...</span>
</div></div>
<!-- 段落 B, C ... 依此類推 -->
</div>

Mode 4 — 段落交錯 (copy_dir="col" only)

┌──────────────────── vercol (唯一) ──────────────────────────┐ │ paragraph A (rcuv): lec:20 lec:21(空) lec:22 │ │ paragraph A (csb): lec:20 lec:21 lec:22 │ │ paragraph B (rcuv): ... │ │ paragraph B (csb): ... │ └─────────────────────────────────────────────────────────────┘
mode 4 是 mode 2（交錯）的「段落版」：只有一個 .vercol，
同一段落的各譯本交錯排列，且每個 .paragraph 內含多個 .lec span（整段）。
copy_dir 固定為 "col"。
<div id="lecMain" mode="4" copy_dir="col">
<div class="vercol">
<!-- 段落 A -->
<div class="paragraph"> <!-- rcuv -->
<span class="lec" ver="rcuv" book="51" chap="2" sec="20"><span class="verseNumber">20-21 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="rcuv" book="51" chap="2" sec="21"><span class="verseNumber"></span><span class="verseContent"></span></span> <!-- 空 -->
<span class="lec" ver="rcuv" book="51" chap="2" sec="22"><span class="verseNumber">22 </span><span class="verseContent">{render_dtexts}</span></span>
</div>
<div class="paragraph"> <!-- csb -->
<span class="lec" ver="csb" book="51" chap="2" sec="20"><span class="verseNumber">20 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="csb" book="51" chap="2" sec="21"><span class="verseNumber">21 </span><span class="verseContent">{render_dtexts}</span></span>
<span class="lec" ver="csb" book="51" chap="2" sec="22"><span class="verseNumber">22 </span><span class="verseContent">{render_dtexts}</span></span>
</div>
<!-- 段落 B, C ... 依此類推（rcuv 後接 csb 交錯）-->
<div class="paragraph">...</div>
<div class="paragraph">...</div>
</div>
</div>
