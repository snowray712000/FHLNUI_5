# 07 → 08 的變化

## 一、highlight 統一

| 版本 | col 模式 | row 模式 |
|------|---------|---------|
| 07 | 藍底白字（`.col-sel`） | 橘底白字（`.row-sel`） |
| 08 | 藍底白字（`.sel`） | 藍底白字（`.sel`） |

兩種顏色原本只是為了方便開發時區分模式，實際使用上不需要區別，統一即可。

---

## 二、電腦 vs 平板的 single 模式分流

07 的 single 模式只有一種行為（開啟 `getSelection` 選取）。

08 依 `pointerType` 分流：

| | 電腦（mouse） | 平板（touch） |
|---|---|---|
| single 行為 | 動態開啟該 td 的 `user-select: text` + `cursor: text`，可選取格內部分文字 | 整格 highlight，不開字元選取，不出現水滴 handle |
| 原因 | 滑鼠精準，字元選取有實用價值 | 手指不精準，整格複製已足夠；水滴 handle 和自訂拖曳流程衝突 |

`tbody td` 預設 CSS `user-select: none`，電腦 single 模式才動態對目標 td 設為 `text`，其餘格維持關閉。

## 三、pointerup 後自動跳出選單

| | single | 跨 cell (col/row) |
|---|---|---|
| 電腦 | pointerup 自動跳出 | 不自動，右鍵觸發 |
| 平板 | pointerup 自動跳出 | pointerup 自動跳出 |

電腦跨 cell 拖曳結束時不自動跳出，是因為拖曳完游標停在表格上，選單出現容易誤觸，習慣右鍵或 Ctrl+C 的使用者也較順手。

---

## 四、互動元素放行

08 在 `pointerdown` 最前面加入檢查：

```js
if (e.target.closest('a, button, [data-action]')) return;
```

點到 cell 內的連結、按鈕、或帶 `data-action` 的元素時，不進入選取流程，讓元素原本的行為正常觸發（例如 Strong's Number 開啟字典）。

---

## 五、CtxMenu 拆為獨立元件

| | 07 | 08 |
|---|---|---|
| ctx menu | HTML 寫死 items，JS 直接操作 DOM | `CtxMenu.js` 元件，`show(x, y, items)` 動態組裝 |
| items 內容 | 固定兩項 | 由呼叫端傳入，彈性擴充 |
| 自動關閉監聽 | 常駐 `document` 事件 | `show()` 時掛載，`hide()` 時移除，不常駐 |

`CtxMenu.js` 對外介面：

```js
menu.show(x, y, [
  { label: '📋 複製', onClick: fn },
  { label: '---' },                        // separator
  { label: '其他項目', onClick: fn, disabled: true },
]);
menu.hide();
```
