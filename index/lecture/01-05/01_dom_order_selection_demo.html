DOM Order Selection Demo

用滑鼠拖曳選取文字，觀察選取範圍如何跟隨 DOM 順序移動。

A. <table> — Row-based (橫向 DOM 順序)

HTML 結構：<tr> → <td>左 <td>中 <td>右，選取會橫向跨欄
左欄 第1行中欄 第1行右欄 第1行
左欄 第2行中欄 第2行右欄 第2行
左欄 第3行中欄 第3行右欄 第3行
左欄 第4行中欄 第4行右欄 第4行
☝ 拖曳選取「左欄 第2行」→「右欄 第3行」：選取橫帶刷過整列（Row-wise selection）

B. Flexbox row — Row-based (橫向 DOM 順序)

HTML 結構：flex-row → cell×3，視覺與 table 相同，DOM 順序也相同
左欄 第1行
中欄 第1行
右欄 第1行
左欄 第2行
中欄 第2行
右欄 第2行
左欄 第3行
中欄 第3行
右欄 第3行
左欄 第4行
中欄 第4行
右欄 第4行
☝ 同 A，選取行為一致（DOM 順序橫向）

C. CSS columns — Column-based (縱向 DOM 順序)

HTML 結構：扁平 cell 清單，CSS 自動分欄。DOM 順序由上到下，選取縱向流動
第1格（欄1）
第2格（欄1）
第3格（欄1）
第4格（欄1）
第5格（欄2）
第6格（欄2）
第7格（欄2）
第8格（欄2）
第9格（欄3）
第10格（欄3）
第11格（欄3）
第12格（欄3）
☝ 拖曳選取：選取範圍沿 DOM 順序縱向流過欄1，再跳到欄2（Column-wise selection）

D. 三個獨立 div 並排 — Selection Isolation (選取隔離)

HTML 結構：三個完全獨立的 div 容器，選取只能在單一容器內
左欄 第1行
左欄 第2行
左欄 第3行
左欄 第4行
中欄 第1行
中欄 第2行
中欄 第3行
中欄 第4行
右欄 第1行
右欄 第2行
右欄 第3行
右欄 第4行
☝ 可以選取整個左欄（縱向），但跨欄選取仍然依 DOM 順序（左→中→右）流動
