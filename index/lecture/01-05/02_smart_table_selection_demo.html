選取狀態

— 尚未選取 —
（尚未複製）
■ 單格字元選取：mousedown 不攔截（不 preventDefault）， 瀏覽器原生 drag 直接作用在該 cell 的文字節點上。
■ Column-based（同欄跨列）：第一個 mousemove 進入不同 cell 時， 呼叫 e.preventDefault() + removeAllRanges() 接管選取。 對欄內每個 cell 加 .col-sel CSS class（藍色）； 同時 addRange()（Firefox 多段保留；Chrome 僅最後一段，視覺靠 CSS）。
■ Row-based（跨欄）：同樣接管後，依 DOM 順序計算範圍內所有 cell， 加 .row-sel CSS class（橘色）。Copy 時同時寫入兩種格式：
 ・text/html → <table> 結構（貼到 Word/Excel 還原為表格）
 ・text/plain → Tab 分欄 + 換行分列（純文字環境相容）
