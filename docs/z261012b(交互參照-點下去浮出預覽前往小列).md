# 7.5.12.6：點交互參照，浮出「預覽｜前往｜?」小列，不再開選擇對話框

## 現象

設定「交互參照方法」是「每次詢問」時，點註釋、串珠、字典裡的經文位置 (如 `羅5:8`)，會開一個完整的 `DialogHtml` (有標題列、關閉鈕)，裡面只放 3 顆按鈕。只是選一個動作，卻多開一層視窗，又要再關掉。

## 做法

改成在點擊處旁邊浮出一條藍色膠囊列 **預覽｜前往｜?**，跟經文反白後的複製按鈕列 (`LecCopyTable`，表格｜MD｜ASCII｜⚙) 同一種界面：沒有標題列、不搶焦點、按了就消失。

| 檔案 | 內容 |
|------|------|
| `index/RefChooseBar.es2023.js` (新) | `showRefChooseBar(anchor, { onPreview, onGoto, onHelp })`、`closeRefChooseBar()`。同時只有一條；`position: fixed` 放在錨點下方，放不下放上方，左右夾在視窗內 |
| `index/queryReferenceAndShowAtDialogAsync.es2023.js` | `show_dialog_choose_method()` 改呼叫它；錨點是被點的 `.ref` (沒有就用 event.target) |
| `index/fhl.css` | `.ref-choose` 與 `.lec-copy-table` 共用底色 / 圓角 / 陰影，按鈕共用 `.lct-btn`；`.ref-choose .intro-help` 的間距、滑過色、觸控 28px |

收掉的方式：點空白處 (`pointerdown` 捕獲)、Esc、任何捲動、視窗縮放。按鈕按下後先收掉再執行 (`setTimeout 0`)。事件要晚一個 tick 才掛，否則開啟這一下自己的 pointerdown 會把它收掉。

## 命名

原本叫「方法 1／方法 2」，看不出差別。差別在「會不會離開現在讀的位置」，所以：

| 舊 | 新 | 意思 |
|----|----|------|
| 方法 1 (`show_in_dialog`) | **預覽** | 跳出小視窗看經文，讀經位置不動 |
| 方法 2 (`show_in_embed`) | **前往** | 主畫面直接跳到那段經文 |

設定下拉：每次詢問／一律預覽／一律前往 (`ps.reference_method` 仍是 0 / 1 / 2，沒有搬移舊值)。`Settings.es2023.js`、說明對話框、`docs/使用說明.md`、`docs/functional_spec.md` 都已換名。

## 「?」用共用的說明鈕

`?` 用的是共用的 `.intro-help` (搜尋框旁、同源字旁、AI 分頁那顆)：白底圓形、品牌色框與字，大小跟介面字級。不是 `.lct-btn`，所以不會有分隔線，在膠囊裡留了左右空隙。

跟搜尋的 `?` 的差別：搜尋的開 markdown 說明 (`IntroHelp`)；這顆開自己的說明對話框，因為裡面有「固定用哪一種」的下拉。

## 順手修的

說明對話框 (`show_help_dialog`)：

- `</ui>` 筆誤改成 `</ul>`。
- 改下拉後只寫 `pageState.reference_method` (全域，不一定存在)，沒有存檔；現在 `ps.saveToLocalStorage()`。
- 設定面板和說明對話框的下拉**同 id** `#reference_method`，`$('#reference_method')` 永遠抓到設定面板那一個，說明裡的初始值不對。改成 `dlg.find(...)`，並在改值後同步設定面板的下拉。

## 驗證

- 瀏覽器：入口函式帶模擬點擊事件 (經文區沒有 `.ref`，要到串珠 / 註釋分頁才有)，列的位置、顏色、`預覽` 開出小視窗 (標題 `羅5:8`)、`?` 開說明、點空白 / Esc 收掉、「一律前往」不浮出列直接跳且 hash 更新。
- `?` 的計算樣式與搜尋框旁的相同 (背景 / 文字 / 框線色)。
- 還沒在 iPad 實機試過 (觸控大小、點空白收掉)。
- 測試時改過的設定已還原成「每次詢問」。

## 之後

若想讓 `?` 也開 markdown 說明 (`docs/交互參照說明.md`，走 `IntroHelp`)，設定下拉就只剩「設定」面板那一處。
