# 中文標準譯本（csb）詩篇卷首標籤未閉合

7.2.8。讀 csb 詩篇 73 時畫面出現原始 `<i>`、`<h5>`、`<br>`。

## 原因

來源資料（`qb.php?version=csb`）在各卷第一篇（詩 1、42、73、90、107）的 `sec=1` 有一行 `<h3><i>（詩篇73-89【1】`，`<i>` 與 `<h3>` 沒有結尾標籤。`DOMParser` 把後面整篇都放進 `<i>`，而 `getAllDTextsFromAllChildrenNode` 不認得 `<i>`，走到 `else` 用 `outerHTML` 當文字。

注意：進入 `parsingToDOMs` 時換行已被換成 `<br/>`（`cvt_others.js` 的 `\r?\n` → `<br/>`），所以比對要看 `<br/>`。

## 暫時繞過

`index/cvt_others.js` 的 `parsingToDOMs` 開頭：`<h3><i>文字` 後面接 `<br/>` 或換行時，改成 `<h3>文字</h3>`。右括號缺失無從得知原意，不補。
