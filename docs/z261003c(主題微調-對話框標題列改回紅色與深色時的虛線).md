# 主題微調：對話框標題列改回紅色；深色時譯本之間的線看不到

7.2.1 (2026-10-03)。接續 7.2.0 的主題切換 (docs/z261003b)。

## 一、對話框標題列改回紅色

7.2.0 把 jQuery UI blitzer 的紅色漸層標題列改成中性色 (surface2 底 + label 字)。實際用起來：

- 對話框內容與主經文同底色 (`--surface-bg`，本來就是)
- 以前靠紅色標題列一眼看出「這是浮在上面的對話框」；改中性後，對話框跟經文區混在一起

所以改回紅色，但只改 **對話框** 的標題列：

| 選擇器 | 顏色 |
|---|---|
| `.ui-dialog .ui-dialog-titlebar` | 紅 `--dlg-title-bg` + 白字 `--dlg-title-fg` + 框 `--dlg-title-line` |
| 其他 `.ui-widget-header` (tab 列等) | 仍是中性色 |

變數在 `index/theme/theme-vars.css`，規則在 `index/theme/theme-3rd.css`。

### 為什麼不直接用 systemRed

systemRed (#FF3B30) 上的白字只有約 3.5:1，標題字 (粗體、約 14px) 不算「大字」，要 4.5:1。所以混黑：

```css
--dlg-title-bg: color-mix(in srgb, var(--systemRed) var(--dlg-k, 80%), var(--darkText));
--dlg-title-fg: var(--label-dark);   /* 各主題都是白 */
```

- 白字不用 `--fg-on-accent`：高對比深色時那是黑字 (那裡的強調色很亮)，紅底黑字很難看
- 高對比深色的紅更亮 (#FF6961)，混 20% 黑只有 4.25:1 → `--dlg-k: 70%` (hc-dark 與跟隨系統的高對比深色兩處都要設)

| 主題 | 白字對比 |
|---|---|
| 淺色 | 5.24 |
| 深色 | 5.05 |
| 高對比淺色 | 7.60 |
| 高對比深色 | 5.31 |

關閉鈕的紅 X 圖 (`DialogHtml.es2023.js`) 不變，在紅底上仍清楚 (blitzer 原本就是這樣)。

## 二、深色時譯本之間的虛線、搜尋結果的橫線看不到

原本都用 `--line` = Apple 的 `separator`。它是 **半透明** (深色 `#54545899`)，疊在黑底上約 #323234，1px 虛線幾乎看不到。

新增 `--col-line` (不透明)：

| 主題 | 值 |
|---|---|
| 淺色 | systemGray3 #C7C7CC (接近原本的 lightgray) |
| 深色 | systemGray2 #636366 |
| 高對比淺色 | systemGray3 #AEAEB2 |
| 高對比深色 | systemGray2 #7C7C80 |

深色時改 Gray2 寫在 `:root[data-theme$="dark"]` 與 `@media (prefers-color-scheme: dark)` 兩處 (與 `--hl-*` 等深色比例同一區)。

用到的地方 (`index/fhl.css`)：

- 經文區譯本之間的虛線：`#lecMain > .lec-grid .paragraph`、`.vercol`
- 交互參照、搜尋結果 (`.verse-grid`)：左邊虛線、`--vg-line` (每列上方的實線)

其他用 `--line` 的地方 (清單分隔、對話框框線) 底色不是純黑或線比較粗，暫不改；之後若看到深色時哪條線不見，同樣改用 `--col-line` 或 `--line-strong`。
