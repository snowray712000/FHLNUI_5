# 新約原文 韋式 / 聯式：整段一個標籤；括號是 WH 編者的意見

7.1.3 (2026-10-03)。接續 6.3.1 (`index/cvt_others_wu_plus.js` 初版，逐字加標籤)。

## 一、資料

`bible_fhlwh.json.gz` (與 qp.php 的 `word`) 中，新約異文寫成 3 個 `+` 一組：

```
… ἀνθρώποις<WG444> + (τὰ<WG3588> παραπτώματα<WG3900> αὐτῶν<WG846>) + +, …   (太6:15)
```

- 第 1、2 個 `+` 之間是 **韋式** (Westcott-Hort, WH 1881)，第 2、3 個之間是 **聯式** (UBS)
- 某一邊可能是空的 (上例聯式是空的)
- 一節可能有好幾組 (太1:9 跨兩行就有 2 組)，所以標籤是「每組各自」，不是一節一個
- `+` 數量不是 3 的倍數時 (路24:3) 只移除 `+`，不標

## 二、顯示：整段一個標籤

| | 太6:15 |
|---|---|
| 舊 (6.3.1) | `(韋：(τὰ) (韋：παραπτώματα) (韋：αὐτῶν))` |
| 新 (7.1.3) | `(韋：(τὰ παραπτώματα αὐτῶν))` |

逐字標籤讀起來像三個獨立的異文，其實是同一段。

### 經文區 `index/cvt_others_wu_plus.js`

仍是 2 步 (中間 `attach_sn_text` 要綁 sn-text，先加標籤會干擾它)：

1. `split_wu_plus`：移除 `+`，組內 DText 以空白斷開並標 `wu: 'w' | 'u'`。**組內的空白也標 wu** (舊版不標，第 2 步就只能逐字)
2. `add_wu_label`：連續、同 wu 的 DText 視為一段，前後加 `(韋：` `)`
   - 頭尾的空白 DText (以及 sn-text 頭尾帶的空白，例 `" Ἀχάς"`) 放在標籤外，並去掉 wu (不上色)
   - 換行 (`isBr`) 斷開，跨行的一段會變成兩個標籤 (目前資料沒看到)
   - 段內字與字之間的空白也上色 (`.greek_w` / `.greek_u`)，看起來是一整段
   - 同一組的韋式後面緊接聯式時，wu 不同就自然分開；兩組之間至少隔著第 3、第 1 個 `+`，不會出現兩段同 wu 相連

### 原文分析分頁 `index/parsing_render_top.es2023.js`

`do_about_plus_symbolic`：每個字仍是自己的 `span[wid].sn-btn` (點了要看該字分析)，所以標籤不另開 span (否則會被加上 `sn-btn`)，而是 `(韋：` 加在段內第一個 span 的文字前、`)` 加在最後一個 span 後；每個 span 各自上底色 (#ffff99 / #ffcccc)。

`method_1` (record 數對不上時的備案) 本來就是整段 `(韋： …)`，沒改。

## 三、括號 ( ) 保留：不是 bug，是 WH 編者的意見

問題：`(韋：(τὰ παραπτώματα αὐτῶν))` 有兩層括號，要不要拿掉資料的那層？

- 古抄本沒有括號 (早期大楷抄本連字間空格都沒有，標點極少)，括號是印刷版編者加的
- WH 印刷版：`[ ]` = 編者認為可疑；`[[ ]]` = 很可能不是原文但保留
- 信望愛資料裡沒有任何 `[ ]`，換成了 `( )`：
  - 路22:43、約7:53 是 `((` → 對應 WH `[[`
  - 太6:1 `(δὲ)`、太18:19 `(ἀμὴν)` → WH `[ ]`
- 共 741 節有括號，其中 48 節在 `+ + +` 之外

決定 (2026-10-03，與使用者討論)：**保留**。它雖不在抄本裡，但是編者的判斷，像一條很短的註腳；拿掉還會讓韋式、聯式看起來一樣，例 太1:18 `+ (Ἰησοῦ) + Ἰησοῦ +` → `(韋：Ἰησοῦ) (聯：Ἰησοῦ)`，看不出差在哪。
