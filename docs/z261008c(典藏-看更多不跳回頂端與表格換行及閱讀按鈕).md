# 典藏：看更多不跳回頂端、表格換行與閱讀按鈕 (7.2.7)

## 1. 卡片「看更多」捲動跳回頂端

- 原因：`.ob_more` 的 click 呼叫 `#setState`，`#paintNow` 用 `this.dom.html(this.#html())` 整頁重畫，捲動位置歸零。
- 作法：只改 `state.expanded_id`，再 `this.dom.find('.ob_results').html(this.#html_results())` 局部重畫（與 `#paintListPart` 同一思路）。展開狀態只影響清單，不需要整頁重畫。
- 之後新增只影響清單的互動，也請用局部重畫，不要走 `#setState`。

## 2. 表格大字時看不到「閱讀」、要水平捲軸

- `.ob_table td:first-child, td:last-child` 原本都 `white-space: nowrap`，大字時撐出水平捲軸，最右邊的「閱讀」被擠出畫面。
- 現在：所有 `th/td` 加 `overflow-wrap: anywhere`（自動換行）；只有最後一欄（閱讀按鈕）維持 `nowrap`，年代欄也可換行。

## 3. 只有「閱讀」按鈕能開書

- 原本整列 `tr.ob_row[data-read-id]` 可點，使用者想框選複製表格文字時會誤開書。
- 現在 `data-read-id` 只在最後一欄的 `<button class="ob_read_btn">`（與卡片同一個樣式）；`tr` 不可點、移除 `.ob_row` 的 `cursor: pointer` 與 `td.list_item_read` 樣式。
- 卡片標題 `.ob_card_title[data-read-id]` 不變，仍可點。

## 4. 表格欄寬可拖、雙擊回自動寬度

- 表頭前四欄右緣有把手（沿用 `.lec-col-handle` 小方塊，`.ob_colgrip`；最後一欄是閱讀按鈕，不放）。
- 第一次拖時，把 5 欄目前寬度量成 px 寫進 `<colgroup>` 的 `<col>`，table 加 `.ob_fixed`（`table-layout: fixed`），之後只改被拖的那一欄（最小 40px）。
- 放開後記在 localStorage `fhlObColW`（5 個 px 的陣列），重畫表格時由 `readColWidths()` 還原。
- 雙擊任一把手：清掉紀錄、拿掉 `.ob_fixed`，全部欄回到自動寬度（不是只重置單欄）。
- 已用預覽驗證：拖 60px → 書名欄 149→209，其餘不動；雙擊回 149，localStorage 清除。
