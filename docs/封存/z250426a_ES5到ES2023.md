## ✅ ES 年代表與重大變更

| 年份 | 版本 | 重點 |
|------|------|------|
| 2009 | **ES5** | 還是傳統 JS：`strict mode`, `JSON`, `Array.forEach` |
| 2015 | **ES6 (ES2015)** | *革命性更新*：`let`, `const`, `class`, `arrow function`, `Promise`, `import/export` |
| 2016 | **ES7 (ES2016)** | `Array.includes()`、`**` 次方運算子 |
| 2017 | **ES8 (ES2017)** | `async/await`, `Object.entries()`, `Object.values()` |
| 2018 | **ES9 (ES2018)** | `Rest/Spread`, `Promise.finally()`, `async generator` |
| 2019 | **ES10 (ES2019)** | `Array.flat()`, `trimStart/End`, `Object.fromEntries()` |
| 2020 | **ES11 (ES2020)** | `optional chaining (?.)`, `nullish coalescing (??)`, `Promise.allSettled()` |
| 2021 | **ES12 (ES2021)** | `String.replaceAll()`, `Logical assignment (??=, ||=)`, `WeakRef` |
| 2022 | **ES13 (ES2022)** | `class fields`, `static block`, `top-level await`, `Object.hasOwn()` |
| 2023 | **ES14 (ES2023)** | `Array.prototype.toSorted()`, `toReversed()`, `findLast()`, `Symbol.asWeakMapKey` |

## 🆕 常見新語法與特性總覽

### 🌱 基本語法
- `let`, `const`（區塊作用域）
- `=>` arrow function
- 模組：`import/export`

### 🌟 語法糖
- `class`、`constructor`, `extends`
- `async/await`
- 解構：`const {a, b} = obj`

### 🔗 鏈式操作
- `obj?.prop` → optional chaining
- `x ?? y` → nullish 合併
- `arr?.[0]` → 安全存取陣列

### 🧹 陣列與物件
- `arr.includes(x)`
- `arr.flat()`
- `Object.entries(obj)` / `Object.fromEntries()`

### 🧠 模組與異步
- `import`, `export`
- `Promise.allSettled()`, `Promise.finally()`
- `top-level await`（script module 中直接 await）

# json取得

- fetch 函式取得
- 可結合 async/await 使用
- 若有 .json.gz ， 可用 pako 解壓 (client 端解)

```js
import pako from 'https://cdn.jsdelivr.net/npm/pako@2.1.0/dist/pako.min.js';

const res = await fetch('./data.json.gz');
const arrayBuffer = await res.arrayBuffer();
const decompressed = pako.ungzip(new Uint8Array(arrayBuffer), { to: 'string' });
const data = JSON.parse(decompressed);
```

# api呼叫

- 不再使用 jQuery 的 ajax
- 使用 fetch 函式
- 可結合 async/await 使用

```js
async function callAPI() {
  try {
    const res = await fetch('/json/sc.php?xxx=ooo');
    if (!res.ok) throw new Error('API 錯誤');

    const data = await res.json(); // 自動把 JSON 轉成物件
    console.log(data);
  } catch (err) {
    console.error('呼叫失敗', err);
  }
}

callAPI();

```
# jQuery 取代方案？

- 因為 jQuery 語法，不是使用 export/import ，所以沒辦法直接 import。
- 但非官方的可以，`import $ from 'https://esm.sh/jquery'`
- `Cash.js` 可取代 jQuery，語法幾乎一樣，但輕量化很多，只有 10kB。 少了 `動畫效果` `ajax` 。 主要就是有 DOM 操作功能。
