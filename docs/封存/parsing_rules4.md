這份 `full_texts3.txt`（涵蓋大量舊約歷史書與智慧文學，如約伯記）帶來了幾個非常重要的**新結構特徵**，特別是「羅馬數字」的出現，這是在之前的書卷中未見的。

以下是針對這份新資料的**驗證與規則更新 (Ver 4.0)**：

### 驗證與發現摘要

1. **羅馬數字 (Roman Numerals) 的出現**：
* **發現**：在《約伯記》中，出現了 `I. 散文體的序言`、`II. 詩體對話`、`III. 散文體的結語`。
* **分析**：這是非常高層級的標題，地位相當於或略低於 `一、`，但高於 `A.`。
* **修正**：必須將羅馬數字（I, II, III, IV...）加入 `Type A` 的層級定義中。


2. **短橫線清單 (Dash List Items)**：
* **發現**：在《以斯拉記》與《尼希米記》的列表部分（如人口統計、名單），使用了 `- ` 作為項目符號。
* **分析**：這是一種非正式的 `Type B`（無序列表），通常用於列舉名詞，層級較低。
* **修正**：將 `^\s*-\s+` 加入 `Type B` 規則。


3. **「第 X 回合」結構**：
* **發現**：在《約伯記》的辯論段落中，出現了 `第一回合`、`第二回合`、`第三回合`。
* **分析**：這不屬於標準的「第一、」（Type A），也不完全是「隱性鍵值」（Type C），它更像是一種**「敘事分段標題」**。
* **修正**：應視為 `Type A` 的變體，正則表達式需擴充以捕捉 `^第[一二三四五六七八九十]+(回合|次|輪)`。


4. **方括號標題 (Square Bracket Headers)**：
* **發現**：在《以斯帖記》中出現 `[參考資料]`。
* **分析**：這是一種元數據（Metadata）區塊的標記。
* **修正**：歸類為 `Type B`（標記項目）或獨立的 Meta 類型。

以下是更新後的 **Parsing Rules (Ver 4.0)**。

### 檔案：parsing_rules4.md (Ver 4.0)

這份文件記錄了處理中文聖經研經資料（Legacy Text）的解析邏輯，包含舊約歷史書與智慧文學的特殊格式。

#### 1. 行類型定義 (Line Types)

程式讀取每一行時，應優先判斷該行屬於哪種類型，並依據 **權重 (Weight)** 決定層級：

* **Type A: 明確層級 (Explicit Hierarchy)**
* 特徵：以「有序符號」開頭。
* **通用權重順序 (Hierarchy Weight)**：
* `10` : `^零、|^壹、|^貳、...` (大寫數字)
* `20` : `^一、|^二、|^三、...` (中文數字)
* `25` : `^第[一二三四五六七八九十]+(回合|次|輪)` (敘事分段) **[NEW]**
* `30` : `^（[一二三四五六七八九十]+）` (括號中文數字)
* `35` : `^\s*[IVX]+\.` (羅馬數字, 如 `I.`, `II.`) **[NEW]**
* `40` : `^\s*[A-Z]\.` (大寫字母, 如 `A.`)
* `50` : `^\s*\d+\.` (阿拉伯數字, 如 `1.`)
* `60` : `^\s*\([A-Z]\)` (括號大寫字母, 如 `(A)`)
* `70` : `^\s*\(\d+\)` (括號數字, 如 `(1)`)
* `80` : `^\s*[a-z]\.` (小寫字母, 如 `a.`)
* `90` : `^\s*\([a-z]\)` (括號小寫字母, 如 `(a)`)




* **Type B: 標記項目 (Symbol Item)**
* 特徵：以「無序符號」開頭。
* 符號與行為：
* `●`, `◎`, `○`, `☆`, `★` : 標準無序項目。
* `^\s*-\s+` : 短橫線清單 (Dash List)。 **[NEW]**
* `^\[.*\]` : 方括號標題 (如 `[參考資料]`)。 **[NEW]**


* 層級策略：
* 預設為 **Leaf Node (葉節點)**。
* 若 `Type B` 之後緊接著縮排更深的 `Type A` (如 `●` 下面有 `1.`)，則該 `Type B` 升級為 **Container Node**。




* **Type C: 隱性鍵值 (Implicit Key-Value)**
* 特徵：`^\s*(時間|地點|人物|原因|特徵|背景|作者|受書人|寫作目的|主題|經文|結論)：`
* 行為：視為 list item，內容包含 Key 與 Value。


* **Type D: 表格區塊 (Table Block)**
* 特徵：包含 `┌`, `─`, `│`, `└`, `├`, `┤`。
* 解析：保留原始排版 (Preformatted)。


* **Type E: 延續內文 (Content Continuation)**
* 特徵：非上述類型。
* 處理：
* **合併 (Concat)**：若縮排 >= 上一層級。
* **新段落**：若縮排明顯少於上一層級且無法歸類，視為 Sibling Text。





#### 2. 關鍵解析邏輯更新

1. **羅馬數字處理**：
* Regex: `^\s*(?=[IVX])M*(C[MD]|D?C{0,3})(X[CL]|L?X{0,3})(I[XV]|V?I{0,3})\.`
* 邏輯：因為 `I.` 可能被誤判為英文字母 `I.`，需確保 Regex 嚴格匹配羅馬數字格式（或者簡單地匹配 `^[IVX]+\.` 且排除常見單字）。鑑於資料特性，簡單的 `^[IVX]+\.` 通常足夠。


2. **短橫線 (Dash) 處理**：
* 必須強制要求 `-` 後面有空白 (`- `)，以避免將連字號或負號誤判為清單。


3. **同級判斷 (Sibling Detection)**：
* 在《約伯記》中，`第一回合`、`第二回合` 之間夾雜了大量的對話內容。
* Parser 必須能「跨越」中間的對話內容，識別出 `第二回合` 是 `第一回合` 的 Sibling，而不是 Child。這依賴於 **Weight 比較**（25 vs 25 -> Pop & Push）。



#### 3. Regex 參考更新

* `Re_Lvl_Roman`: `^\s*[IVX]+\.`
* `Re_Lvl_Round`: `^\s*第[一二三四五六七八九十]+(回合|次|輪)`
* `Re_Type_B_Dash`: `^\s*-\s+`
* `Re_Type_B_Bracket`: `^\s*\[.*\]`
