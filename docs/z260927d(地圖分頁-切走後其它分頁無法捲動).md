# 地圖分頁：切走後其它分頁無法捲動（6.8.3）

## 現象

切到「地圖」，再切回其它分頁（例如註釋），內容很長，卻無法用滑鼠滾輪／觸控板往下捲。

## 原因

`static/fhlmap_api/fhlmap_main.js` 的 `fhlmap_render` 原本直接拿 `#fhlInfoContent`（右側內容區，所有分頁共用）當 leaflet 的 map container：

```js
rfhlmap = generateMap(document.getElementById("fhlInfoContent"))
```

`L.map(dom)` 會對那個 dom：

- 加上 class `leaflet-container leaflet-touch leaflet-grab …`（`touch-action: none`、`cursor: grab`）
- 綁 `wheel` 事件（scrollWheelZoom），裡面 `preventDefault()` —— 滾輪不會捲動
- 綁拖曳、觸控等事件

切到別的分頁時，那個分頁只換掉 `#fhlInfoContent` 的內容，**容器本身的 class 與事件都還在**。
原本只有「再切回地圖」時才 `rfhlmap.remove()`，而 leaflet 1.3.4 的 `remove()` 也不會把 container 的 class 拿掉。

## 修改

1. 地圖改建在子 div：`#fhlInfoContent > #fhlmapContainer`（`width:100%; height:100%`），leaflet 只動到子 div。
2. 新增 `fhlmap_dispose()`（`fhlmap_main.js`）：`rfhlmap.remove()`、`rfhlmap = null`、清 `markersLast`、移除 `#fhlmapContainer`。
3. `FhlInfoContent.render()` 開頭：若 `fhlmap_titleId_prev === "fhlInfoMap"` 且這次不是地圖，先 `fhlmap_dispose()`。
   再切回地圖時，`rfhlmap == null` 會重建 map，`fhlmap_chap_prev = -1` 讓標記重新載入。

`fhlmap_render`、`fhlmap_dispose`、`fhlmap_titleId_prev` 都是 classic script 的全域，ES module 直接用。

## 驗證方式

1. 地圖分頁：地圖大小與以前相同，圖磚正常。
2. 切到註釋：`#fhlInfoContent` 的 className 為空、`touch-action` 為 `auto`，對它 dispatch `wheel` 事件 `defaultPrevented === false`，實際滾輪可捲動。
3. 再切回地圖：重建成功，頁面上只有 1 個 `.leaflet-container`，console 無錯誤。

## 教訓

第三方元件（leaflet、編輯器、圖表…）不要直接掛在多個分頁共用的容器上，給它一個自己的子 div，切走時整個拿掉。
