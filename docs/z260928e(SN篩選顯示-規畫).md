# SN 篩選顯示 — 規畫

app_versions 的 todo：「關閉 SN 時，卻強制 SN 顯示某些指定的，例如 G1063」。

SN 全開太雜，全關又可惜。研讀時真正想要的是「只看某一類字」：

- 只看某個 SN (G1063 γάρ)
- 所有連接詞，**包含和合本沒翻出來的**
- 動詞；只看限定動詞 (非分詞、非不定詞)；只看不定詞
- 只看實詞：名詞、形容詞、動詞

分支：`sn-filter`。

## 已有的資料 (決定能做到哪)

1. **SN 本來就都在 DOM 裡**。關閉 SN 只是 `.sn` 加 `.sn-hidden` (現在的資料一律帶 SN)。所以篩選 = 決定每個 `.sn` 要不要加 `.sn-hidden`，不必重新要資料。
2. **和合本 / KJV 的 qsb 資料比畫面上看到的多**，約1:12：
   `凡接待<WG2983><WTG5656>他<WG846>的{<WG1161>}{<WG3745>}…`
   - `{<WG1161>}` 大括號 = 沒翻出來的字 (DText `isCurly`，DOM `.isCurly`)
   - `<WTG5656>` = 該動詞的時態語態語氣碼 (5656 簡單過去主動直說，5723 現在主動分詞，5664 不定詞)；舊約 `<WTH8804>` (Qal 完成式)。**逐字的，不必對齊**
   - `<WAH09002>` 之類 (WA, ≥ 9000) 是標記，不是字
   - 和修本 (rcuv) 只有舊約有 SN
3. 原文 fhlwh / bhs 只嵌 SN，沒有形態。`bible_parsing.db` 有：
   - 新約 `pro` 詞性碼 (n v c p a ra rp rd rr ri rf t d …)，`wform` 形態碼 (`papdpm` = 時態 p、語態 a、語氣 p、格數性)。語氣：i 直說 s 假設 o 祈願 d 命令 n 不定詞 p 分詞；時態：p 現在 i 未完成 f 未來 a/b 簡單過去 x 完成 y 過去完成
   - 舊約 `wform` 是中文描述：「動詞，Qal 敘述式 3 單陽」「連接詞 ו + 受詞記號」，可用規則解出詞幹 (Qal Nif‘al Pi‘el Pu‘al Hif‘il Hof‘al Hitpa‘el，亞蘭文 Peal…) 與形式 (完成式 未完成式 敘述式 連續式 祈使式 祈願式 鼓勵式 不定詞附屬形/獨立形 主動/被動分詞)
4. **舊約 ו (waw) 沒有自己的 SN**，是字首。和合本的「舊約所有連接詞」不可能含 waw (已接受此限制)；原文可由形態資料看到。
5. 七十士譯本 SN 是推的，無形態，只能用 L1 L2。SN 是 G，依新約 (希臘文) 設定篩選。

## 預設組合 (語言學家角度，可多選，聯集)

**新約**：論述標記 (c + t，含未譯出：δέ γάρ οὖν ἀλλά διό ὥστε)、限定動詞、分詞、不定詞、命令語氣、完成時態、被動語態、實詞 (名形動)、參與者 (代名詞)、介系詞、否定。

**舊約**：敘事主線 (敘述式 wayyiqtol)、背景 (完成式、分詞)、連續式 (weqatal：律法、預言)、意志式 (祈使 祈願 鼓勵)、不定詞獨立形 (加強)、詞幹、功能詞 (כִּי אִם אֲשֶׁר 否定；受詞記號 853 預設排除)、神的名字 (3068 430 136)、亞蘭文。

**共通**：本章主導詞 (Leitwort，本章出現 ≥ N 次且非功能詞，用 `Sn_cnt_chap`)、本書罕見字、研讀集 (字典裡按 📌 累積)。

## 決定 (2026-09-28)

1. 不符合的 SN：預設**隱藏**，選項可改**變淡**
2. 套用範圍**全部一致**：主經文、交互參照對話框、搜尋結果。註釋裡的 SN 是作者寫的內容，不篩
3. 舊約 waw 在和合本無法顯示，接受
4. 設定存 localStorage (`snFilter`)，不放網址
5. 設定介面是一個 dialog (`SnFilterDialog`)

## 規則模型

```js
SnFilter.s = {
  isOn: false,               // 篩選 (ps.strong == 1 時才有作用；ps.strong == 0 就是關)
  hideMethod: 'hide',        // 'hide' | 'dim'
  nt: { sns: ['1063'], includeCurly: true, showTvm: true },   // P2 起加 presets, exclude
  ot: { sns: ['3068'], includeCurly: true, showTvm: true },
}
```

模式：`ps.strong == 0` → 關；`isOn` → 篩選；否則全部。

判斷：WA 標記 / ≥ 9000 → 不顯示；未譯出且 `includeCurly` 為否 → 不顯示；SN 在清單 → 顯示。
時態碼 `(5656)` 跟著它前面的字：前一個字顯示且 `showTvm` 才顯示。
搜尋結果中被搜尋的 SN (`.seKey`) 一律顯示。

## P2 實作 (字典詞性、預設組合)

- `tools/gen_sn_pos.mjs` (`npm run gen:snpos`) → `index/sn_pos.json.gz` (約 38 KB，`Sn_pos_json` 載入，沿用 `BaseJson`)。新約 5411、舊約 8559 個 SN
  - 新約：`pro` 對應詞性；`n` 且原型大寫開頭 → 專有名詞；οὐ μή 等另標 `neg`
  - 舊約：`wform` 以 `+` 分段，去掉「詞尾」與「冠詞 / 定冠詞」段 (希伯來文冠詞是字首，**亞蘭文冠詞是字尾**「名詞，陽性單數 + 定冠詞」)，取最後一段；去掉「…的停頓型，」、「按讀型，它是」再看開頭的詞類。指示詞、疑問詞算代名詞
  - 一個 SN 佔 ≥ 10% 的詞性都列 (`"d|neg"`)，篩選時符合任一就算。多詞性約 166 個 (H2088 זֶה 代名詞/形容詞、H176 אוֹ 質詞/連接詞…)
  - 對不到的約 180 字 (零星描述)，另有 3126 個「段落符號」是 9014/9015 標記。報告 `tools/.cache/gen_sn_pos_report.txt`
- 每個約多了 `presets`、`exclude`、`leitwort`：
  - 預設組合 (`SN_PRESETS`)：實詞、動詞、名詞、專有名詞、形容詞 (含數詞)、連接詞 (含質詞)、代名詞 (含關係)、介系詞、副詞、否定、冠詞 (只新約)、受詞記號 (只舊約)、神的名字 (列 SN)
  - 本章主導詞：正在讀的這一章在**和合本**出現 ≥ N 次的實詞 (`Sn_cnt_chap_unv_json`)。約1 ≥ 4 次：道、光、見證、恩典、基督、施洗、約翰…；εἰμί λέγω 這類常用字也會進來，用排除拿掉。搜尋結果也以正在讀的那章計
  - 排除優先於一切 (搜尋的 SN 除外)
- 用到預設組合或主導詞時才載入這兩個檔；載好前只有 SN 清單有作用，載好後 `applyAll` 再套一次

## P3 實作 (逐字的動詞形態)

資料 (都是用到才載入)：

- `tools/gen_sn_morph.mjs` (`npm run gen:snmorph`) → `index/sn_morph_nt.json.gz` (92 KB，28517 字)、`sn_morph_ot.json.gz` (240 KB，73428 字)。只有動詞，`{"43.1.12": "2983:aai 1325:aai 1096:amn 4100:pap"}`
  - 新約：`wform` 前三碼正規化為 時態 語態 語氣。原資料時態 `b` 第二簡單過去→a、`g` 第二未來→f、`c` `d` 第二完成/完成被動→x、`e` 亞蘭文無時態 (略過)；語態 `n` 中間異態→m、`o` 被動異態→p；語氣 `d` 是命令
  - 舊約：「動詞，Qal 敘述式 3 單陽」→ `q:wy`。詞幹寫法很亂 (`Qall`、`Hif'l`、`Hophal`、「Hif‘il敘述式」沒空白)，比字首；「動詞 ，」多空白、「未完成」少「式」也要容忍。Polel、Peal (亞蘭文) 等歸「其它」。對不到 41 字
- `tools/gen_tvm_table.mjs` (`npm run gen:tvm`) → `index/tvm_table.json` (3.6 KB)：和合本時態碼 → 形態代碼
  - 下載和合本全文 (含 SN，1189 章，快取 `tools/.cache/unv_qsb.json`)，同一節某 SN 在和合本 (帶時態碼) 與 parsing 都只出現一次時記一票，取佔 ≥ 1% 的。81495 票
  - 新約幾乎一對一 (5723 → pap 2259 票全中)；舊約 Strong's 時態碼**不分敘述式/未完成式 (8799)、連續式/完成式 (8804)**，所以一個碼對到幾個代碼
  - 不用外部的時態碼表，也就沒有授權問題；KJV 的碼有時不同 (5627)，表中沒有就退回同節對應

對應方式 (`SnFilter.#isMorphMatch`)：

1. 節的位址：主經文 `.lec[book][chap][sec]` (逐節產生時由 `add_sn_hidden_if_need` 傳 `opt.addr`)、搜尋結果 `.sd-text-row[data-vaddr][data-ver]`、交互參照對話框節號 `.ref[data-vaddr]` (`prepare_dtexts_for_html` 的 `vaddr`)
2. 同節同 SN 的候選代碼。原文譯本 (fhlwh bhs) 第 n 次出現對第 n 個；和合本此 SN 次數與原文相同時也依順序 (翻譯大致保留語序，例 創1:5 兩個「稱」：敘述式、完成式)，否則全部候選
3. 和合本字後面有時態碼時，候選與 `tvm_table` 取交集 (空的就用表)。例 約1:15 parsing 有 3 個 λέγω、和合本 2 個，次數不同，靠 5723 才知道「說」是分詞
4. 同一組 (語氣) 勾多個是任一、不同組 (語氣、時態) 都要符合，例「分詞 + 現在」= 現在分詞。與詞類、主導詞、另外加的 SN 是聯集

限制：和合本同一節同一動詞多次、次數又與原文不同、時態碼也分不出時 (舊約 8799 敘述式/祈願式)，會多顯示。
