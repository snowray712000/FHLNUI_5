# 工具列合成一列 (260930)

## 緣由

原本上方有兩列，寬螢幕約 100px、手機約 140px：

1. 標題列 `nav#fhlTopMenu`：logo、信望愛聖經工具、版本號 + 手動更新、「讀經 教學 查詢 工具 專欄 連結 義工」選單、問題回報
2. 工具列 `#fhlToolBar` (在 `#mainWindow` 內)：?、視窗按鈕 (選擇譯本、左側、右側、全螢幕)、書卷章、搜尋

問題：

- 那 7 組選單平常 `opacity: 0`，滑鼠滑過才出現，展開時剛好擋住下面的功能
- 視窗按鈕用扳手、文件 icon，看不出是開關左右側欄；窄時還有一套 JS (`chnageControlsMaxWidthInToolbar`、`fitSearchToolWhenNarrow`) 在算寬度、改標題文字
- 選擇譯本的按鈕和點經文上方譯本名稱重複

## 現在

一列 44px (`--tb-h`)，`nav#fhlTopMenu > div#fhlToolBar` (flex)：

```
≡  logo 信望愛聖經工具 v6.11.11 ⟳ | 創世記：第一章 ▼ | [搜尋] ▦ ? ⛶ ✉ ▥
```

| 元素 | 說明 |
|---|---|
| `#fhlLeftWindowControl` ≡ | 左側欄開關 (id 沿用，事件仍在 `WindowControl`，`.selected` = 開著) |
| `#fhlInfoWindowControl` ▥ | 右側欄開關 (`bi-layout-sidebar-inset-reverse`) |
| `#title` | `.t-full` 信望愛聖經工具 / `.t-short` 聖經工具，由 css 切換；簡繁由 `TopBar.setTitle(gb)` |
| `#appVerNum` | 版本號，點了開版本變更 dialog (`indexLast.js` 的 `addVersionInfosDialog`) |
| `#force-reload` ⟳ | `checkHtmlVersion` 加入 `#appVer`；已最新只顯示 icon，有新版 `.has-new-ver` 顯示「更新至 x」(⋮ 上也有橘點) |
| `#resourcesMenuBtn` ▦ | 開 `#resourcesPanel`，原本 7 組連結 (骨架裡的 `<section><h4>`)，**點了才開**，`#tbBackdrop` 點外面或 Esc 關 |
| `#help` ? | 使用說明 (原本 `#help::after` 畫 ?，`indexLast` 的 `removeHelpText` 已移除) |
| `#fullscreenControl` | 全螢幕 |
| `#problemsReport` ✉ | mailto 由 `TopBar.setReportHref` 設 (⋮ 裡的也一起) |
| `#moreMenuBtn` ⋮ | 窄時才出現，`#moreMenu` 放 ▦ ? ⛶ ✉ 版本變更 手動更新，各項是去 trigger 上面那些按鈕 |
| `#searchToggle` 🔍 | 最窄時才出現，按了加 `.search-open`，搜尋框蓋住整列；focusout 收回。`SearchTool.focus()` (Alt+Shift+F) 也會先展開 |

寬窄全交給 `fhl.css` 的 @media，不再用 JS：

- ≤ 1000px：標題縮成「聖經工具」
- ≤ 760px：`.tb-wide` (▦ ? ⛶ ✉) 與版本號收進 ⋮
- ≤ 560px：只剩 logo；書卷章用縮寫 (`BookSelect` 輸出 `.bs-full` / `.bs-short`，例「創 1」)；搜尋收成 🔍

## 連帶修改

- `#mainWindow` top 用 `--tb-h`，左中右三個視窗 top 用 `--win-top` (8px)。`windowAdjust` 改成清掉 inline top 回到 css 值 (全螢幕時 `requestFullscreen` 設 0)
- `coreInfoWindowShowHide` 不再管工具列 (rc4、高度 2 行、改標題、算按鈕寬度都拿掉)
- `#versionSelect3` 移除；`FhlLecture` 點譯本名稱改 trigger 左側的 `#versionSelect2` (左側欄隱藏也可以)
- `#windowControl`、`#windowControlIcon` 移除

## 已知 (原本就如此)

手機上右側欄寬度會設成整個畫面，會蓋住左側欄與經文；要看經文得先按 ▥ 收起右側欄。
