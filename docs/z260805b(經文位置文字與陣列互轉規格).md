# 經文位置：文字描述 ↔ 節陣列 互轉規格

> 本文件整理自 FHLNUI 專案（信望愛聖經工具）現有實作，目的是提供給另一個專案的 AI 助理，
> 依照相同邏輯以 **TDD** 方式重新開發同等功能。文件包含：資料型別說明、核心演算法完整原始碼、
> 依賴的輔助函數、以及可直接轉譯為測試案例的 input/output 範例。

## 0. 背景：兩種經文位置表示法

本專案中，經文位置有兩種表示法：

1. **文字描述**（人類可讀），例如：
   - `"創1:2-3;12-32;出2:3"`
   - `"太 1:1-2;創 2:3"`
   - `"31:12-15,18,19-31"`（省略書卷名，沿用預設書卷）
2. **節陣列**（程式內部使用），例如：
   - `[{book:1,chap:1,verse:2}, {book:1,chap:1,verse:3}, ...]`

專案中負責「文字 → 陣列」與「陣列 → 文字」互轉的邏輯，其實有**兩套並存的實作**：

| | 文字 → 陣列 | 陣列 → 文字 | 特色 |
|---|---|---|---|
| **新式（本文件主體）** | `ParsingReferenceDescription` + `GetAddresses` | `VerseRange` + `VerseRangeToString` | 邏輯較嚴謹、有清楚對應的 QUnit 測試檔，適合作為重構藍本 |
| 舊式（僅附錄簡述） | `splitReference` | `cvtAddrsToRef` | 用途略有不同（見附錄），以正則/狀態機為主，測試案例對「合併連續節/章」規則涵蓋較完整，可交叉參考 |

**本文件以新式（`ParsingReferenceDescription` / `GetAddresses` / `VerseRange` / `VerseRangeToString`）為主要重構依據。**

## 1. 資料型別 `DAddress`

專案中對「一節經文的位置」有多種欄位命名，**並不統一**。原始碼作者在 `index/DText.js` 中對此有自白：

```js
/**
 * @typedef {Object} DAddressObject
 * @property {number} [book] 1-based book id
 * @property {number} [chap] 1-based chap number
 * @property {number} [verse] 1-based sec number ... 有的部分是用 verse，有的地方是用 sec。沒有統一，很抱歉。
 */

/**
 * @typedef {Array<number>} DAddressArray 例如 [1,1,1]，皆為 1-based
 */

/**
 * @typedef {DAddressObject | DAddressArray} DAddress
 * 若是 object 就是 {book:1, chap:1, verse:1}；
 * 若是 Array<number> 就是 [1,1,1]；皆為 1based。
 */
```

實際出現過的變體：

| 變體 | 出現位置 | 說明 |
|---|---|---|
| `{book, chap, verse}` | `ParsingReferenceDescription.js`、`GetAddresses.js`、`VerseRange.js`、`VerseRangeToString.js` — **本文件核心 pipeline 全採此形式** | 主流命名，1-based |
| `{bookIndex, chap, sec}` | 呼叫端，例如 `index/hash_change_on_initial.js`（`splitReference(str, { book: ps.bookIndex, chap: ps.chap, sec: ps.sec })`）、`TPPageState.s` | 頁面全域狀態使用的命名 |
| `[book, chap, verse]`（純陣列） | `BibleConstantHelper.getNextAddress()` 支援此形式作為輸入/輸出 | 陣列形式，皆 1-based |

`BibleConstantHelper.getNextAddress` 對物件形式的相容處理，可看出 `sec` 是 `verse` 的別名：

```js
static getNextAddress(address, isStopAtBookEnd = false) {
    if (false == Array.isArray(address)) {
        address = [address.book ?? 1, address.chap ?? 1, address?.verse ?? address?.sec ?? 1]
    }
    // ...
}
```

**新專案重構時，欄位命名可自行決定**（例如統一用 `book/chap/verse`），但務必在對外 API 邊界明確定義，避免重蹈「有的用 verse，有的用 sec」的歷史包袱。

書卷 ID（`book`）為 **1-based，範圍 1~66**（創世記=1 ... 啟示錄=66）。

## 2. 文字 → 陣列：`ParsingReferenceDescription` + `GetAddresses`

### 2.1 整體流程

```
"太 1:1-2;創 2:3"
   │  ParsingReferenceDescription.main()
   │    1. 把字串中的 '.' 換成 ';'
   │    2. splitBook2(): 依書卷名稱切成多段 [{id:書卷ID, des:"該書卷內的描述文字（含書卷名本身）"}]
   │    3. 對每段：SmartDescriptEndParsing 修飾描述尾部 → getAddressesOneBook()
   │         getAddressesOneBook(): 以 ';' 再切分該書卷內的多段描述
   │           對每小段呼叫 GetAddresses(bookId).main({idbook, descript})
   │    4. 驗證所有產出的 {book,chap,verse} 都在合法範圍內；只要有一個不合法，整體回傳 []
   ▼
[{book,chap,verse}, ...]
```

### 2.2 `ParsingReferenceDescription`（完整原始碼）

```js
import { BibleConstantHelper } from "./BibleConstantHelper.es2023.js";
import { SmartDescriptEndParsing } from "./SmartDescriptEndParsing.js";
import { splitStringByRegex } from "./splitStringByRegex.es2023.js";
import { GetAddresses } from "./GetAddresses.js";
import { assert } from "./assert_es2023.js";

/**
 * @typedef {{book: number, chap: number, verse: number}} DAddress
 */

export class ParsingReferenceDescription {
    static #s = null
    /** @returns {ParsingReferenceDescription} */
    static get s() { if (this.#s == null) this.#s = new ParsingReferenceDescription(); return this.#s }

    /** @type {RegExp} */
    _regBookNames = null;
    /** @returns {RegExp} */
    get regBookNames() {
        if (this._regBookNames == null) {
            this.makeSureStaticExist()
        }
        return this._regBookNames;
    }

    constructor() {
        this.makeSureStaticExist();
    }

    /**
     * main
     * @param {string} strDescription
     * @param {{ book?: number, chap?: number }} [defaultAddress]
     * @returns {DAddress[]}
     */
    main(strDescription, defaultAddress) {

        // accept '.' as ';'
        strDescription = (strDescription || '').replace(/\./g, ';');

        const defAddress = this.getDefaultAddress(defaultAddress);
        let re2 = []
        try {
            const re2b = this.splitBook2(strDescription, defAddress);
            re2 = re2b;
        } catch (error) {
            console.warn(error.message);
            return [];
        }

        const reVerse = [];
        for (const it of re2) {
            // SmartDescriptEndParsing 可以修改描述尾部（例如處理 'e' 之類）
            const re3 = new SmartDescriptEndParsing().main(it.id, it.des);

            if (re3 != null) {
                it.des = re3;
            }

            const re4 = this.getAddressesOneBook(it);
            for (const a1 of re4) {
                reVerse.push(a1);
            }
        }

        // - 檢查所有地址是否合法，任何一個不合法，就全部不回傳
        if ( reVerse.some( addr => {
            if (addr.book < 1 || addr.book > 66) {
                console.warn("錯誤書卷 " + addr.book);
                return true; // 錯誤書卷
            }
            const maxChap = BibleConstantHelper.getCountChapOfBook(addr.book);
            if (addr.chap < 1 || addr.chap > maxChap) {
                console.warn(BibleConstantHelper.getBookNameArrayChineseFull()[addr.book-1] + " 沒有第 " + addr.chap + " 章");
                return true; // 錯誤章節
            }
            const maxVerse = BibleConstantHelper.getCountVerseOfChap(addr.book, addr.chap);
            if (addr.verse < 1 || addr.verse > maxVerse) {
                console.warn(BibleConstantHelper.getBookNameArrayChineseFull()[addr.book-1] + " " + addr.chap + " 沒有第 " + addr.verse + " 節");
                return true; // 錯誤節
            }
            return false;
        })){
            return [];
        }

        return reVerse;
    }

    /**
     * 把單一書卷的描述（可能包含分號 ;）轉成多個 DAddress
     * @param {{ id: number; des: string }} it
     * @returns {DAddress[]}
     */
    getAddressesOneBook(it) {
        const r1 = it.des.replace(/\s/g, '');
        const r2 = r1.split(';').filter(a1 => a1.length !== 0);

        if (r2.length !== 0) {
            const vrs = [];
            for (const it2 of r2) {
                const arg = { idbook: it.id, descript: it2 };
                for (const it3 of new GetAddresses(it.id).main(arg)) {
                    vrs.push(it3);
                }
            }
            return vrs;
        } else {
            const arg = { idbook: it.id, descript: '' };
            return new GetAddresses(it.id).main(arg);
        }
    }

    /**
     * 依書卷名稱切分描述字串
     * @param {string} strDescription
     * @param {{book:number, chap:number}} defAddress
     * @returns {{ id: number; des: string }[]}
     */
    splitBook2(strDescription, defAddress) {
        const re2 = [];

        // - 不使用書卷名切割（會誤切，例如「錯誤書名4:1-3」被切成「錯誤」「書」「名4:1-3」）
        // - 改用 4:1-3,5; 這些符號來切割，切出「數字/範圍片段」與「其餘片段（含書卷名）」
        let re = splitStringByRegex(strDescription, /[\d\-,:;]+/g);
        if (re == null) {
            re = [{ w: strDescription }];
        }

        // - 任何一段不是「純書卷名稱」也不是「範圍描述」的，視為整體錯誤
        if ( re.some(it => {
            if (it.exec != null){
                return false // 這段是數字/範圍片段，合法
            }

            // - 開頭至結尾，都必須是書卷名稱，且只能切出 1 個
            const bookname = splitStringByRegex((it.w || '').trim(), ParsingReferenceDescription.s.regBookNames)
            if ( bookname == null ){
                return true // 有非書卷名稱, 不正確
            }
            if ( bookname.length != 1 ){
                return true // 一段字串被切成多個書卷名，不合理
            }
            return false;
        })){
            throw new Error("這個字串不太正確 「" + strDescription + "」");
        }

        // - 依序組合成 {id: 書卷ID, des: 該書卷的描述文字}
        let cur = defAddress.book;
        let curDes = '';

        for (const it of re) {
            if (it.exec != undefined) {
                // 文字片段：描述內容（數字/範圍）
                curDes += it.w;
            } else {
                // 見到下一個書名，先 push 前一個累積的描述（若有）
                if (curDes.length != 0) {
                    re2.push({ id: cur, des: curDes });
                }
                cur = BibleConstantHelper.getBookId(it.w.trim().toLowerCase());
                assert(cur != -1, `無法辨識的書卷名稱：「${it.w}」`);
                curDes = it.w;
            }
        }
        if (curDes.length !== 0) {
            re2.push({ id: cur, des: curDes });
        }

        return re2;
    }

    getDefaultAddress(defaultAddress) {
        const defAddress = { book: 40, chap: 1 };
        if (defaultAddress !== undefined) {
            if (defaultAddress.book !== undefined) {
                defAddress.book = defaultAddress.book;
            }
            if (defaultAddress.chap !== undefined) {
                defAddress.chap = defaultAddress.chap;
            }
        }
        return defAddress;
    }

    makeSureStaticExist() {
        if (this._regBookNames == null) {
            const names2id = BibleConstantHelper.getMapName2Id();
            const names = Object.keys(names2id);
            names.sort((a, b) => b.length - a.length); // 長度由大到小，避免短名稱先被誤配
            this._regBookNames = new RegExp(names.join('|'), 'gi');
        }
    }
}
```

**重點行為**：
- 預設書卷/章節：若字串一開頭沒有書卷名，套用呼叫端傳入的 `defaultAddress`（預設 `{book:40, chap:1}` 即馬太福音）。
- `.` 會被當成 `;` 處理（分隔符相容）。
- 任何一個地址不合法（書卷超出 1~66、章節超出範圍、節數超出範圍），**整個結果回傳空陣列 `[]`**，而非只濾掉錯誤的那筆。
- 書卷名稱辨識錯誤時會 `throw`，並在 `main()` 中被攔截、回傳 `[]`（並 `console.warn`）。

### 2.3 `GetAddresses`（完整原始碼）

負責把單一書卷內的描述字串（如 `"1:1-3,6-7,21,25,2:3-5"`）展開成 `DAddress[]`。

```js
export class GetAddresses {
    // 類型 0: 跨章節範圍，例如 "1:32-2:31" → match ["11:32-2:31","11","32","2","31"]
    static #regA1 = new RegExp('(\\d+):(\\d+)-(\\d+):(\\d+)');
    // 類型 1: 章內範圍，例如 "1:32-50" → match ["11:32-50","11","32","50"]
    static #regA2 = new RegExp('(\\d+):(\\d+)-(\\d+)');
    // 類型 3: 承接上一章的範圍，例如 "4-7" → match ["4-7","4","7"]
    static #regA4 = new RegExp('(\\d+)-(\\d+)');
    // 類型 4: 特定章節單節，例如 "1:23" → match ["1:23","1","23"]
    static #regA5 = new RegExp('(\\d+):(\\d+)');
    // 類型 2: 單一數字（依上下文為「章」或「節」），例如 "23" → match ["23","23"]
    static #regA3 = new RegExp('^(\\d+)$');

    #idBook;
    #addresses = [];

    constructor(idBook) {
        this.#idBook = idBook;
    }

    getChapCountEqual1BookIds(){
        return BibleConstantHelper.getChapCountEqual1BookIds()
    }
    getVerseCount(bookId, chap) {
        return BibleConstantHelper.getCountVerseOfChap(bookId, chap);
    }

    /**
     * @param {{idbook:number, descript:string}} oneBookResult
     * @returns {DAddress[]}
     */
    main(oneBookResult) {
        try {
            // 描述字串為空，且書卷是「只有一章」的書（如約二、約三）時，預設整章
            if (oneBookResult.descript.length === 0) {
                if (this.getChapCountEqual1BookIds().includes(this.#idBook)) {
                    return this.#generateOneChap(1);
                }
                console.warn('GetAddresses 不加章節只允許「一章」的書卷 (例如約二、約三)。');
                return [];
            }

            const descriptions = oneBookResult.descript.split(',');
            const classifiedTypes = descriptions.map(desc => this.#classifyType(desc));

            classifiedTypes.forEach(addressType => {
                if (addressType === null) return; // 忽略無法解析的片段

                let generatedAddresses = [];
                switch (addressType.tp) {
                    case 0: generatedAddresses = this.#generateFromType0(addressType); break; // C:V-C:V
                    case 1: generatedAddresses = this.#generateFromType1(addressType); break; // C:V-V
                    case 2: generatedAddresses = this.#generateFromType2(addressType); break; // C 或 V（依上下文）
                    case 3: generatedAddresses = this.#generateFromType3(addressType); break; // V-V（承接上一章）
                    case 4: generatedAddresses = this.#generateFromType4(addressType); break; // C:V
                    default: break;
                }
                this.#addresses.push(...generatedAddresses);
            });

            return this.#addresses;
        } catch (error) {
            console.error('GetAddresses 執行錯誤:', error);
            throw error;
        }
    }

    /** 依序嘗試 5 種正則，回傳分類結果；順序很重要（先比對較嚴格的樣式） */
    #classifyType(des) {
        const r1 = des.match(GetAddresses.#regA1); // C:V-C:V
        if (r1 !== null) {
            return { tp: 0, ch1: parseInt(r1[1],10), vr1: parseInt(r1[2],10), ch2: parseInt(r1[3],10), vr2: parseInt(r1[4],10) };
        }
        const r2 = des.match(GetAddresses.#regA2); // C:V-V
        if (r2 !== null) {
            const ch1 = parseInt(r2[1], 10);
            return { tp: 1, ch1, vr1: parseInt(r2[2],10), ch2: ch1, vr2: parseInt(r2[3],10) };
        }
        const r4 = des.match(GetAddresses.#regA4); // V-V（承接上一章）
        if (r4 !== null) {
            return { tp: 3, ch1: -1, vr1: parseInt(r4[1],10), ch2: -1, vr2: parseInt(r4[2],10) };
        }
        const r5 = des.match(GetAddresses.#regA5); // C:V
        if (r5 !== null) {
            return { tp: 4, ch1: parseInt(r5[1],10), vr1: parseInt(r5[2],10), ch2: -1, vr2: -1 };
        }
        const r3 = des.match(GetAddresses.#regA3); // 單一數字
        if (r3 !== null) {
            const ch1 = parseInt(r3[1], 10);
            return { tp: 2, ch1, vr1: ch1, ch2: -1, vr2: -1 };
        }
        return null; // 無法識別
    }

    // 跨章節範圍，例如 1:2-3:24
    #generateFromType0(add) {
        if (add.ch1 === add.ch2) {
            return this.#generateFromType1(add); // 退化為章內範圍
        }
        const re = [];
        // 第一章節（vr1 ~ 本章末）
        const verse1End = this.getVerseCount(this.#idBook, add.ch1);
        re.push(...linq_range(add.vr1, verse1End - add.vr1 + 1).map(v => this.#new_DAddress(this.#idBook, add.ch1, v)));
        // 中間整章
        if (add.ch1 + 1 < add.ch2) {
            linq_range(add.ch1 + 1, add.ch2 - add.ch1 - 1).forEach(chap => re.push(...this.#generateOneChap(chap)));
        }
        // 最後章節（第1節 ~ vr2）
        re.push(...linq_range(1, add.vr2).map(v => this.#new_DAddress(this.#idBook, add.ch2, v)));
        return re;
    }

    // 章內範圍，例如 1:12-43（假設 ch1 === ch2）
    #generateFromType1(add) {
        return linq_range(add.vr1, add.vr2 - add.vr1 + 1).map(v => this.#new_DAddress(this.#idBook, add.ch1, v));
    }

    // 整章
    #generateOneChap(chap) {
        const verseEnd = this.getVerseCount(this.#idBook, chap);
        return linq_range(1, verseEnd).map(v => this.#new_DAddress(this.#idBook, chap, v));
    }

    #new_DAddress(book, chap, verse) { return { book, chap, verse }; }

    #getLastVerseAddress() {
        return this.#addresses.length === 0 ? undefined : this.#addresses.at(-1);
    }

    // 單一數字：沒有前面地址時代表「整章」；有前面地址時代表「當前章的單節」
    // 例如 "創 23" → 創世記 23 章；"創 1:1,23" → 創世記 1 章 23 節
    #generateFromType2(add) {
        const last = this.#getLastVerseAddress();
        if (last === undefined) {
            return this.#generateOneChap(add.ch1);
        }
        return [this.#new_DAddress(this.#idBook, last.chap, add.vr1)];
    }

    // 承接上一章的範圍，例如 "7-9"；若前面沒有地址，預設第1章
    #generateFromType3(add) {
        const last = this.#getLastVerseAddress();
        const chap = last?.chap ?? 1;
        return linq_range(add.vr1, add.vr2 - add.vr1 + 1).map(v => this.#new_DAddress(this.#idBook, chap, v));
    }

    // 特定章節單節，例如 "1:23"
    #generateFromType4(add) {
        return [this.#new_DAddress(this.#idBook, add.ch1, add.vr1)];
    }
}
```

`linq_range(start, count)` 為 `[start, start+1, ..., start+count-1]` 的整數序列產生器（等同一般 `range` helper）。

**分類優先順序很關鍵**：`regA1`(`C:V-C:V`) → `regA2`(`C:V-V`) → `regA4`(`V-V`) → `regA5`(`C:V`) → `regA3`(單一數字)。因為正則彼此有包含關係，順序決定何者優先命中。

### 2.4 依賴的輔助函數（`BibleConstantHelper.es2023.js`）

```js
static getBookId(name) // 1-based book id；不存在回傳 -1；英文需先轉小寫
static getMapName2Id() // 所有書卷名稱變體（繁中/簡中/英文全名/縮寫/短縮寫，皆 toLowerCase 後為 key）→ id 的對照表
static getCountChapOfBook(book) // 該書卷章數；book 超出 1~66 回傳 0 並 console.error
static getCountVerseOfChap(book, chap) // 該章節數；book/chap 超出範圍回傳 0 並 console.error
static getChapCountEqual1BookIds() // 回傳只有 1 章的書卷 id 陣列（如 約貳=63, 約參=64, 猶大書, 俄巴底亞書...）
static getBookNameArrayChineseFull(isGb) // 中文全名陣列（index 0 對應 book=1）
```

`getMapName2Id()` 額外處理了特殊別名（`約壹/约壹/約翰壹書/約一` 等 → id 62，以此類推 63/64；以及 `馬太/马太`、`馬可/马可`、`路加`、`約翰` 對應正典書卷本身）。

### 2.5 邊界案例

- **空描述 + 一章書**：`GetAddresses.main({descript:''})` 若書卷屬於「只有一章」（`getChapCountEqual1BookIds()`），回傳整章（第1章）所有節；否則回傳 `[]` 並警告。
- **書卷名稱錯誤**：`splitBook2` 中 `assert(cur != -1, ...)` 失敗 → `main()` catch 後回傳 `[]`。
- **章節/節數超出範圍**：`ParsingReferenceDescription.main()` 最後統一驗證，任一筆不合法則**整體**回傳 `[]`（不是部分過濾）。

## 3. 陣列 → 文字：`VerseRange` + `VerseRangeToString`

### 3.1 `VerseRange`（節錄，含完整互轉相關方法）

```js
import { BibleConstantHelper } from "./BibleConstantHelper.es2023.js";
import { ParsingReferenceDescription } from "./ParsingReferenceDescription.js";
import { VerseRangeToString } from "./VerseRangeToString.js"

/** @typedef {{book: number, chap: number, verse: number}} DAddress */

/** 供 linq distinct/orderBy 用：book*10000 + chap*1000 + verse */
export function DAddressComparor(addr) { return addr.book * 10000 + addr.chap * 1000 + addr.verse; }
export function DAddressComparor2(addr, addr2) {
  const r1 = DAddressComparor(addr), r2 = DAddressComparor(addr2);
  if (r1 == r2) return 0;
  return r1 < r2 ? -1 : 1;
}

export class VerseRange {
  /** @type {DAddress[]} */
  verses = [];

  /** 文字描述 → VerseRange；內部委派給 ParsingReferenceDescription */
  static fromReferenceDescription(describe, book1BasedDefault) {
    try {
      const re = ParsingReferenceDescription.s.main(describe, { book: book1BasedDefault });
      if (re.length == 0) {
        return null; // 解析失敗或結果為空，回傳 null（不是空陣列）
      }
      const re2 = new VerseRange();
      re2.verses = re;
      return re2;
    } catch (error) {
      console.error('fromReferenceDescription');
      throw error;
    }
  }

  /** fromReferenceDescription 縮寫；book1BasedDefault 預設 40（馬太福音） */
  static fD(describe, book1BasedDefault = 40) {
    return VerseRange.fromReferenceDescription(describe, book1BasedDefault);
  }

  /** 逐節比較兩個 VerseRange 是否完全相同（順序也須一致） */
  static isTheSame(a1, a2) {
    if (a1 === undefined || a2 === undefined || a1.verses === undefined || a2.verses === undefined) return false;
    const aa1a = a1.verses, aa2a = a2.verses;
    if (aa1a.length !== aa2a.length) return false;
    return aa1a.every((r1, i) => {
      const r2 = aa2a[i];
      return r1.book === r2.book && r1.chap === r2.chap && r1.verse === r2.verse;
    });
  }

  isIn(d) {
    if (this.verses.length === 0 || d === undefined) return false;
    return this.verses.some(a1 => a1.book === d.book && a1.chap === d.chap && a1.verse === d.verse);
  }

  add(v) { this.verses.push(v); }
  addRange(v) { v.forEach(a1 => this.verses.push(a1)); }

  /** 產生「太4:1-6」（繁中簡稱） */
  toStringChineseShort() { return new VerseRangeToString().main(this.verses, "羅"); }
  /** 產生簡體版 */
  toStringChineseGBShort() { return new VerseRangeToString().main(this.verses, "罗"); }
  /** 產生「Mt 4:1-6」（英文） */
  toStringEnglishShort() { return new VerseRangeToString().main(this.verses, "ro"); }

  toString() { return this.toStringChineseShort(); }
}
```

> **注意**：`VerseRange.js` 原始檔案中還有 `MergedChapFind`、`MergedCauseDataChanged`、`ToStringAfterMerged`、`VerseRangeComparor`、`BookNameTryGetBookId` 等 class，其中 `MergedChapFind`/`MergedCauseDataChanged` 依賴未匯入的 `ObjTools`、`getVerseCount`（全域函數，非 `BibleConstantHelper` 方法），`VerseRangeComparor`/`isTheSame`（原始檔案版本）依賴未匯入的 `Enumerable`（linq.js），研判是 TypeScript → JavaScript 移植時殘留的未完成/死碼。**重構新專案時不需照抄這幾個 class 的實作，只需理解 `VerseRangeComparor`/`DAddressComparor` 提供「排序鍵」的用途即可**（詳見 §3.3）。上方 `isIn`/`isTheSame` 已改寫為不依賴 `Enumerable` 的等價實作，供直接參考。

### 3.2 `VerseRangeToString`（完整原始碼）

負責把 `DAddress[]` 依書卷分組 → 找連續節 → 依章分組 → 組出精簡字串（例如整段連續會合併成 `4:1-6`，整章省略節號等）。

```js
import { BibleConstantHelper } from "./BibleConstantHelper.es2023.js";

export class VerseRangeToString {
    /**
     * 將 verses 轉成字串，例如 太1:1-3;創2:1
     * @param {DAddress[]} verses
     * @param {'羅'|'羅馬書'|'罗'|'罗马书'|'romans'|'rom'|'ro'} [lang='羅']
     * @returns {string}
     */
    main(verses, lang = '羅') {
        const re = this.splitBookId(verses);                          // 依書卷分組
        const re2 = re.map(a1 => this.splitContinueVerse(a1));         // 找出連續節
        const re3 = re2.map(a1 => this.splitTheSameChap(a1));          // 依章分組
        const re4 = re3.map(a1 => this.getDescriptionEachBook(a1, lang)).join(';');
        return re4;
    }

    getBookName(id, lang) { return BibleConstantHelper.getBookNameArrayWhereTp(lang)[id - 1] }
    getVerseCount(book, chap) { return BibleConstantHelper.getCountVerseOfChap(book, chap); }
    getChapCount(book) { return BibleConstantHelper.getCountChap(book); }

    getDescriptionEachBook(arg, lang) {
        const id = arg[0][0][0].book;
        const na = this.getBookName(id, lang);

        const des = arg.map(a1 => {
            if (a1.length > 1) {
                // 同一章內有多群不連續的節：[[23],[25,26,27],[30],[32...42]]
                const chap = a1[0][0].chap;
                const r2 = a1.map(a2 => {
                    const vr1 = a2[0];
                    if (a2.length === 1) return `${vr1.verse}`;
                    const vr2 = a2[a2.length - 1];
                    return `${vr1.verse}-${vr2.verse}`;
                }).join(',');
                return `${chap}:${r2}`;
            } else {
                // 該章只有一群連續節
                const a2 = a1[0];
                const vr1 = a2[0];
                const chap = vr1.chap;
                if (a2.length > 1) {
                    const vr2 = a2[a2.length - 1];
                    if (vr1.chap !== vr2.chap) {
                        // 跨章的連續範圍
                        return `${chap}:${vr1.verse}-${vr2.chap}:${vr2.verse}`;
                    } else {
                        if (vr1.verse === 1 && vr2.verse === this.getVerseCount(id, chap)) {
                            // 剛好整章：只顯示章號（除非全書只有一章）
                            if (this.getChapCount(id) === 1) return '1';
                            return `${chap}`;
                        }
                        return `${chap}:${vr1.verse}-${vr2.verse}`;
                    }
                } else {
                    return `${chap}:${vr1.verse}`;
                }
            }
        }).join(';');

        return na + des;
    }

    // 依章分組（同章的連續群放一起）
    splitTheSameChap(vrsOneBook) {
        const re3 = [];
        let sameChap = [];
        let chap = -1;
        const fnPushSameChapToResult = () => {
            if (sameChap.length > 0) re3.push(sameChap);
            sameChap = [];
        };

        for (let i = 0; i < vrsOneBook.length; i++) {
            const vrsOneContinue = vrsOneBook[i];
            const vr1 = vrsOneContinue[0];

            if (vrsOneContinue.length > 1) {
                const vr2 = vrsOneContinue[vrsOneContinue.length - 1];
                if (vr1.chap !== vr2.chap) {
                    // 跨章的連續群獨立一組
                    fnPushSameChapToResult();
                    sameChap.push(vrsOneContinue);
                    fnPushSameChapToResult();
                    chap = -1;
                } else {
                    if (chap === vr1.chap) {
                        sameChap.push(vrsOneContinue);
                    } else {
                        fnPushSameChapToResult();
                        sameChap.push(vrsOneContinue);
                        chap = vr1.chap;
                    }
                }
            } else {
                if (vrsOneContinue[0].chap !== chap) {
                    fnPushSameChapToResult();
                    sameChap.push(vrsOneContinue);
                    chap = vr1.chap;
                } else {
                    sameChap.push(vrsOneContinue);
                }
            }
        }
        if (sameChap.length > 0) re3.push(sameChap);
        return re3;
    }

    // 找出連續節群組（依 isContinueVerse 判斷相鄰是否連續）
    splitContinueVerse(vrsOneBook) {
        const re2 = [];
        let re1 = [];
        for (let i = 0; i < vrsOneBook.length; i++) {
            if (i !== 0 && this.isContinueVerse(vrsOneBook[i - 1], vrsOneBook[i])) {
                re1.push(vrsOneBook[i]);
            } else {
                if (re1.length !== 0) re2.push(re1);
                re1 = [vrsOneBook[i]];
            }
        }
        if (re1.length !== 0) re2.push(re1);
        return re2;
    }

    // 判斷兩節是否「連續」：同章節號+1；或跨章時前者為該章最後一節、後者為下一章第1節
    isContinueVerse(vr1, vr2) {
        if (vr1.chap === vr2.chap) {
            return vr1.verse + 1 === vr2.verse;
        } else {
            if (vr1.chap + 1 === vr2.chap && vr2.verse === 1) {
                return this.getVerseCount(vr1.book, vr1.chap) === vr1.verse;
            }
            return false;
        }
    }

    // 依書卷分組（假設輸入已依書卷連續排列，不會重新排序）
    splitBookId(verses) {
        const re = [];
        let id, r1;
        for (const it1 of verses) {
            if (id === it1.book) {
                r1.push(it1);
            } else {
                if (r1 !== undefined && r1.length !== 0) re.push(r1);
                r1 = [it1];
                id = it1.book;
            }
        }
        if (r1 && r1.length !== 0) re.push(r1);
        return re;
    }
}
```

> **潛在問題**：`getChapCount(book)` 呼叫 `BibleConstantHelper.getCountChap(book)`，但 `BibleConstantHelper.es2023.js` 中實際方法名稱是 **`getCountChapOfBook(book)`**（見 §2.4），並無 `getCountChap`。也就是說「剛好整章、且全書只有一章」這個分支（`if (this.getChapCount(id) === 1) return '1';`）在目前程式碼中呼叫會噴錯（`TypeError: ... is not a function`）。**新專案重構時應修正為呼叫 `getCountChapOfBook`**，並補上這個案例的測試（例如：猶大書全書只有 1 章 25 節，若輸入整章，輸出應為 `1` 而非 `1:1-25`）。

**核心概念**：輸入的 `verses` 陣列**必須已依書卷、章、節的順序排列**（`splitBookId`/`splitTheSameChap` 都假設同書卷/同章的項目是連續出現，不會做排序）。若順序錯亂需先用 `DAddressComparor2` 排序。

### 3.3 排序/去重輔助

```js
/** 供 linq distinct() 用, 也可用在 orderBy */
export function DAddressComparor(addr) { return addr.book * 10000 + addr.chap * 1000 + addr.verse; }
export function DAddressComparor2(addr, addr2) {
  const r1 = DAddressComparor(addr), r2 = DAddressComparor(addr2);
  if (r1 == r2) return 0;
  return r1 < r2 ? -1 : 1;
}
```

注意此排序鍵假設 `chap < 1000` 且 `verse < 1000`（乘數係數固定），對絕大多數書卷成立（詩篇 176 節為最長章，仍遠低於 1000）。

## 5. 附錄：舊式 pipeline 簡述（僅供理解，非重構依據）

- **`splitReference`**（`index/splitReference.es2023.js`）：用途是從**自由文字**（例如註解、講章內容）中「找出」帶有 `#書卷章:節|` 標記或裸露的引用字串，而不是把一個已知的、單純的位置描述字串轉成陣列。內部經過 `findRefernece()`（正則標記 a~f 六種樣式）→ `merge()` → `removeTpf()` → `cvtToDTexts()`，最終呼叫 `BibleConstantHelper.generateAddressesTpA/TpB/TpE/TpF`（四個範圍展開函數，見下方）展開為 `refAddresses`。
- **`cvtAddrsToRef`**（`index/cvtAddrsToRef.es2023.js`）：陣列 → 文字的舊實作，測試案例（見 §4.4）對「合併連續節/章」規則覆蓋較完整，建議作為 `VerseRangeToString` 重構後的交叉驗證基準，但兩者演算法路徑不同，不建議直接復刻程式碼。

`BibleConstantHelper` 中四個範圍展開函數（`splitReference` 依賴，`ParsingReferenceDescription`/`GetAddresses` 未使用，但邏輯上等價於 §2.3 的 `GetAddresses` 展開規則）：

```js
// 創1:4-7
static generateAddressesTpE(book, chap, verse1, verse2) {
    const range = verse2 > verse1
        ? Array.from({ length: verse2 - verse1 + 1 }, (_, i) => verse1 + i)
        : Array.from({ length: verse1 - verse2 + 1 }, (_, i) => verse2 + i);
    return range.map(v => ({ book, chap, verse: v }));
}
// 創1:5-end（到章末）
static generateAddressesTpB(book, chap, verse) {
    const cnt = BibleConstant.COUNT_OF_VERSE[book - 1][chap - 1];
    return Array.from({ length: cnt - verse + 1 }, (_, i) => ({ book, chap, verse: verse + i }));
}
// 創2（整章）
static generateAddressesTpF(book, chap) {
    const cnt = BibleConstant.COUNT_OF_VERSE[book - 1][chap - 1];
    return Array.from({ length: cnt }, (_, i) => ({ book, chap, verse: i + 1 }));
}
// 創1:2-3:4（跨章）
static generateAddressesTpA(book, chap1, verse1, chap2, verse2) {
    const part1 = this.generateAddressesTpB(book, chap1, verse1);
    const part2 = [];
    if (chap2 - chap1 > 1) {
        for (let ch = chap1 + 1; ch < chap2; ch++) {
            part2.push(...this.generateAddressesTpF(book, ch));
        }
    }
    const part3 = this.generateAddressesTpE(book, chap2, 1, verse2);
    return part1.concat(part2, part3);
}
```

兩套 pipeline 的 `DAddress` 皆使用 `{book, chap, verse}` 形式，彼此輸出可互通。
