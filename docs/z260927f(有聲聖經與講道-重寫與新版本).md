# 有聲聖經、講道分頁：重寫與新版本

## 為什麼重寫

舊的 `static/bible_audio_api/audiobible_api.js` (2015 年)：

- 畫面：中間一個大 CD 圖示，控制鈕是 png 圖片，進度條只能拖曳，手刻的版本下拉選單，不能調速度
- 資料：寫死 8 個版本，網址寫死 `http://media.fhl.net/...`，「只有新約」也是寫死判斷
- `<audio>` 放在 `#fhlInfoContent` 裡，切到別的分頁就被清掉，聲音中斷

信望愛站這幾年多了很多版本 (au.php 已到 version 21) 和投影片 (aump4.php 的 mp4)。

## API 與資料的坑

- `json/au.php?version=&bid=&chap=` **不檢查檔案是否存在**，任何版本、任何章都回傳網址。所以不能拿它判斷有沒有錄音
- 覆蓋度的來源是舊版列表頁 `new/audio_hb.php?version=N` (首頁「聖經朗讀」點進去的那頁)，只列出存在的章：
  - 連結 `listenhb.php?version=17&bid=1&chap=001` 表示只有聲音；`listenhbm4.php?...` 表示那章有 mp4 投影片
  - `bid=1A`、`1B`、`1C` 是同一章的**其它朗讀版本**。檔案在 `{dir}/1A/1_001.mp3`，au.php 也吃 `bid=1A`
  - 客語 (v2) 的 A 版是海陸腔 (au.php 的 name 寫「客語(四縣腔，A版海陸腔）」)，其它版本的 A、B、C 沒有說明，畫面上顯示成 2、3、4
- 網址規則：`https://media.fhl.net/{dir}/{bid}{variant}/{bid}_{章3位}.{mp3|mp4|ogg}`，dir 從 au.php 回傳的網址取出 (unv1、tte、thv…)。我們直接組網址，不必每章打一次 api
- 不要用大量 HEAD 去掃 media.fhl.net：會被限流 (403、逾時)，掃出來的覆蓋度會有假的缺漏
- au.php、media.fhl.net 都有 `Access-Control-Allow-Origin: *`；media 支援 range (可拖進度)
- 首頁有些版本沒有連結 (例如福州話)，但 au.php 與列表頁都有，照樣列出

目前 (2026-09-27) 22 個版本；有 mp4 的：現代台語譯本 (v17)、現代客語譯本 (v18)、達悟語 (v19)。新增版本時：跑 `npm run gen:audio`，再到 `AUDIO_VERSION_META` 加分組與名稱 (沒加的會出現在「其它」)。

## 播放器常駐 (切分頁不中斷)

- 只有一個 `<video>`，mp3 也用它播。聲音模式時放在 `body` 下的 `.au-holder` (display:none，照樣出聲)；投影片模式且在有聲分頁時，搬到畫面的 `.au-stage`
- 其它分頁 render 會 `.html()` 清掉 `#fhlInfoContent`。media 被移出 document 就會暫停，所以切分頁時 (`InfoTitleChanged`，在新分頁 render 之前觸發) 先把 video 搬回 holder。同一個 task 內搬動不會暫停
- 按過播放後，切到其它分頁會在 `#fhlInfo` 左下出現迷你播放列 (播放/暫停、目前章、✕ 停止)，點文字回到有聲分頁
- 分頁畫面每次 render 都重建，狀態都在 player；`player.onChange` / `onTime` 只更新目前這份畫面

## 跟著閱讀

- 經文換章 (`go` 事件) → 播放器換章；原本在播就接著播
- 播完接下一章，或按上一章 / 下一章 → 跳過此版本沒有的章 (`AudioBibleIndex.step`)，並讓經文翻頁 (設 ps、觸發 `go`、render、`chapchanged` 更新網址)
- 此版本沒有這章 (例如希伯來文在馬太福音) → 顯示提示，並建議幾個有這章的版本

## 講道

取代 `static/preach_api/preach_api.js` 與 `static/commonR/` (audio.js、processbar.js、h.js，都只有講道在用)，以及 5 張播放器圖片。

- 資料：`sc.php?engs=&chap=&sec=&book=&gb=`，book 是講員：8 蔡茂堂、9 盧俊義、10 康來昌 (`sc.php?validbook=1`)。盧俊義目前查不到資料，仍照舊查
- com_text 是大綱文字夾著錄音標記 `[media$N01_001_001_001_001_t.m3u]（台語）`、`[media$40/N40_5_1_5_3.m3u]`。
  錄音在 `https://media.fhl.net/cbolcom/{book}/{標記內路徑}.mp3` (舊版寫死 http)。標記後面緊接的括號是錄音名稱 (台語、華語)，括號全形半形混用
- title「馬太福音 5章1節 到 5章3節」顯示成「馬太福音 5:1-3」；0章0節是書卷導論
- 每位講員一張卡片；卡片的上一段 / 下一段是 sc.php 回傳的 prev / next，只換那張卡片，不動讀經位置 (與舊版相同)
- 同一段經文的查詢結果快取在記憶體 (點同一段的不同節不重查)
- 播放中換到別的經文：卡片重建，但正在播的不停；若它不在新卡片裡，上方顯示「正在播放」那一列
