# 7.5.8.1 對話框：寬高不設限、記住大小、捲軸貼邊

交互參照、搜尋、原文字典都用 `DialogHtml` (jQuery UI dialog)。字型調大後三個問題一起浮現。

## 1. 預設寬度太窄、max-width 太小
- `maxWidth` 預設 80% 視窗 → 視窗寬減 16px。
- 預設寬度：交互參照 `560px × k` (並排多譯本 `120 + 320 × 譯本數`，也乘 k)，搜尋 `max(80% 視窗, 1100 × k)` (上限 95%)，字典同 `max(80%, 560 × k)`；`k = contentFontK()` = `--fontsize / 12pt` (≥ 1)，全部不超過視窗寬減 16px。

## 2. 捲軸離內容很遠
兩個原因：
- jQuery UI 內容區 `padding: .5em 1em`，內容區字型 = `--fontsize`，字一大內距就跟著大。→ `fhl.css` 改 `0.5rem 0.75rem`。
- 拖曳改大小時 jQuery UI 用 `alsoResize` 對內容區加減像素，且高度寫在內容區 (px)，寬高漸漸和 dialog 對不上，拖越多捲軸離邊越遠。→ `DialogHtml` 不再把高度交給 `height` 選項，而是 `$ui.outerHeight(h)` 設在 dialog 上並加 class `dlg-fluid`；css 讓 `.ui-dialog.dlg-fluid` 為 flex column，內容區 `flex: 1 1 auto; min-height: 0; width/height: auto !important`。

## 3. 高度上限與記住大小
- 預設 80% 高只管第一次的自動高度；一開始拖曳 (`dialogresizestart`) 或載入記住的大小時 `releaseMax()`：內容區 `max-height: none`，resizable `maxHeight` = 視窗高 − 16。
- `showDialog({ sizeKey })`：拖曳結束 (`dialogresizestop`) 存 `{w, h}` 到 localStorage `fhlDlgSize[sizeKey]`，下次開啟套用 (夾在視窗內，高度變了要重新 `position`)。目前 `ref` / `dict` / `search` (窄螢幕的搜尋不記)。

## 7.5.8.2 補充：版本更新資訊視窗記住捲動位置
`index/indexLast.js` 的 `#version-infos` (NUI版本更新資訊) 是建一次、反覆開關的 jQuery UI dialog，關閉時內容 `display:none` 會丟掉 `scrollTop`。`beforeClose` 記下 `lastScrollTop`，`open` 時還原 (只在頁面開著期間，重新整理不保留)。開發站實測捲到 300、關掉再開仍是 300。

### 7.5.8.2 之後又捲回最上面 (2026-10-12 修)
只在 `open` 還原不夠：jQuery UI 在 show 動畫結束後 (`open` 事件之後) 會 `focus()` 第一個 tabbable，而更新資訊最上面那筆有「表單連結」`<a>`，瀏覽器為了讓它可見把內容捲回 0 (7.5.8.2 當時頂端沒有連結所以沒發現)。
- 第一次修：`open` 設 `restoreOnFocus`，在 `focus` 事件再還原。真實滑鼠 / 按鍵實測有效，但 log 顯示仍是「先被捲到 0 再拉回」，畫面可能閃一下。
- 現在：直接覆寫這個 dialog instance 的 `_focusTabbable`，改 focus 視窗本身 (`uiDialog`)，Esc 仍可關、連結仍可 Tab；根本不動捲動 (實測 focus 落在 `DIV.ui-dialog`，scrollTop 全程 1000)。上面的還原保留當保險。
- 測試要用真實輸入 (滾輪 + Esc / X + 點開)：腳本呼叫 `dialog('open')` 時瀏覽器窗格沒有 focus，重現不出來。
