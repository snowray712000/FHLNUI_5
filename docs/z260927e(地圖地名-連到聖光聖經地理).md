# 地圖地名：點 label 連到聖光聖經地理（6.9.1）

## 需求

地圖分頁上的地名（點、線、區域，例如 創15 的 耶布斯、伯拉、埃及）原本點了沒反應。
查聖經地名最好用的是聖光聖經地理（https://biblegeography.holylight.org.tw），
例如 `condensedbible_detail?id=2&top=0071`（簡明聖經史地的地名詳解）。
希望點地名就能直接查到聖光的資料。

## 做法

點 label 或圖形本身，開一個 leaflet popup，三個連結（新分頁）：

| 項目 | 網址 |
|---|---|
| 聖光：查「耶布斯」 | `condensedbible_list?name=耶布斯&range=id` |
| 聖光：創 15 的所有地名 | `condensedbible_list?select1=1&select2=15&range=id` |
| Google：耶布斯 創 15 | `耶布斯 創 15 site:biblegeography.holylight.org.tw` |

- 第 1 項最準，列出這個地名出現的所有經文（含 創15:21）。
- 第 2 項列出這章聖光收錄的所有地名（創15 共 13 筆）。`select1` 是書卷 1–66，與 `ps.bookIndex` 相同。
- 第 3 項可補到文章、照片，也能補救兩邊譯名不同的情況。
- `name` 與 `select1/select2` 一起給時只看 `name`，所以分成兩項。

## 用哪個地名：cname（和合本）

`sobj.php?engs=Gen&chap=15&gb=0` 每筆地名有多個名稱：

| 欄位 | 例 | 說明 |
|---|---|---|
| `cname` | 耶布斯、大馬色、伯拉 | 和合本 |
| `c1name` / `c2name` | 大馬士革、幼發拉底 | 其它譯本 |
| `ename` | Jebus、Euphrates | 英文 |
| `mname` | Jerusalem、Tell es-Safi Gath | 現代地名，不適合拿來查 |

只有 `is_site == "1"` 的才是地點（「盾牌」「麻雀」等 `is_site=0` 不畫、也不處理）。

抽樣 創世記、約書亞記、使徒行傳 共 512 個地點，與聖光「簡明聖經史地」全部 1271 個地名比對：

- 完全相同：`cname` 429（84%）、`c1name` 381、`c2name` 374 → 聖光用的是和合本，用 `cname`。
- 聖光的查詢是「包含」比對（查「黑門」會找到「黑門山」，查「亞捫」找到「亞捫人」），
  但名稱含「•」就查不到（「伯•亞文」0 筆、「伯亞文」4 筆），所以先去掉「•」。約 95% 查得到。
- 仍查不到的約 26 個是兩邊譯名不同（西底結、安城、意大利、馬耳他…），靠 Google 那項補救。
- 聖光也能用英文查（`Jabbok` 查得到），目前未使用。

## 簡體

`gb=1` 時 `cname` 是簡體，聖光只有繁體可查。所以簡體時多呼叫一次 `sobj.php …&gb=0`，
以 `id` 對應繁體地名；label 仍顯示簡體，連結中的地名與書卷名（`getBookNameArrayChineseShort(false)`）一律繁體。

## 實作細節（`static/fhlmap_api/fhlmap_main.js`）

- `fhlmap_createLinksPopup(nameTrad, nameShow, ps)`：產生 popup 內容（DOM，`textContent` 避免注入）。
- `fhlmap_bindLinks(layer, …)`：`layer.bindPopup(...)`，圖形本身點了就會開。
  permanent tooltip 在 leaflet 1.3.4 預設 `pointer-events:none`，所以直接對 tooltip 的 element 設
  `pointer-events:auto`，綁 click → `layer.openPopup(tooltip.getLatLng())`；
  並 `L.DomEvent.stop(e)`，否則 click 冒泡到 map 會把剛開的 popup 關掉。
- `fhl.json_api_text_post` 回傳的 Promise 只會 resolve `fncb_success` 的回傳值，
  所以要傳 `function (t) { return t; }`，不能傳 null。
- 資料回來時若已切到別章或離開地圖（`fhlmap_chap_prev` / `fhlmap_engs_prev` / `rfhlmap` 不符），就不畫。
