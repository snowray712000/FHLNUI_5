# 典藏清單篩選：分類 chip、語言 chip＋文字框、表格／卡片、可收合（6.7.1）

典藏（ob）分頁的清單畫面改版。設計來源是 FHLNUI_6 的原型頁
`FHLNUI_6/src/ob/demo/ui-pv-catalog-browse.{html,ts,css}`（實作記錄 `FHLNUI_6/history/2026/s3/0920a_ob-demo實作記錄.md`）。
原型把每個待決定的地方做成可切換的選項，這次選定：

| 項目 | 原型的選項 | 選定 |
|---|---|---|
| 1. 分類（`div`） | 分頁籤 / 篩選 chip | **篩選 chip** |
| 2. 語言（`lang`） | 高頻 chip＋文字框 / 純文字框 / 完整清單 | **高頻 chip＋文字框** |
| 3. 其他 | 關鍵字（書名／作者）＋年代＋文體 | **照原型** |
| 4. 清單呈現 | 表格 / 卡片 | **兩種都能，可切換** |

之後又加上：篩選區**可收合**。

改的檔案：`index/FhlInfoOb.es2023.js`（清單部分；閱讀畫面、局部縮放檢視器沒動）、`static/ob_api/ob_api.css`。

---

## 1. 資料流：篩選改在前端做

以前每點一次年代／文體，就重跑 `ob.php`（有快取）＋ `sob.php?book=all`，並在回應裡篩好寫進 `state.obdata`。

現在：

- `state.obdata` = 「本章有資料的書目」，**不篩選**。只有換書、換章、換繁簡時才重查（`render()` 裡的 `listChanged`）。
- 篩選條件放在 state：`div_set`、`lang_set`、`keyword`、`year_set`、`style_idx`，由 `#passes()` / `#filtered()` 即時算。
- `sob.php?book=all` 加上請求序號 `#listSeq`（與閱讀用的 `#reqSeq` 分開，兩種查詢會同時在飛），快速換章時過期回應直接丟掉。

順便修掉：**清單開著時換章，清單仍是上一章的書目**（以前換經節只更新閱讀用的 `sobdata`）。

### 幾個細節

- **Faceted count**：算分類 chip 的數字時不套用分類自己的篩選，語言同理（`#passes(r, skip)`）。否則選了「英文」，其它語言 chip 全變 0。
- **分類順序**照 `ob.php` 全書目的出現順序，不隨本章計數跳動；計數為 0 的分類隱藏（目前選中的除外）；空字串 `div` 顯示為「未分類」（`OB_NO_DIV`）。
- **語言 chip** 取本章（套用其它篩選後）最常見的前 `OB_LANG_CHIP_MAX = 10` 個。語言有數十種值（全書目 97 種，創 1 就有 26 種），且有「廣東話、英語」這種組合值，所以比對用**子字串**：chip 與文字框共用 `lang_set`，輸入「話」會命中台灣話、客家話…。
- **文體存索引**（`style_idx`）不存字串：`ob.php` 的 `style`、`div`、`lang` 會隨 `gb` 參數變成簡體字串。換繁簡時 `div_set`、`lang_set` 清空。
- **年代**維持字串比較（`age` 是字串，沿用舊行為，不 parseInt）。

## 2. 重繪：打字時只換局部

整個面板是 `dom.html(...)` 全量重繪。點選類（chip、下拉、切換、收合）照舊全量重繪；**打字類**（語言文字框、關鍵字）改呼叫 `#paintListPart()`，只換掉 chip、筆數、收合摘要、清單，輸入框不動，才不會失去焦點、打斷中文輸入法組字。

## 3. 呈現

- **表格**：年代／書名／作者／語言／閱讀，整列可點進閱讀；表頭 sticky。
  不再用舊的 `.obtable`（`static/ob_api/ob_table.css` 用 `tr:first-child td` 當表頭樣式，改用 `<thead>` 後會把第一筆資料畫成表頭）。
- **卡片**：分類徽章、年代（`agec`）、書名、作者·語言·文體、兩行簡介；「閱讀」與「看更多」（版權、提供單位、備註）。
- 表格／卡片的選擇存在 `localStorage` `fhlObListMode`。

## 4. 可收合的篩選區

- 標題列「篩選 ▾」，整列可點；收合時右側用小標籤列出目前套用的條件（`#html_filters_summary()`），沒有條件顯示「未設定」。
- 筆數列「本章有資料 N 筆,符合 M」與「清除篩選」放在篩選區外，收合時仍看得到。
- 預設展開（第一次使用看得到有哪些篩選），之後記住：`localStorage` `fhlObFiltersOpen`。

## 5. 樣式：為什麼第一版「很醜」，與 css 變數

第一版功能正確但與原型差很多，原因不在顏色，而在版面與間距沒照原型：

| | 第一版 | 原型／現在 |
|---|---|---|
| 「分類」「語言」標題 | 與 chip 擠在同一個 wrap 列 | 獨立一行在上 |
| chip | `padding:1px 10px`、`gap:4px` | `4px 12px`、`gap:6px` |
| 篩選區 | 無內距、line-height 1.5 | 內距 12–14px、line-height 1.7 |
| chip 計數 | 另一個灰色小字 | 內嵌「聖經珍藏（47）」 |
| 年代／文體 | 沒標題，兩個下拉都顯示「全部」 | 每欄有標題 |
| 表格 | 內距 4/6、斑馬紋 | 6/8、只有分隔線 |

唯一刻意保留的差異：主程式 body 強制 `Zen Maru Gothic !important`，原型是 `system-ui`。

**顏色一律用 css 變數**（將來走 theme）：`static/ob_api/ob_api.css` 開頭的 `:root { --ob-fg, --ob-fg-muted, --ob-bg, --ob-border, --ob-accent, --ob-accent-lang, --ob-badge-* … }`，值取自原型（GitHub Primer 色系）。舊的閱讀畫面按鈕也改用變數。
局部縮放檢視器的 inline style 寫成 `var(--ob-border, #d0d7de)` 帶預設值——該處原本就刻意不依賴 css 檔（避免吃到舊快取）。
已不用的 `.yearitem`、`.styleitem` 規則刪除。
