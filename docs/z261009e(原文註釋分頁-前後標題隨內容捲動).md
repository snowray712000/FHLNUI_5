# 7.5.8.3 原文、註釋分頁：前 後 標題隨內容捲動

## 目標
原文 (parsing)、註釋兩個右側分頁原本用左右兩側整高的 ❮ ❯ 大箭頭 (`.parsingSecBack` / `.commentSecBack`…) 與角落小標題；改成跟串珠 (`index/tsks/renderTsk.js`) 一致的按鈕列：`前 後 [書卷背景] 標題`。

## 試過又放棄的做法
先做成固定的上下兩列 (flex 直排)，但佔 2 列高度，字型大時更明顯。改成**隨內容捲動**：一列在捲動內容最前面 (捲動時被推走)，一列在最後面 (捲到底不必回到上面)。

## 結構
- `index/InfoBar.es2023.js` `infoBarHtml({ prev, next, extrasHtml, title, pos })`：`div.toolbar.tsk.info-bar`，沿用串珠的 `#fhlInfoContent .toolbar.tsk .btn` (字與高跟介面大小)；前 / 後帶 `book` / `chap` / `sec` 屬性，沿用原 class (`parsingSecBack/Next`、`commentSecBack/Next`) 所以 click 處理沒動；沒有上一 / 下一節 (創1:1、啟22:21) 時是 `disabled` 按鈕，版面不跳動；標題 `flex: 1 1 0` 超長截斷、`title` 看全文。
- 註釋：`#commentScrollDiv` 是捲動容器，工具列 `prepend` / `append` 在 `renderCommentDTexts` **之後** (它會清空容器)；「書卷背景」(`.commentBackground`，`ps.chap == 0` 時是「返回註釋」) 在前 後之後、標題之前。
- 原文：`#parsingBody` flex 直排 = `#parsingTop` (上列在它最前面) / `#parsingSplit` (12px) / `#parsingTable` (`flex: 1`，下列在它最後面)。灰框拖曳改用 `#parsingTop.offsetHeight` 當起點，`--parsing-top-h` 不再含工具列。`#parsingTable div` 有 `padding: 6pt` 與陰影，工具列要用較高優先序覆蓋。
- 拿掉的 css：`.commentSecBack/Next`、`.parsingSecBack/Next` (含 span / hover)、`#commentTitle`、`.commentBackground` 舊的 absolute 樣式、`#parsing-where-title`；`#parsingTop` 左右內距 50px (給大箭頭用) 改 10px。

開發站實測：兩個分頁最前、最後都有工具列；原文按「後」跳 2:19 → 2:20、標題更新；灰框拖曳有效；捲到底時下列看得到。沒在簡體模式測。
