# 對話框：點標題列 (拖曳) 之後，按 Esc 沒反應 (7.5.16.6)

## 現象

開著任何對話框，按 Esc 通常會關閉；但先點 (拖) 標題列移動它，再按 Esc 就沒反應，只有點內容區之後 Esc 才有效。看起來像 bug。

## 原因

- Esc 關閉是 jQuery UI dialog 的 `closeOnEscape`：`keydown` 掛在 `.ui-dialog` 元素本身，所以**焦點要在對話框裡面**，鍵盤事件才到得了它。
- jQuery UI 1.12.1 的 draggable 在 mousedown 時會把目前焦點元素 `blur()` (`_blurActiveElement`)；標題列的 mousedown 先 `uiDialog.focus()`，緊接著 (事件往上冒到 `.ui-dialog` 的 draggable handler) 又被 blur 掉，焦點落到 `<body>`。重現：標題列 mousedown 後 `document.activeElement` 是 `BODY`，不在對話框裡。
- 點內容區沒事：內容區的 mousedown 沒有 draggable 的 blur，點到非可聚焦的地方，焦點會落到最近的可聚焦祖先 `.ui-dialog` (`tabindex="-1"`)。

## 修正 (`index/DialogEsc.es2023.js`，`index.js` 引入)

在 `document` 層 (比對話框的 draggable handler 晚) 掛一個委派的 `mousedown`：點到 `.ui-dialog-titlebar` 或 `.ui-dialog > .ui-resizable-handle` (縮放把手，同理)、且不是關閉鈕，若焦點不在該對話框裡，就把焦點放回 `.ui-dialog` (`focus({ preventScroll: true })`，`.ui-dialog` 沒有外框)。
所有接在 `<body>` 下的 jQuery UI 對話框 (`DialogHtml`、交互參照預覽、搜尋、SN 字典、SN 篩選、字型大小、版本資訊、譯本選擇、書卷章...) 統一處理，不必每種各寫一份；對話框裡本來就有焦點 (例如搜尋框打字) 時不動。

## 驗證

真實滑鼠拖標題列 + 真實按 Esc 都關得掉：SN 篩選、SN 字典、搜尋、交互參照預覽。其餘 (字型大小、SN 說明、書卷章、版本資訊、譯本選擇) 以腳本模擬標題列 mousedown，確認焦點留在對話框內 (Esc 之後就走 jQuery UI 原本的流程)。

## 全螢幕時，焦點在對話框按 Esc 不要退出全螢幕 (同 7.5.16.6)

瀏覽器的 Esc 一定會退出全螢幕，`keydown` 的 `preventDefault` 擋不住 (保留鍵)。Chromium 系 (Chrome / Edge) 有 **Keyboard Lock API**：全螢幕中 `navigator.keyboard.lock(['Escape'])` 之後，Esc 就是一般按鍵、會送到頁面，jQuery UI 才收得到、關掉對話框；要退出全螢幕改成「按住 Esc 約 2 秒」或按全螢幕鈕。
- `DialogEsc.es2023.js` 的 `syncEscLock`：**只在「全螢幕且焦點在 `.ui-dialog` 裡」才 lock**；焦點離開、對話框關掉、離開全螢幕就 `unlock()`。所以第一次 Esc 關對話框 (焦點隨之離開 → 解鎖)，第二次 Esc 才照常退出全螢幕；沒有對話框時 Esc 完全不受影響。
- 觸發時機：`focusin`、`focusout` (等一個 tick 讓焦點落定)、`fullscreenchange` / `webkitfullscreenchange`、`dialogopen` / `dialogclose`。與上面「點標題列後把焦點放回對話框」搭配：點標題列後焦點在對話框裡，才會 lock。
- **Safari、Firefox 沒有這個 API**，行為不變 (Esc 仍會退出全螢幕，也關不掉對話框是兩件事：這時對話框是否同時關閉不一定)。需要 secure context (https 或 localhost / 127.0.0.1)。
- 驗證：開發用的內嵌瀏覽器進不了真正的全螢幕，改用模擬 (覆寫 `document.fullscreenElement`、換掉 `navigator.keyboard.lock / unlock`)：全螢幕 + 開對話框 → `lock(['Escape'])`；關對話框 → `unlock()`；非全螢幕開對話框 → 不 lock；全螢幕沒對話框 → 不 lock。**真正的全螢幕沒有實測**，請在 Chrome / Edge 試。

## 沒做 / 之後

- 焦點在對話框外 (例如點了經文區) 時按 Esc，仍不會關閉對話框 (同以前)；只修「點標題列 / 縮放把手」這個像 bug 的情況。
