# 複製：「繼續選」不連續片段 (branch `copy-multi-select`)

反白一段後，可以再加選另一段 (不連續)，一次複製 (`index/LecCopyTable.es2023.js`)。片段可以在同一個 cell、不同 cell (跨 row)、不同欄 (跨 column)。

## 操作

同一格反白時按鈕是 **文字 | 含出處 | 繼續選** (原本是前兩個)：

| | 電腦 | 平板 (沒有 Ctrl) |
|---|---|---|
| 進入繼續選 | 按「繼續選」，或 Ctrl / ⌘ + 按下 (通常不會放開) | 按「繼續選」 |
| 這時 | 整排按鈕先藏起來 (免得擋住要選的字)；先前的反白變成底色 (`::highlight(lct-multi)`)，原生選取收掉 | 同左，水滴也消失 |
| 選下一段 | 拖曳 / 雙擊選字；放開滑鼠按鈕才再跳出 | 從另一處長按，出現新的水滴與按鈕；調水滴時，原本那段不變 |
| 按鈕跳出的位置 | 「最低」(DOM 順序最後) 那一段旁，同樣三個鈕；Ctrl 還按著就沒有「繼續選」 | 同左 (畫面下方中央) |
| 兩段接在一起 / 重疊 | 自動併成一段 (電腦平板都一樣)，併成一段後就是一般單段 | 同左 |
| 取消 | Esc；`#continuing` 中點空白過 400 ms 沒選到字 → 放棄繼續，按鈕回來 (先前的反白留著)；選到別的 cell / 跨格 → 先前的作廢 | 輕點空白 (不在繼續選中) → 全部取消 |

Ctrl 一按，按鈕藏起來；沒按滑鼠就放開 Ctrl (例如只是 Ctrl+C) → 按鈕回來。

## 輸出

單一 cell、不連續的反白：每一節都列節碼，沒選到的頭尾與段與段之間以 `...` 表示。

- 「文字」：`3 ... 長了銹； ... 4 ... 收割莊稼， ...`
- 「含出處」：`3 ... 長了銹； ... 4 ... 收割莊稼， ...(雅5:3-4_和合本)`；節不連續時出處是 `雅5:1,3-4` (`cvtAddrsToRef`)
- 同一節有兩段：`3 ... 金銀都長了銹 ... 又要吃你們的肉 ...`
- Ctrl+C 同「文字」
- 單段 (沒按過繼續選) 的「文字」仍是照反白的原文，「含出處」不變 (`3 ... 你們在這末世只知積攢錢財。 4 工人 ...(雅5:3-4_和合本)`)
- 括號前沒有空格 (沿用原本 `...(雅5:9_和合本)` 的寫法)

程式：`multiCellText(segs, withCite)` → 每個碰到的 `.lec` 用 `partsOfLec(lec, ranges, base)`；原本單段的 `toCitedText` 也改用 `partsOfLec` (單段 = 一個 range)，兩者同一套規則。

## 為什麼要自己記

Chrome / Safari 只有一段原生選取 (Firefox 的 Ctrl + 拖曳才有多段)，所以先前的片段記在 `#extra` (`Seg = { scope, range }`)，`mergeSegs` 依 DOM 順序排序、重疊 / 相接併起來；`#group()` 檢查先前的片段與現在的選取都在同一格 (`cellOfSeg`)。

## 跨 cell 的多段 (沒跨欄跨 row、跨欄)

- **整格展開只發生在「單次選取」跨 cell** (滑鼠按下到放開之間的選取，原本的行為，不變)。用「繼續選」加選的片段，各自保留選到的字、不展開：`Seg.whole` 有值才是單次跨格展開的 (存那些格的全部節，`snapSeg`)，沒有就照 `range`
- 單次跨格的片段留著整格底色 (`.lct-cell`)；加選的片段用 `::highlight(lct-multi)`；兩者可並存。`mergeSegs` 只併「沒有 whole」的片段
- `tableOfSegs(segs)` 把所有片段合成一個 `CopyTable`：`range` 是 `LecParts` (`Map<lec, Range[] | null>`，null = 整節)，`shade` = 要上底色的整格。下游的 `toPlainText` / `toCitedText` / `toClipboardData` / `toMarkdown` / `toAscii` 都沒改，只有 `lecRuns` 認得 `LecParts`，沒選到的頭尾、段與段之間以 `...` 表示 (`partRuns`，同單格的 `partsOfLec`)
- 沒有被碰到的節 / 列不放進表格 (mode 1 每節一列時，中間沒選到的節不放，`columnsByVerse` 的 `rowsOnly`)
- 按鈕：
  - 片段都在同一個 cell → 文字 | 含出處 | 繼續選
  - 沒跨欄、跨 row → 文字 | 連續文字 | 連續含出處 | 表格 | MD | ASCII | 繼續選 (`...` 的位置同單格)
  - 跨欄 → 表格 | MD | ASCII | 繼續選 (沒選到的格留空)
  - 「繼續選」每種情形都有
- Ctrl+C：同一格 → 同「文字」；跨 cell → 複製對照表 (含 html)

## 狀態

- `#continuing`：等著選下一段。電腦：滑鼠放開 (`#pointerDown` false) 且有新選取才結束；觸控：長按出現選取就結束
- `#ctrlDown` / `#ctrlFresh`：Ctrl 按著 / 剛按下還沒按滑鼠 (這時按鈕藏起來)
- `#hideBar()` 只藏按鈕 (狀態、先前的片段留著)；`#hide()` 全部重設
