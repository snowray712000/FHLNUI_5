# 信望愛資源 (▦) — 各連結說明與首頁比對

工具列 **▦ 信望愛資源** 面板 (`#resourcesPanel`，定義在 `index/appSkeleton.es2023.js`) 每個連結只有一個標題，很多猜不出是什麼。
本文逐一打開每個連結 (2026-09-30)，記下「它是什麼」、「和本工具哪個功能重疊」，再和信望愛首頁 <https://bible.fhl.net/index.html> 比對，找出首頁有、面板沒有的項目。

面板每個連結下面有一行灰色小字簡介 (取自本文「是什麼」欄的縮寫)。連結資料在 `appSkeleton.es2023.js` 的 `RESOURCES` 陣列 `[網址, 標題, 簡介]`，由它產生面板 HTML；樣式 `#resourcesPanel a small` (`fhl.css`)。沒用 tooltip：手機沒有 hover。

圖例：**對應** = 本工具已有類似功能，差在哪裡寫在後面。
