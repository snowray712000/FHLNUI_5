# 7.3.1 複製按鈕依選取情形變化 (文字 / 連續文字 / 連續含出處 / 表格 / MD)

延伸 z261001a、z261002c。原本跨格一律只有「複製對照表」+「MD」，但常需要像以前一樣的純文字。
按鈕改為依反白範圍顯示 (`index/LecCopyTable.es2023.js`)：

| 情形 | 條件 | 按鈕 |
|---|---|---|
| Case1 | 起訖同一格 | 文字 |
| Case2 | 跨列、不跨譯本欄 (交錯模式多譯本也算) | 文字 \| 連續文字 \| 連續含出處 \| 表格 \| MD |
| Case3 | 並排且跨譯本欄 (`isCrossCol`) | 表格 \| MD |

- **文字**：同一格照反白起訖；跨列時每個 `.paragraph` 一行，有經文位置 (搜尋結果、交互參照) 時行首加位置 (`toPlainText`)
- **連續文字**：同上但列與列、格內換行都接成空白
- **連續含出處**：每個譯本一段，各節含節碼接成連續文字，結尾 `(出處_譯本)` (`toCitedText`)
  - 出處用 `cvtAddrsToRef` (與交互參照同一套)：`詩107:6,13,19`、`詩33:5;35:6-7,11;創1:2-3`；簡體模式用簡體書名縮寫
  - 譯本名用 `verName` (cname)；`unv` 例外，正式名稱 FHL和合本，但呈現為「和合本」
  - 交錯多譯本：每個譯本一段、各自帶出處，段間換行
- **表格**：原「複製對照表」改名，`text/html` table + tab 分隔純文字
- Ctrl+C 跨格仍是複製對照表 (未改)
- 按鈕改成 `#btns` 物件 (`text/flat/cite/table/md`)，`#copyByButton(kind)`；按鈕之間的分隔線只畫在看得到的相鄰按鈕間 (`.lct-btn:not([hidden]) ~ .lct-btn:not([hidden])`)
- `CopyTable` 新增 `isCrossCol`

## 注意

- `cvtAddrsToRef` 靠全域 `Enumerable` (linq)；瀏覽器有，vitest 的 node 環境沒有，所以 `toCitedText` 沒有單元測試，靠手動驗證
- 連續文字各節間用空白接 (節碼前後需要)；若要完全無空白，改 `toPlainText` 的 `join(' ')`
