# 前言

- 這是關於聖經相關的網站
- 功能
  - 提供許多譯本
  - Strong Number 的資料
    - 和合本, KJV, 都提供 Strong Number 的資料。提供的方式是將對應的 SN 資料，放在經文的後面，例如
      - 1 奉<1223>神<2316>旨意<2307>，作基督<5547>耶穌<2424>使徒<652>的保羅<3972>，寫信給在<1722>{<3588>}以弗所<2181>的聖徒{<3588>}<40>，{<2532>}就是<1510>(5723)在<1722>基督<5547>耶穌<2424>裡有忠心<4103>的人。
      - 其中，{...} 是原文有，但譯本沒譯出來的字詞。<...> 是非動詞時態的 SN。(...) 是表示動詞時態的 SN。
  - 對於章節，提供一些工具
    - 原文Parsing。針對其中一節經文。api 會是純文字資料。程式關鍵字 parsing
    - 註釋資料。某幾節經文，會是一份註釋資料。api 會是純文字資料。程式關鍵字 comment
    - 講道資料。是錄音檔或影片檔，也是某段經文對應一段資料，api 資料會是一個「連結」與「偵述」。程式關鍵字 preach
    - 串珠資料。是某一本叫「串珠」的書籍，每一節經文，都會有一些「字詞」的交互參照。api 是純文字資料。程式關鍵字 tsk
    - 典藏資料。是聖經的「照片檔」，每種譯本。api 提供的是 照片的連結。
    - 有聲資料。是朗讀聖經的 錄音檔，通常是每一章經文對應一段，但可能有多種譯本。api 是回傳 mp3 的連結。
    - 地圖資料。有些章節，有一些地點是有提供資訊的，藉著與 openstreet map 的整合，會顯示在地圖上。
    - 圖片資料。有些關鍵字，有一些圖片，例如「七燈檯」「無花果」可能有人去拍過照片之類的。
    - 原文字典資料。每個 SN，都有對應的 字典資料，api 提供 2 個來源，一個是 CBOL (Chinese Bible On-line) 的資料 ，原始是以 KJV 譯本為主的字典翻譯，另一個是 浸宣出版社 授權的 原文字典資料。
    - 原文彙編資料。就像關鍵字搜尋一樣，輸入 SN，就會回傳出現章節位置。
    - 經文搜尋資料。輸入關鍵字，就會回傳出現章節位置。
    - 同源字資料。(新約 才有)
  - 小工具
    - 章節瀏覽歷史。快速切換到之前看過的章節。
    - 上一章、下一章、目錄。
    - 切換到上次看的章節、下次看的章節。
    - 同 SN 滑鼠移過，同 SN 會標記為紅色，同源字會標記暗紅色。(具 SN 限定)
    - 滑鼠經過 SN，就會顯示 SN 對應資訊。
    - 若有「交互參照」，可直接點擊，以對話方塊的方式快速呈現，或跳至對應章節。例如有些譯本會提供相關經文的交互參照，有的交互參照則是由註釋中的內文出現。
- 設定
  - 字型大小: 一般字型大小，希臘文字型大小，希伯來文字型大小，Strong Number 字型大小。
  - 顯示經文模式：
    - 1 不分段_併排 ... 多譯本時，並併顯示。(即 多 columns 的感覺，同一節，同 row)
    - 2 不分段_交錯 ... 多譯本時，交錯顯示。(即 多譯本，仍然只有 1 column，但一節，有多 row)
    - 3 分段_併排 ... 可以想像，模式 1，每 row 就是一節經文，而模式 3 則是 每 row 是一段連續的經文。目前「分段」暫以「新譯本」的分段為參考。
    - 4 分段_交錯 ... 模式 2 的分段版本。
