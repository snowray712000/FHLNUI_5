# 設定面板：開關改成按鈕、SN 設定改齒輪、? 搬進對話框標題 (7.5.16.2)

## 為什麼

- 設定面板的「原文SN」「即時SN」「地圖顯示」「圖片顯示」各佔兩行 (標籤一行、ON/OFF 滑動開關一行)，左欄很窄，小螢幕要捲動。
- 原文SN 旁的漏斗只有約 10 × 19px，遠小於手指的 44px 最小可按範圍 (`--touch-min`)；旁邊還塞了一個 `?`。
- 這個按鈕開的是「SN 設定與篩選」對話框，比起「篩選」更像設定，且專案裡開設定對話框的按鈕本來就是 ⚙ (字型大小、搜尋範圍、複製選項)。

## 做法

- `index/ToggleBtn.es2023.js` 的 `toggleBtnHtml(id, name, checked)`：`<label class="tgl-btn">` 裡面一個隱藏的 checkbox (id 不變) 加名稱。
  原本的 `change` 事件、`.prop('checked')`、`$('#snOnOffSwitch').trigger('change')` (`SnFilterDialog.#setMode` 用) 都照用，只換了外觀。
  - 開 = 淡藍底、藍字、藍框、粗體 (最初版本前面有 ✓，後來拿掉)；關 = 灰框；名稱不再有冒號。
  - 高度 `max(26px × --ui-k, --touch-min)`：滑鼠 26px，手指 (`pointer: coarse`) 44px。一行一個，比原本兩行還矮。
  - `#settings li > div > div.tgl-row:first-child`：蓋掉 `#settings li>div>div:first-child` 的 `float: left; margin-right: 20px`。
- 套用在 SnSelect (原文SN + ⚙)、RealTimePopUpSelect (即時SN)、MapTool (地圖顯示)、ImageTool (圖片顯示)。
  **繁簡切換 (GbSelect) 沒改**：它是二選一 (繁 / 簡)，不是開關，仍用 `.onOffSwitch`。
- ⚙ 仍是 `#snFilterBtn` (事件、右鍵快速選單、`.active` 切換都沒動)：`fa-cog`，同樣 `max(26px × --ui-k, --touch-min)` 的方形按鈕；篩選開啟 (`mode == 'filter'`) 時整個變藍 (原本漏斗的 `.active` 是紅色，改成 accent)。
- `?` 搬到「SN 篩選顯示」對話框標題列 (`SnFilterDialog.open` 在 `.ui-dialog-title` 後加 `helpButtonHtml('原文SN')`，`bindIntroHelp(titlebar, 'sn')`)。
  對話框裡「讀經組合」旁還有一個 `?`，那個是讀經組合說明，兩個不同。

## 對齊的坑

- 按鈕與 ⚙ 不同高：Bootstrap 的 `label` 有 `margin-bottom` (約 8px)，`.tgl-btn` 的外框變 34px，用 `align-items: center` 排的 ⚙ 就比按鈕低 4px。`.tgl-btn { margin: 0 }`，且 `.tgl-row` 改 `align-items: stretch`，兩者永遠同高。
- 標題列的 `?`：`.intro-help` 的 `vertical-align: middle` 對中文字會偏低。`.ui-dialog-title:has(> .intro-help)` 改 flex + `align-items: center` (文字與 ? 中心只差 0.2px)；只套用在有 ? 的標題列。

## 7.5.16.5：再縮短、同一列放兩個

- 名稱縮短：原文SN → **SN**、即時SN → **即時**、地圖顯示 → **地圖**、圖片顯示 → **照片** (完整名稱放在按鈕的 `title`，`toggleBtnHtml` 多了 `title` 參數)。
- 同一列：`⚙ SN 即時` 與 `地圖 照片`。`appSkeleton` 的 `<li class="tgl-li">` 放兩個 div (`#snSelect` + `#realTimePopUpSelect`、`#mapTool` + `#imageTool`)；`#settings li.tgl-li` 是 flex，裡面的 div 用 `display: contents`，⚙ 與按鈕直接是 flex 子項，`align-items: stretch` 所以一樣高。不再有 `.tgl-row` 包裝。
- 字型大小的 ⚙ 與 SN 的 ⚙ 同一個樣式 (`.sn-filter-btn, .fs-gear`：方框、圓角、`max(26px, --touch-min)`)；字型那一列固定大小 (不乘 `--ui-k`)，所以它的 ⚙ 覆寫成固定 26px。
- 繁簡切換：拿掉「繁簡切換:」標題 (停在開關上看 `title`)，開關文字 **繁 / 簡 → 繁中 / 簡中**；兩個字放不下 59px，`.onOffSwitch-wide` 寬 80px，旋鈕未勾位置 = 寬度 − 16 (64px)。
- 主題：拿掉「主題:」標題 (`ThemeTool` 不再畫標題)。
- TSK顯示模式：只有串珠會用到，從設定面板拿掉 (`Settings.es2023.js` 的 `render_tsk_show_mode` / `register_tsk_show_mode` 刪除)，改成串珠工具列上面那一列的 ⚙ (`index/tsks/renderTsk.js` 的 `.btnTskGear` + `openTskModeMenu`，選單沿用 `.snf-menu`，選了存 `ps.tsk_show_mode` 並重畫串珠)。順手修掉舊設定的 `ps.tsk_show_mode || 2` (0 = 英文被當成假值，選英文重開會變全名)；現在 `?? 1` (預設 1 = 中文縮寫，與 `TPPageState` 一致)。

## 7.5.16.5 續：字型大小、下拉選單

- 字型大小：拿掉「字型大小:」標題 (看到 A− A+ 就知道，`title` 留著)，順序 **⚙ A− A+ 100%**。
  - 原本控制列是 `#settings li>div>div:first-child` 的 `float: left`，標題浮在左邊、控制列貼上緣 (看起來是 top align)；現在 `.fs-ctl` 是 `display: flex; align-items: center`，並蓋掉那條 float。
  - 字型那一列固定大小 (不乘 `--ui-k`)：⚙ 與 A− A+ 都是 `max(26px, --touch-min)` 高，數字 `100%` 垂直置中。
- 下拉選單 (顯示切換、交互參照、選章、註腳) 全部拿掉上方的標題列，改成整列寬的下拉，選項文字帶名稱 (`交互參照：每次詢問`、`選章：依視窗大小` (原「切換經文方法」)、`註腳：點擊顯示`；顯示切換的選項 `併排（單節）` 本來就自明)。原本每個佔兩行，現在一行；完整名稱放 `title`；選項文字也補上 `gbText` (以前選項沒轉簡體)。
  - 高度與按鈕一致：`#settings li select { min-height: max(26px × --ui-k, --touch-min) }`；`li > div:has(> select)` 改 `display: block` 才能撐滿。
- 列的順序：字型 → 顯示切換 → ⚙ SN 即時 → 地圖 照片 → 繁中 / 簡中 → 主題 → 交互參照 → 選章 → 註腳 (常動的在上面；繁簡、主題、後面三個設一次就不太動)。顯示切換 (多譯本對照方式) 從原本第 5 列提到第 2 列。

## 7.5.16.5 續：顯示切換改兩組分段按鈕、交錯每節加虛線

- 顯示切換 (`Show_mode.es2023.js`)：`ps.show_mode` 仍是 1 ~ 4 (1 單節併排、2 單節交錯、3 段落併排、4 段落交錯)，UI 拆成兩個正交的選擇：**[單節｜段落]** 與 **[併排｜交錯]** (`isPara = m >= 3`、`isSide = m % 2 == 1`，按一個按鈕只改它那一軸再組回 1 ~ 4)。`.sm-ctl` 是 `flex-wrap`，兩組放得下就同一列、字大 / 左欄窄時自己換成兩列；按鈕高度 `max(26px × --ui-k, --touch-min)`。事件委派在 `#show_mode`，按了先重畫按鈕再重畫經文。順手拿掉原本 `pageState.show_mode = …` (引用不存在的全域)。
- 交錯 (mode 2 / 4) 每節結束的虛線：`render_interleaved` (`FhlLecture_render_core.js`) 對每一節 (mode 4 是每一段) 的最後一個譯本的 `.paragraph` 加 `.il-end`，CSS `.vercol > .paragraph.il-end:not(:last-child) { border-bottom: 1px dashed var(--col-line) }`，與併排時譯本之間的虛線同色同樣式 (最後一節不畫)。只有主經文區；交互參照 / 搜尋結果的交錯 grid 本來就有每列的橫線。

## 7.5.16.5 續：主題也用分段按鈕

`ThemeTool.es2023.js` 改成與顯示切換同一套 `.sm-ctl` / `.sm-seg` / `.sm-btn`：兩列 `[淺色｜深色]`、`[自動｜高對比]` (`.sm-rows`：一組佔滿一列)。舊的 `.th-ctl` / `.th-btn` / `.th-hc` CSS 刪除。
- 模式仍是 `auto` / `light` / `dark` / `hc-light` / `hc-dark` (`Theme.s.mode`)；淺色 / 深色 / 自動三個互斥 (亮的是目前的)，**高對比是開關**：亮 = hc，按了切 `hc-` 前綴；自動時它是灰的、不能按 (跟隨系統的「增強對比」)，`title` 說明。
- 踩到的坑：舊規則 `#settings li div div { display: inline-block }` (優先度 1,0,3) 蓋掉 `.sm-ctl { display: flex }` / `.sm-seg { display: flex }`，兩組按鈕變成行內並排、`flex-basis` 無效。這幾個要加 `#settings` 前綴 (`#settings .sm-ctl` …) 才贏；`#themeTool`、`#show_mode` 的外層 div 也要 `display: block`。

## 7.5.16.5 續：繁中｜簡中也用分段按鈕

`GbSelect.es2023.js` 的滑動開關改成 `[繁中｜簡中]` 分段按鈕 (同顯示切換、主題的 `.sm-ctl` / `.sm-seg` / `.sm-btn`)，事件改成委派在 `#gbSelect` 的 `.sm-btn` click (`data-v` = `big5` / `gb` → `ps.gb` 0 / 1，同值不動)，其餘 (重畫經文、標題、書卷名、`alert('重新載入後生效')`、存 ps) 與以前相同。
至此舊的 `.onOffSwitch*` 滑動開關沒有人用了：CSS 整段與 `theme-vars.css` 的 `--switch-on-bg` / `--switch-off-bg` / `--switch-knob` 一併刪除；上面「繁簡切換沒改」「`.onOffSwitch` 還在」「繁中 / 簡中 80px 開關」的說明已被取代。

## 7.5.16.5 續：改用 Bootstrap 按鈕 (自訂樣式太素)

分段按鈕 / 開關按鈕最初是自訂樣式 (透明底、細框)，與其它地方的 Bootstrap 按鈕 (串珠工具列 前 / 後 / ⚙ 等) 並排顯得素、像拿掉 CSS。改成直接用 Bootstrap 5.1 的類別，`theme-3rd.css` 已把 `.btn-outline-secondary` 等接上主題色：
- 所有設定面板按鈕：`btn btn-sm btn-outline-secondary set-btn` (`.set-btn` 只定高度 `max(26px × --ui-k, --touch-min)`、字級、內距)。開關按鈕是 Bootstrap 的 `input.btn-check` + `label.btn` (`ToggleBtn.es2023.js`)；⚙ 是 `<button>`；A− A+ 用 `.fs-step` (不再用 `.fs-btn`，那個留給字型對話框)；分段按鈕是 `.btn-group.sm-seg` 裡的 `.sm-btn`。
- 「開」(勾起 / 選中 / SN 篩選開啟的 ⚙)：字由灰變藍 (`--accent-fg`)、底淡藍 (`--accent-bg`)、框藍 (`--accent`)、粗體，**不加 ✓** (灰 / 藍已經夠明顯，使用者確認不需要；最初我誤會截圖裡的 ✓ 是想要的)；**不是**整顆實心藍底白字 (第一版那樣，使用者說原本是字變藍、底淡藍)。滑過去只是淡淡的底 (`--hover-bg`)，不用 Bootstrap 預設的整個填灰、字變白。
- **合併成一組**：`⚙｜SN｜即時`、`地圖｜照片`、`A−｜A+` 與分段按鈕 (`.sm-seg`) 都是「只有兩端有圓角、中間框線疊在一起」，圓角與單顆按鈕一樣大 (8px，Bootstrap 的 `.btn-group` 預設只有 .2rem，所以另外蓋)。同一列的 `li.tgl-li` 是 `gap: 0` 的 flex，按鈕以 `.grp-first` / `.grp-mid` / `.grp-last` 標位置 (`toggleBtnHtml` 的 `pos` 參數；`margin-left: -1px` 疊框，亮的那顆 `z-index: 1` 讓藍框蓋過旁邊的灰框)。組內的開關各自獨立，可同時亮 (SN 與即時、地圖與照片)，分段按鈕則只亮一個。
- Bootstrap 的 `label` 有 `margin-bottom`，會把同一列撐高、⚙ 與按鈕不一樣高：`#settings .tgl-btn { margin-bottom: 0 }`。
- 下拉選單：`select.set-select` (外框、圓角同按鈕；`appearance: none`，箭頭用兩個 `linear-gradient` 三角形 + `currentColor`，不寫死顏色)。
- 這些樣式在 `fhl.css` 的「設定面板的按鈕、分段按鈕、下拉選單」一段。**小心**：刪掉舊 `.onOffSwitch` CSS 時，曾因刪除範圍切太大，把這一段 (當時是前面新寫的) 一起刪掉，設定面板變成完全沒樣式；改以此版重寫。之後改這一段前先看它的前後邊界。

## 7.5.16.5 續：字型大小、各分頁工具列也合成一組

- 字型大小：`⚙｜A−｜A+` 合成一組 (`.grp-first` / `.grp-mid` / `.grp-last`)，`100%` 在組外 (`.fs-val` 的 `margin-left`)；`.fs-ctl` 的 `gap` 改 0，拿掉 ⚙ 的 `margin-right`。
- 右側各分頁的工具列 (串珠、註釋、原文解析共用 `.toolbar.tsk`)：`前｜後｜[書卷背景]｜標題｜⚙` 合成一組，只有兩端 8px 圓角、中間框線疊在一起 (`margin-left: -1px`，滑過去 `z-index: 1`)。
  - 用 `:first-child` / `:last-child` 決定圓角，所以不論有沒有書卷背景、有沒有 ⚙ 都對 (串珠最後是 ⚙，註釋 / 原文最後是標題)。
  - `.toolbar.tsk` 一律 `display: flex; gap: 0`：串珠原本是行內按鈕、靠換行字元的空白隔開，改成 flex 後空白沒了；`.btnTitle` 一律吃剩下的寬度 (串珠的標題以前是自然寬度)。
