# 設定面板：開關改成按鈕、SN 設定改齒輪、? 搬進對話框標題 (7.5.16.2)

## 為什麼

- 設定面板的「原文SN」「即時SN」「地圖顯示」「圖片顯示」各佔兩行 (標籤一行、ON/OFF 滑動開關一行)，左欄很窄，小螢幕要捲動。
- 原文SN 旁的漏斗只有約 10 × 19px，遠小於手指的 44px 最小可按範圍 (`--touch-min`)；旁邊還塞了一個 `?`。
- 這個按鈕開的是「SN 設定與篩選」對話框，比起「篩選」更像設定，且專案裡開設定對話框的按鈕本來就是 ⚙ (字型大小、搜尋範圍、複製選項)。

## 做法

- `index/ToggleBtn.es2023.js` 的 `toggleBtnHtml(id, name, checked)`：`<label class="tgl-btn">` 裡面一個隱藏的 checkbox (id 不變) 加名稱。
  原本的 `change` 事件、`.prop('checked')`、`$('#snOnOffSwitch').trigger('change')` (`SnFilterDialog.#setMode` 用) 都照用，只換了外觀。
  - 開 = 亮藍底、粗體、前面一個 ✓ (不只靠顏色，色盲也看得出)；關 = 灰框；名稱不再有冒號。
  - 高度 `max(26px × --ui-k, --touch-min)`：滑鼠 26px，手指 (`pointer: coarse`) 44px。一行一個，比原本兩行還矮。
  - `#settings li > div > div.tgl-row:first-child`：蓋掉 `#settings li>div>div:first-child` 的 `float: left; margin-right: 20px`。
- 套用在 SnSelect (原文SN + ⚙)、RealTimePopUpSelect (即時SN)、MapTool (地圖顯示)、ImageTool (圖片顯示)。
  **繁簡切換 (GbSelect) 沒改**：它是二選一 (繁 / 簡)，不是開關，仍用 `.onOffSwitch`。
- ⚙ 仍是 `#snFilterBtn` (事件、右鍵快速選單、`.active` 切換都沒動)：`fa-cog`，同樣 `max(26px × --ui-k, --touch-min)` 的方形按鈕；篩選開啟 (`mode == 'filter'`) 時整個變藍 (原本漏斗的 `.active` 是紅色，改成 accent)。
- `?` 搬到「SN 篩選顯示」對話框標題列 (`SnFilterDialog.open` 在 `.ui-dialog-title` 後加 `helpButtonHtml('原文SN')`，`bindIntroHelp(titlebar, 'sn')`)。
  對話框裡「讀經組合」旁還有一個 `?`，那個是讀經組合說明，兩個不同。

## 對齊的坑

- 按鈕與 ⚙ 不同高：Bootstrap 的 `label` 有 `margin-bottom` (約 8px)，`.tgl-btn` 的外框變 34px，用 `align-items: center` 排的 ⚙ 就比按鈕低 4px。`.tgl-btn { margin: 0 }`，且 `.tgl-row` 改 `align-items: stretch`，兩者永遠同高。
- 標題列的 `?`：`.intro-help` 的 `vertical-align: middle` 對中文字會偏低。`.ui-dialog-title:has(> .intro-help)` 改 flex + `align-items: center` (文字與 ? 中心只差 0.2px)；只套用在有 ? 的標題列。

## 沒做 / 之後

- 右鍵快速選單沒有「說明」項目 (看 SN 說明要先開對話框)。
- `.onOffSwitch` 的 CSS 還在 (GbSelect 用)；ON / OFF 文字只剩 GbSelect 的「繁 / 簡」、顯示模式的「並列 / 交錯」。
