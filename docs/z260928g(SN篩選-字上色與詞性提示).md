# SN 篩選 P4：字上色與詞性提示

接續 [z260928e(SN篩選顯示-規畫)](z260928e(SN篩選顯示-規畫).md) 的 P4、[z260928f(SN篩選-讀經組合與說明)](z260928f(SN篩選-讀經組合與說明).md)。

## 緣由

P1–P3 決定「哪些 SN 編號要顯示」，但編號本身還是雜訊：要看出句子骨架 (哪些是動詞、哪裡轉折)，最直接的是讓**字本身上色**，像 STEP Bible 的 color-coded grammar。P2 P3 已經有詞性 (`sn_pos`) 與每個字的動詞形態 (`sn_morph` + `tvm_table`)，P4 只是把它們畫在字上。

## 字在 DOM 中已經有了

不必自己切字：各譯本在產生 DText 時已把 SN 前面那段文字包成 `span.sn-text[sn][tp]` (`attach_sn_text.js`、`add_sn_text.js`、`cvtDTextsToHtml` 中「有 sn 沒 tp2」的)。例：

```html
<span class="sn-text" tp="H" sn="7225">起初</span><span class="sn" sn="9002" tp2="WAH">…</span><span class="sn" sn="7225" tp2="WH">…</span>
<span class="sn-text" tp="G" sn="746"> ἀρχῇ</span><span class="sn" sn="746" tp2="WG">…</span>
<span class="sn-text" tp="H" sn="8064"> the heaven</span>…   (KJV)
```

- 字與它的 `.sn` 之間可能夾著 WAH 標記 (9002)，所以往後找「同 SN、同 tp」的第一個 `.sn` (略過時態碼、標記)
- 未譯出的 `{<853>}` 前面沒有字，不會對到
- 少數字沒包成 `.sn-text` (例 fhlwh 的冠詞 ὁ 是普通 span)，就不上色
- 搜尋結果 (`colorBibleText`) 的字沒有包，所以不上色

## 做法

`SnFilter.colorBy`：`'off' | 'pos' | 'verb'`，存在 localStorage `snFilter` 的 `colorBy`。與 SN 顯示模式無關，**SN 關閉時也上色** (這正是用途：不看編號只看顏色)。

`apply()` 每次都跑 `#colorWords(all, verseOf)`：

1. 選取 `.sn, .sn-text, .lec[book], [data-vaddr]`；`.sn-text` 不參加 `groupByVerse` (否則會被當成節的標記)
2. 每個字先清掉上次的 class 與 title (`data-snc` 標示是這裡加的)，再依模式加 `snc-{id}` 與 title
3. 動詞形態共用篩選用的 `#morphCodesOf` (P3 的 `#isMorphMatch` 拆出來)：原文逐字、和合本同次數依順序、時態碼交集

`WORD_COLORS` (`index/SnFilter.es2023.js`)：

| 模式 | 類別 (class `snc-…`) |
|---|---|
| pos 詞類 | neg 否定、c 連接詞 (含質詞)、p 介系詞、v 動詞、pn 專有名詞。字典形可兼多種詞類，依此順序取第一個符合的 (οὐ d\|neg → 否定) |
| verb 新約 (語氣) | ind 直說、sub 假設、vol 命令與祈願、inf 不定詞、ptc 分詞 |
| verb 舊約 (形式) | wy 敘述式、pf 完成式、impf 未完成式、wq 連續式、vol 意志式 (祈使、祈願、鼓勵)、inf 不定詞 (附屬形、獨立形)、ptc 分詞 (含被動分詞) |
| vx | 是動詞，但候選代碼分屬不同類 (例 創1:3 「要有」：祈願式 יְהִי 與敘述式 וַיְהִי 同節，和合本只對到一個)，灰色虛線底線 |

配色 (`fhl.css` 的 `--snc-*`)：動詞/直說/敘述式橘、連接詞 firebrick、介系詞 sienna，與 Parsing 分頁的 `.parsing-verb/conj/prep` 同色系；意志類 (命令、祈願、意志式) 同一種紅、非限定 (不定詞 teal、分詞藍) 冷色，新舊約同概念同色。CSS 放在 `.snAct` 之前，滑鼠移過去的紅色優先。

**詞性提示**：字的 `title` = `SN 詞類 形態`，例 `G4100 動詞 現在 主動 分詞`、`H7121 動詞 Qal 敘述式`、對不準時 `H1961 動詞 Qal 祈願式 / Qal 敘述式`。`morphName()` 由 `MORPH_GROUPS` 的選項名稱組出來 (舊約 `ptcp` → 被動分詞)。詞類模式不載 sn_morph，提示只有詞類。

資料：上色時載 `sn_pos`；動詞形態模式另載 `sn_morph_nt/ot` 與 `tvm_table.json` (`#ensureDataThenApplyAll`)。

## 驗證

- 約1:12 動詞形態：接待、賜 直說；信 分詞；作 不定詞 (和合本、原文、KJV 一致)
- 創1:5 兩個「稱」：敘述式、完成式；1:22 滋生、繁多、充滿 祈使式；說 不定詞附屬形
- 約1:17 詞類：ὅτι καὶ 連接詞、διὰ 介系詞、Μωϋσέως Ἰησοῦ Χριστοῦ 專有名詞
- `tests/snFilter.test.js`：`morphName`、每個形態代碼只屬一個顏色類、每個顏色都有 css
