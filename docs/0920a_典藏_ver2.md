# 1. 功能名稱與用語

- 功能名稱：典藏；使用者也稱為 `ob`。
- `ob` 可能是 Old Bible 的縮寫；入口註解出現 `Old Bible`，但此名稱不是資料範圍的完整定義。
- 使用者以「聖經紙本翻拍照片」「對應經文的古卷」描述內容；不要據此推定所有典藏都是同一類古卷或版本。
- 「目前經節」（原稿 activate address）是概念名稱，不保證程式存在同名變數。
- 必須區分「典藏書籍／版本識別值」與「聖經書卷索引」。例如範例 URL 的 `book=27`，使用者理解為典藏書籍識別值；入口的 `ibook` 則由 `ps.bookIndex - 1` 取得。兩者不可直接視為同一編號系統，完整映射待查。
