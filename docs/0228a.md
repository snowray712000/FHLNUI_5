目標: 生成一個 html 將 Tsk 結果畫出來，叫 tsk2_test.html 與 tsk2_test.js 來完成

動機: 在整合到主專案前，先看一下，大概要長怎樣

特色:
- 畫面比例，通常是 width < height, 像是手機一樣, 因為它佔的是電腦畫面的右邊。
- 按 TSK 資料的特色
  - 回顧 parseTsk 後的 block 
  - type: summary
    - 通常是每一章的第一節。「本章總覽」。
  - type: keyword
    - keyword: 這是關鍵字，通常是從「* 」後面來的
    - items: 這是關鍵字底下的內容，通常是從「\n # 」後面來的
      - type: ref
      - type: text
    - 這種會有多個的可能，每個關鍵字，可能會有 ref 也可能沒有, 因為有的會是 text 有點像注腳的概念。
  - type: refOnly
    - 通常也只會有一個 item，它是這一節經文相關的經文參考，就叫它「相關經文」好了。
  - type: empty
    - 此節沒有資料
- api
  - 會回傳資料
  - 會回傳 上一筆資料、下一筆資料 (通常就是上一節、下一節)

畫面
- 第 1 row 是 「前」「後」「說明」「創 1:1」「設定」
  - 備註: 「創 1:1」這還是需要 ... 因為手機畫面時，可能經文顯示會被遮住。
  - 設定: 將會有一個對話方塊，可以選 書卷名稱：「原始資料/中文簡稱/中文名稱」(但還不用)
    - 這個版本，就預設 中文簡稱
  - 說明: 將會有一個對話方塊說明 (此版本先不做)
- 第 2 row 之後就是 parseTsk 的結果了. 按順序應該是
  - 「本章總覽」(若有)
  - 「本節相關經文」(若有)。
  - 「關鍵字1」
      - 相關經文 (若有)
      - 注腳 (若有)
  - 「關鍵字2」
      - 相關經文 (若有)
      - 注腳 (若有)
  - 「本節無資料」(特例)

套件
- 使用 es2023 fetch 取資料
- 使用 jquery 操作 DOM
- 使用 bootstrap 來快速做出對話方塊等 UI 元件
- 編碼使用 utf8
