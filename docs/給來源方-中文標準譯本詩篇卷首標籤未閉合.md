# 中文標準譯本（csb）詩篇卷首：HTML 標籤沒有閉合

## 一句話

中文標準譯本在詩篇每一卷的第一篇，卷首那一行寫成 `<h3><i>（詩篇73-89【1】`，**`<i>` 和 `<h3>` 都沒有結尾標籤**。接收端用瀏覽器解析 HTML 時，後面整篇經文都被當成這個標題的內容，畫面上就出現原始標籤。

## 怎麼重現

```
https://bible.fhl.net/json/qb.php?chineses=詩&chap=73&version=csb&gb=0
```

看 `sec=1` 的 `bible_text`，解開 `\u` 後是：

```html
<h2>第三卷</h2>
<h3><i>（詩篇73-89【1】
<h5>述說神的公義</h5>
神必然善待<u>以色列</u>，<br/>
善待那些心裡純潔的人。<br/>
```

## 問題在哪

- `<h3><i>（詩篇73-89【1】` 之後沒有 `</i></h3>`，緊接著就是下一行 `<h5>`。
- 看起來結尾標籤和註腳標記 `【1】` 有關：標題行的收尾可能在註腳處理時漏掉了。結尾標籤應該在註腳標記之外、整行之後，請貴方確認是在哪一步掉的。
- 「（」也沒有對應的「）」，推測同樣是在這個位置被截掉。

## 影響範圍

同樣格式出現在每一卷的卷首（各卷第一篇的 `sec=1`），已確認：

| 卷 | 篇 | 內容 |
|---|---|---|
| 第一卷 | 詩篇 1 | `<h3><i>（詩篇1-41【1】` |
| 第三卷 | 詩篇 73 | `<h3><i>（詩篇73-89【1】` |
| 第四卷 | 詩篇 90 | `<h3><i>（詩篇90-106【1】` |
| 第五卷 | 詩篇 107 | `<h3><i>（詩篇107-150【1】` |

第二卷（詩篇 42）也是。

## 希望的結果

標題行應為完整、成對的標籤，例如：

```html
<h3><i>（詩篇73-89【1】）</i></h3>
```

註腳標記 `【1】` 留在標題文字裡沒關係，但 `</i></h3>` 要在它後面補上。
