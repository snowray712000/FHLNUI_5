## 4. Data Flow

### 4.1 Request 與 API

`TPPageState.s.bookIndex`（1-based）→ `BibleConstant.ENGLISH_BOOK_ABBREVIATIONS[book-1]` → `/json/qp.php?engs=...&chap=...&sec=...&gb=...`。`isRDLocation()` 判斷 localhost、127.0.0.1、file origin；開發位置使用 `https://bible.fhl.net`，其它位置使用相對 origin。使用 jQuery ajax，未指定 dataType 或 timeout；依回應與 jQuery 解析結果取得物件。證據：`parsing_api_async_es2023.js:10–34`、`isRDLocation.es2023.js:6–8`。

API 只驗證 `status === 'success'` 與非空 record，沒有驗證所有必要欄位、wid 連續或 N 合法值。`record_count` 不控制 render，實際讀 array.length。[官方 qp.php 說明](https://bible.fhl.net/json/) 提供 N、prev/next、wid 與 record 欄位契約；本報告仍以目前前端讀寫與實際回應為準。

### 4.2 分詞、換行、版本差異

**Confirmed**：token 規則 `/[^ \n\r־,.]+/g`；分隔符為一般空格、CR、LF、希伯來連字號 maqaf、英文逗號與句點。不是所有標點：括號、希臘標點等可能保留在 token。`+` 若成獨立 token 會占 wid；貼在字旁不一定被當版本符號。上區先只比數量（`top:21–37,78–83`），數量相同不證明每個 token 與 record 的內容對應正確。

method_2 重新產生 wid span，並非直接消費 `_jaWord`；下區的 + 跳過與 w/u 色塊才讀 cache（bottom `:78–80`）。正常 H 反轉已在 cache 完成，method_2 沒再反轉；將換行轉 br 後，再以 br 分组。直譯與原文行數不合時取最大，缺的一方用空白，不報 UI 錯誤。

G 的 + 全部收集後每三個分組，第一／第二之間的每個詞各加「(韋：…)」黃底，第二／第三之間各加「(聯：…)」紅底，最後移除 + span（top `:163–214`）。空段迴圈沒有詞便不產生標籤；沒有三元完整性檢查。cache 的 binder 也假定依序可找到三個 +，標記中間 token 為 w/u，連分隔片段也會帶 wu。下區以實際 record.wid 查 cache 所推算的 + wid，略過符號，並保留原 wid 間隙。

**fallback 是活路徑**：詞數不合時記錄 console warning/error，轉 method_1；它以純文字呈現，不加 sn-btn/wid，所以上方詞項 click／hover 不能作用（top `:245–307`）。H 在 `:250` 又 reverse，因此與 cache 的反轉互相抵銷；對多行 H 可能配错直譯，這是程式可證明的二次反轉，不宣稱本次代表 H 節已觸發。G fallback 是否進入特殊處理，檢查外層整節 + 數是否為正的三倍數，卻逐行 split('+') 繪製；若一組跨行，不保證版本區段正確。

### 6.3 備註 SN 與文法圖片

**Confirmed**：備註 SN regex `/SN ?([0-9]+a?)/gi`，支持 SN 後零或一個 ASCII 空格、數字與可選 a，不支持任意空白、沒有 SN 前綴的第二數字。多次有 SN 前綴可各自轉換。產生可見 H/G 前綴與去零數字，但屬性為 `N,k,tp`，沒有 `sn`（bottom `:158–167`）；Content 的主區及 dialog click 都讀 sn，因此會送 undefined。這是「匹配到 SN」之外另一個独立缺陷，不能因為看見可點的 span 就宣稱字典正常。

## 10. Recovered Feature Specification

下列正式規格只納入已確認的現有功能。此節描述使用者可輸入與系統輸出，不以函式名稱綁定未來實作。

### Input

- 目前書卷、章、節，以及選取的「原文」分頁。
- 繁簡設定、希伯來／希臘文字型大小、即時 SN 開關。
- 整節原文、直譯、語言識別、前後節與逐詞分析資料。
- 使用者的原文字點擊／滑入滑出、SN 點擊、前後節與分頁操作。

### Behavior

1. 使用者選取「原文」後取得目前節的分析資料；原文分頁選取中，改節／書章、繁簡或即時設定會重新取得內容。重點同一個已選分頁不重畫。
2. 將整節原文與直譯按行交錯呈現；正常舊約資料先調整原文行序使其對應直譯。兩者行數不同時保留較長一方，以空白補另一方。
3. 能按詞分配位置時，上方原文字具詞項操作，下方依資料順序顯示詞索引、原文編號、原文字、字彙分析、原型、簡義與備註；新約額外顯示詞性。相同原文編號不同出現位置仍是不同詞項。
4. 分詞數量與逐詞資料不合時，原文區退回非逐詞操作的文字呈現，逐詞分析區仍另行產生。
5. 對符合三個分隔記號的版本差異，顯示韋式／聯式文字及黃／紅背景，略去符號自身詞項並保留詞索引間隔；一方可為空段。
6. 點上方原文字顯示該位置的分析對話框，先關閉既有同名框；主 SN 可送往原文字典。焦點在該框關閉按鈕時可按 Esc 關閉。
7. 即時模式下，滑入／滑出原文字觸發詞項框開／關；點擊時暫停即時開關一段時間。一般模式仍可點擊開框。
8. 備註中符合格式的文法編號轉成新頁圖片連結，多個編號各有連結；範圍標記指向起始編號圖片。
9. 前後節以服務提供的相鄰位置切換，更新目前經節與相關閱讀區；全書起點不提供上一節，終點不提供下一節。
10. 原文有各自字型與大小設定；上方 H 右對齊、G 左對齊。詞性及版本差異使用既有顏色規則；上下區分別捲動。

### Output

- 經節標題、適用的前後節控制、整節原文／直譯、逐詞分析。
- 選定詞項的 Parsing 對話框、主原文編號的字典查詢入口、文法圖片連結。
- 經節／設定及相關閱讀歷史狀態更新；不保證每次按鈕導航均改寫 URL。

### 現有缺陷與限制（不是未來必須保留的需求）

- 備註原文編號的點擊屬性契約錯誤，不能保證正確字典查詢；使用者已確認 `SN 112  1` 表示 SN112、SN1，現行解析漏掉 SN1。
- 懸停同 SN 標色參數不合，不能保證所有相同詞號同步變紅。
- 舊約 fallback 可能二次反轉；單純詞數相同也不保證逐詞內容吻合；不完整／跨行版本組的处理有限。
- 空資料、失敗字串、部分欄位缺失沒有完整使用者錯誤呈現；舊內容可能保留，快取可被失敗值污染。
- 非同步舊回應可能覆寫新內容或其它分頁，且標題可能與回應節数不同；已開詞項框不自動隨節更新。
- 部分繁簡標籤／詞性色彩、奇數列白底、全型文法標記不具全面支援保證。
- 未提供主畫面自訂剪貼簿格式或跨應用混合文字方向保證。

聯式正式資料版本，以及複製／貼入目標的確切驗收期望。完整互動及异常情境尚待工程實測的部分見第4.3節；不將未驗證觀察補寫成正式功能。
