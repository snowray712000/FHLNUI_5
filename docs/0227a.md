
目標: 將書卷名稱從英文轉換成中文，並且測試轉換結果是否正確。

動機: 這是給 tsk 用的，雖然其它也可以用，但原本是設計給 tsk 用的。應該會在 parseTsk 後面呼叫，不論是改變 w 或是 ref 

# Job 26:14; Ps 33:6; 104:30; Isa 40:12-14|

方法:
- 有常數可以用
  - ENGLISH_BOOK_SHORT_ABBREVIATIONS ... 例如 'Ge', 'Ex', 'Le',...
  - CHINESE_BOOK_ABBREVIATIONS_GB CHINESE_BOOK_ABBREVIATIONS ... 例如 '創', '出', '利', ...
  - CHINESE_BOOK_NAMES CHINESE_BOOK_NAMES_GB ... 例如 '創世記', '出埃及記', '利未記', ...
- 偵測到 Job Ps Isa 這些名稱，作為 斷點
- 然後找到對應的 book id
- 然後再找到對應的中文名稱
- 會變成 # 伯 26:14; 詩 33:6; 104:30; 賽 40:12-14|

函數設計:
- cvt_ref_to_chinese(ref: string, isgb, isfullname): string
  - 會把 ref 中的英文書卷名稱轉換成中文書卷名稱
  - 例如 # Job 26:14; Ps 33:6; 104:30; Isa 40:12-14| 會轉換成 # 伯 26:14; 詩 33:6; 104:30; 賽 40:12-14|

Case 歸納:
- # 10,12,18,25,31; Ec 2:13; 11:7|
  - 偵測到 Ec 作為斷點.
  - 第 1 部分 10,12,18 ... 因為沒有書 ... 所以不處理
  - 第 2 部分 Ec 2:13; 11:7| 因為有書 ... 所以處理成 傳 2:13; 11:7|
