# 7.5.14.6：全螢幕，對話框跳不出來

## 現象

按工具列的全螢幕 (⛶) 後，開搜尋視窗、交互參照預覽、字典、設定對話框……都不見了 (其實有開，只是看不到)。

## 原因

瀏覽器全螢幕時，只畫「全螢幕元素的子孫」。舊的 `requestFullscreen()` 只讓 `#mainWindow` 全螢幕，
而 jQuery UI dialog、`RefChooseBar` 的浮出列、注腳 popup、複製按鈕列都是 `append` 到 `<body>` 下，不在 `#mainWindow` 裡，全被擋掉。
(工具列 `#fhlTopMenu` 也在 `#mainWindow` 外，所以全螢幕時本來就看不到，那是想要的。)

## 做法 (`index/requestFullscreen.es2023.js`)

- 改成**整份文件** (`document.documentElement`) 全螢幕，body 下的東西都看得到。
- 工具列照舊藏起來：`fhl.css` 的 `:root:fullscreen { --tb-h: 0px }` 與 `:root:fullscreen #fhlTopMenu { display: none }`，`#mainWindow` 的 `top` 吃 `--tb-h`，所以三個視窗自動從最上面開始 (原本靠 JS 寫 inline `top: 0px`，已拿掉)。
- 按鈕改成真正的開關 (`toggleFullscreen`)：全螢幕中再按一次 → `exitFullscreen()`。原本再按只是拿掉 `selected` 樣式，沒有真的離開。
- 按鈕的 `selected` 由 `fullscreenchange` (含 webkit) 決定 (`watchFullscreen`，`WindowControl` 呼叫一次)，按 Esc 離開也會跟著；原本 `.then(afterExit)` 是在「進入」時就執行，名稱與時機相反。
- 鍵盤 `L` (`registerEvents_doc`) 與窄螢幕 ⋮ 選單的全螢幕，都是觸發 `#fullscreenControl` 的 click，不用另外改。

## 進出全螢幕時，開著的對話框重算位置與大小 (`index/DialogFit.es2023.js`)

整份文件全螢幕後，對話框看得到了，但視窗大小一下變很多：全螢幕中開的對話框退出時比視窗大、跑到視窗外；一般視窗中開的對話框進全螢幕後相對變小、擠在左上。
`DialogFit` 監聽 `resize` (debounce 120ms) 與 `fullscreenchange`，對所有開著的 `.ui-dialog` 處理 (DialogHtml、譯本選擇、書卷章、版本資訊都在內)：

- **進出全螢幕**：位置與大小照視窗比例縮放 (中心點照比例)，進去變大、退出縮回來，來回幾乎還原 (實測 1400×900 ↔ 900×600：1120×765 @140,68 → 720×510 @90,45 → 1120×765 @140,68)。
- **一般縮放視窗 / 旋轉**：不縮放，只在放不進視窗時縮小 (邊緣留 8px)，跑出視窗外的拉回來。
- 只有「使用者拖過 / 設過高度」(有 inline `height`) 的才縮放高度，自動高度的只在放不進視窗時限制，免得變成固定高度後下方一片空白。
- 拖曳放大的上限 (`resizable` 的 maxWidth / maxHeight) 跟著新視窗。**不要改 dialog 的 `maxWidth` / `maxHeight` 選項**：jQuery UI 會重算 `_size()`，高度變回 auto、位置跑掉 (試過)。
- `fullscreenchange` 比 `resize` 早 (mac 全螢幕動畫要幾百 ms，`resize` 在動畫結束才來)，所以它只設旗標 (2 秒內有效)，真正計算等 `resize` 之後；沒等到 `resize` 就不縮放。
- 使用者記住的大小 (`fhlDlgSize`) 只在拖曳時寫入，這裡的調整不寫入，下次開還是使用者原本的大小。

測試注意：預覽面板的視窗大小模擬不會送 `resize`，要自己 `dispatchEvent(new Event('resize'))`；面板剛打開時 `innerWidth` 是 0，那時開的對話框寬度會是 150，關掉重開。

## Firefox 回報「沒成功」其實是跑到舊版

發版後 Firefox 回報：全螢幕裡開對話框 (按了 3 次) 都看不到，退出才出現那 3 個視窗 — 與修之前的症狀一模一樣。
原因是 Firefox 還在用快取的舊 `requestFullscreen.es2023.js` (ES module 檔案快取)，強制重新載入 (⌘⇧R) 後正常；Safari 一開始就是新的。
遇到類似回報先確認版本號 / 強制重新載入，再查程式。要驗證時在全螢幕裡看 `document.fullscreenElement?.tagName`：`HTML` = 新版 (整份文件)，`DIV` = 還是舊版 (只有 `#mainWindow`)。

## 注意

- 全螢幕要使用者手勢 (click / 按鍵) 才能進；開發者工具或預覽面板用 JS 呼叫會 `Permissions check failed`。
- 全螢幕時工具列藏起來，所以搜尋框要用快捷鍵或先離開全螢幕 (與以前相同)。
- iPhone Safari 不支援一般元素全螢幕，沒有變 (以前也一樣)；iPad 走 `webkitRequestFullscreen`。
