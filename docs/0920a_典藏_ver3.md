## 1. 功能摘要

**Confirmed / S**：典藏是右側資訊面板的一個分頁。首次建立元件時顯示「年代／文體篩選＋書籍清單」，使用者按某列「閱讀」後，才用該典藏 ID 與主畫面目前經節查詢對應頁面。閱讀區提供回清單、上一頁、下一頁、書名、書卷／封面、頁碼、章節範圍及圖片；圖片連到原圖的新瀏覽內容。證據：`index/FhlInfoTitle.es2023.js:27–43`，`index/FhlInfoContent.es2023.js:215–229`，`obphp.js:225–286,289–383,447–474`。

**Confirmed / S+A**：不能把本功能限定為「古卷」或「每節一張照片」。API 清單還有信仰著作，範例 ID 27 是 1924 年《勸世良言》，`procb="0"`，但仍出現在創世記第一章的可用書籍結果中，創 1:1 與 1:2 都查得 page 3。前端不以 `procb` 或 `div` 排除資料，而採用兩 API 的 ID 交集。見第 4 節實測及 `obphp.js:564–592`。

**Confirmed / S**：頁面定位由 API 完成；前端沒有把節號算成紙本頁碼的演算法。`book=27` 是典藏 ID，`ps.bookIndex=1 → ibook=0 → engs=Gen` 是聖經書卷索引的轉換；回應 `vid=1` 又是聖經書卷的一基編號，三者不可混用。證據：`index/FhlInfoContent.es2023.js:220–224`，`static/search_api/fhl_api.js:261–271`，`obphp.js:343–346,687–714`。

## 3. Runtime Flow

以下為 **Confirmed / S** 的程式路徑；括號說明該步職責。

```text
點「典藏」或初始化恢復 titleId=fhlInfoOb
└─ FhlInfoContent.render（組經節、語系、高度 props）
   └─ React.render(frame, #fhlInfoContent)
      ├─ 新建 frame：getInitialState（list／全部篩選／idxbook=257）
      │  └─ componentWillMount → _set_obdata_from_ajax
      │     ├─ ob.php?gb=0|1（全書目）
      │     └─ 成功後 sob.php?gb=0|1&book=all&engs=...&chap=...
      │        └─ 成功後用書籍 ID 交集＋年代＋文體篩選 → obdata → 清單
      └─ 已有 frame 接收 props：componentWillReceiveProps
         └─ 用 state.idxbook + 新經節查 sob → sobdata（不重建 obdata）

清單年代／文體 click
└─ _set_year_range／_set_style（改篩選）
   └─ 再做全書目＋當章可用書籍兩次請求 → 更新清單

清單某列「閱讀」click
├─ _set_book_id(iid)（改 idxbook；用傳入 iid 直接查詢，避免等 setState）
│  └─ sob.php?gb=...&book=iid&engs=...&chap=...&sec=...
│     └─ success → sobdata=record, err_msg=""（也重寫 idxbook）
└─ _set_content_type("read") → 閱讀畫面，僅用 sobdata[0]

閱讀「上一頁／下一頁」click
└─ 讀 sobdata[0].prev／next → _set_read_page(page)
   └─ sob.php?gb=...&book=idxbook&page=page → sobdata → 閱讀畫面

閱讀「回清單」click → content_type="list"（沿用 obdata，不查詢）
圖片 click → <a href=orig target=_blank>（瀏覽器處理連結）
```

證據：`obphp.js:15–16,80–85,225–229,289–303,333–383,391–435,447–481,535–618,652–749`；HTTP 封裝：`static/search_api/fhl_api.js:99–126`。

**Confirmed / S+E**：初始化不是自動打開 257。VM 呼叫 `componentWillMount` 只記錄 `ob.php?gb=0`；未完成其 callback 前沒有第二個請求。即使新舊經節完全相同，呼叫 `componentWillReceiveProps` 仍記錄 `sob.php?gb=0&book=257&engs=Gen&chap=1&sec=2`。`FhlInfo.init` 兩次 render 的結構意味恢復典藏時也可能多一次頁面查詢（**Inferred**，完整 mount/update 時序未實測）。

> **【2026-09-21 更新】**：`componentWillReceiveProps` 已改為先比對 `nextProps` 的 `ibook`/`ichap`/`isec`/`isgb`
> 與 `this.props` 是否完全相同，相同就直接 `return`，不再呼叫 `_query_sob_from_ajax_book_chap_sec`。因此
> 「新舊經節完全相同仍記錄 sob.php」這句已不成立；`FhlInfo.init` 呼叫兩次 render 的結構本身未動，但即使因此
> 觸發第二次 `componentWillReceiveProps`，只要經節與語系相同就不會再多發一次 `sob.php` 請求，見
> `docs/0920d_典藏bug修正記錄.md` 第 4 項。
