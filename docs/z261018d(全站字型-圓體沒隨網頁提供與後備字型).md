# 全站字型：圓體只是本機字型，Mac Safari 退回預設

7.6.2.5

## 現象
Windows 看起來是圓角、舒服的字形，Mac Safari 卻像沒設定字型。

## 原因
`LatinQuotes, 'Zen Maru Gothic', 'GenSenRounded'` 兩個圓體都**沒有 `@font-face`**、沒有 Google Fonts，`static/font/` 也沒有，只是用「本機已安裝」的字型。作者的 Windows 裝了所以正常；沒裝的電腦（Mac、其他使用者）全部找不到，清單最後又沒有通用字型，退回瀏覽器預設。

Zen Maru Gothic 只含日文字集，很多繁中字沒有，所以放第一個（有字就用它的圓體，缺字才往後退）；GenSenRounded 字全但需本機安裝。

## 修法 (7.6.2.5，後備字型)
清單尾端補 `"Hiragino Maru Gothic ProN", "PingFang TC", "Noto Sans TC", "Noto Sans CJK TC", "WenQuanYi Micro Hei", "Microsoft JhengHei", sans-serif`（`index/fhl.css` 的 body、`#lecMain`、註釋區、`#commentContent`）：
- Ubuntu 的 Noto CJK 字型名稱是 `Noto Sans CJK TC`，所以另列；文泉驛微米黑為部分發行版預裝。
- Mac 有 Hiragino 丸ゴシック (圓體，缺的繁中字退蘋方)，沒有的字再到蘋方 / Noto / 微軟正黑體。
- `.sn` 的 `font-family: Microsoft JhengHei` 也補蘋方 / Noto / `sans-serif`。
- 順序刻意不動：`LatinQuotes` 仍最前（彎引號用西文字型）。

## 沒做 (待決定)
- 用 Google Fonts 載入 Zen Maru Gothic：全平台一致，但缺字仍退回後備字型。
- 自行提供完整繁中圓體 webfont (如粉圓 / 源泉圓體)：需子集化或分段載入，專案已有 11MB 的 `open_han.woff`。
- `fhl.css` 多處 `font: ... bold ,Microsoft JhengHei` 因 `bold` 位置不合法，整條宣告無效，本來就不作用，沒有動。
