# 地圖分頁：拖分隔條出現灰邊與「自動範圍」按鈕（7.6.2.4）

## 灰邊

地圖在右側工具窗格內。拖曳分隔條改變窗格大小時沒有 `window` 的 `resize` 事件，leaflet 不知道容器變了，露出灰色空白或偏移。

`generateMap`（`static/fhlmap_api/fhlmap_main.js`）對容器 `#fhlmapContainer` 掛 `ResizeObserver`，大小一變就 `map.invalidateSize()`（保持中心與縮放級數）。`fhlmap_dispose` 裡 `disconnect()`。

## 自動範圍按鈕

左上角（縮放按鈕下）自訂 `L.Control`，`leaflet-bar` 樣式、⛶。按下 `map.fitBounds(ptsAllForAutoZoom)`，即載入本章時的範圍。`ptsAllForAutoZoom` 在換章載入時重建；本章沒有地名（空陣列）則不動。
