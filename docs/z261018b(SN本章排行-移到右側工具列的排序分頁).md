# 7.6.2.3 SN 本章排行移到右側「排序」分頁

## 為什麼
本章排行很常用，但要先按設定面板的 SN ⚙ 開對話框、再切到「本章排行」分頁，太深。改放右側工具列 (原文 / 註釋之間) 一鍵可達。

## 做法
- `FhlInfoTitle.es2023.js`：`title` 在「原文」後加 `{ name: '排序', id: 'fhlSnRank' }` (繁簡同名)。
- `FhlInfoContent.es2023.js`：`case "fhlSnRank"` 呼叫 `SnFilterDialog.s.renderRankTab(dom)`。
- `SnFilterDialog.es2023.js`：
  - 對話框分頁只剩 `combo` / `detail`；`readTab` 舊值 `'rank'` 自動回 `combo`。
  - `renderRankTab(dom)`：建 `.snf-dlg.snf-tabpane > .snf-rank` 放進 dom，`#rankBox` 指向它，畫排行並 `#watchLecture()`。`#renderRank` 本來就檢查 `box.isConnected`，切走分頁後不會重畫到消失的節點。
  - 經文換章的 MutationObserver 不再隨對話框關閉而斷開 (排序分頁沒有對話框也要更新)。
  - 對話框內改了設定 (`render()`、`#setMode`、排行的 ＋ / −) 時一併呼叫 `#renderRank()`，開著的排序分頁跟著更新。
- `fhl.css`：`.snf-dlg.snf-tabpane` 高度 100%，沿用原有排行 css (選擇器都掛在 `.snf-dlg` 下，所以外層也要有這個 class)。

## 注意
- 排行的主導詞規則 (不用 / 前 N 名 / ≥ N 次) 也在這個分頁，對話框細項的說明文字已改指向「排序」分頁。
- 寬螢幕版面 (清單撐滿高度與捲動) 只用 DOM 檢查過，沒親眼看。
