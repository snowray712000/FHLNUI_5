以前 ❮ ❯ 是經文區左右兩側各 50px 的整條高度的點擊區，手機上吃掉很多寬度。現在放進表頭列（譯本名那一列）：

`[❮] 譯本1 譯本2 譯本3 [❯][←][→]`

- 按鈕是 `#fhlLecture` 底下的 absolute 元素（`.chapBack` / `.chapNext` / `#viewHistoryButton`），疊在 `#lecMainTitle` 上，寬 `--nv-w`（32px × `--ui-k`，觸控不低於 `--touch-min`），高 `--bar-h`。電腦與手機一致。
- 表頭欄寬沒變（仍與經文欄對齊、灰線可拖）；第一個譯本名左邊讓 1 個 `--nv-w`，最後一個右邊讓 3 個，被壓縮的只是名字的可用寬度（`.versionName` 太長省略）。
- `#lecMain` / `#lecMainTitle` 左右 padding 由 50px 改為 10px，經文變寬。
- 第一章 / 最後一章：按鈕改 `visibility: hidden`（原本 display none，絕對定位不會位移，兩者皆可）。
- 取捨：手機 + 3 個譯本時，最後一欄名字只剩約 20px，可能被遮住。決定：接受，譯本是使用者自己選的，仍知道它是什麼。
